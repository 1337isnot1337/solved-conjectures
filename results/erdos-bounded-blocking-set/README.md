# Erdős’s bounded blocking-set problem

**Lean status:** none.

Translation planes of bounded dimension over a kernel field of bounded characteristic have blocking sets meeting each line in a uniformly bounded number of points.

The bound is uniform over the extension degree and the choice of spread. The proof gives an explicit construction, including a non-Desarguesian example. The absolute bound for all finite projective planes remains open. [Erdős problem 1159 and its original references](https://www.erdosproblems.com/1159)
