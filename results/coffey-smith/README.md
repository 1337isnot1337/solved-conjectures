# Coffey–Smith conjecture

Complete proposed unconditional disproof of Smith’s named conjunction: if RH holds the dyadic coefficient square mass is O(N^(-1/2) log³ N), so both proposed positive-fraction sets have density zero for 0<ε<1/4; without RH the polynomial upper bound fails. The weaker Coffey upper-bound assertion alone is not refuted.

**Status:** complete proposed result for the stated scope; internally reviewed, not Lean-formalized or externally refereed. Prior-art findings are bounded; exclusive priority is not claimed.
