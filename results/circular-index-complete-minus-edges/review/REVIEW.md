# Referee report: Part A (and B, C, D) of `circular-index-complete-minus-edges/PROOF.md`

Reviewer: independent referee. The author's scratch directory was not read. All code is in `/home/claude/kn_review/`.

## Verdict

**Part A is correct and complete.** It proves χ'_c(K_n − e) = n for odd n ≥ 7, which is Mazák–Zrubák Conjecture 2. I checked every step by hand, including the wrap-around in A6 and the case m = 3. Its logic does not depend on the first proof. I found no mathematical error in Part A. Three presentation gaps remain, none of them serious (G1–G3 below), and each is closed in one or two lines.

**Part B (Lemma B) is correct for m ≥ 2.** As stated it is false for m = 1 (error E1), which is a trivial fix. **Part C**: every stored colouring checks out, and every value in the table is correct. One row says less than is now known (G5). **Part D**: Conjecture H is stated as a conjecture and nothing in the data contradicts it.

## Errors

- **E1 (Lemma B, m = 1).** As stated the lemma allows m = 1. Then K_3 − P_3 is a single edge. It trivially has a perfect sequencing, but F = P_3 is not a matching. The proof breaks because the middle vertex has no occurrences, so "its gaps sum to N" is false. *Fix:* assume m ≥ 2. Then every vertex has degree 2m − d ≥ m − 1 ≥ 1, and N ≥ m + 2, so the positions j, j+m, j+m+1 are distinct and A2 applies.
- **E2 (citation).** The remark that no graph is known with χ'_c ∈ (Δ + ½, Δ + 1) for Δ ≥ 8 is cited as "[MZ, Section 4]". In arXiv:2603.08822, Section 4 contains Conjecture 2. The Δ ≥ 8 sentence is in the final open-problems section, after Problem 7. (I read the PDF through a fetch tool. It reported the section once as 7 and once as 8, and both times not 4.) The quoted content is accurate: Conjecture 2 is stated for even d > 4, and K_5 − e has value 9/2.
- **E3 (source of F1, cosmetic).** The numerator bound comes from A. Vince, *Star chromatic number*, J. Graph Theory 12 (1988) 551–559, **Theorem 3**. For a graph on n vertices there is a k₀ ≤ n with χ* = χ_{k₀}, where χ_k = k / (minimum circular distance). So χ_c = k₀/d with k₀ ≤ |V|. I read this in Vince's PDF. Applied to the line graph it gives p' ≤ |E| exactly as Lemma 0 uses it. The equivalence "(p,q)-colourable ⇔ χ_c ≤ p/q" is the standard Bondy–Hell fact, also in Zhu's survey. The text marks [Zhu01] as "quoted from memory". It should cite Vince's Theorem 3 directly.
- **E4 (scripts, cosmetic).** `verify_seq.py` refers to a "Lemma C1" that does not exist. For A5, `check_structure` checks only that each full vertex is in each ordinary class exactly twice. It does not check that the two slots are consecutive, the bijection, or the formula z_{k−1}z_k (it builds `cycles` but never uses them). It does not check A6 at all. So "checks Lemmas A2–A5" overstates what it does for A5. My `lemma_check.py` checks all of these.

## Gaps (with completions)

- **G1 (A6, iteration).** The proof treats one special class. If r_u and r_v are adjacent, possibly across the wrap m → 0, the chain passes through two special classes. *Completion:* at a position Q of a special class, the special vertex stays, so μ(Q) = w is the full vertex there. Its block in that class has length 1 and is entered by a move, so w arrived from Q − m, and w = μ(Q − m). Repeat this until an ordinary class is reached, which takes at most 3 steps. Each step changes the slot by −1, or by 0 at the move (0,k) → (m,k). The sequence of classes depends only on ρ, so the total shift c is constant. I checked the slot formulas (σ,k)+m = (σ−1,k+1) for σ ≥ 1 and (0,k)+m = (m,k) by hand and in code.
- **G2 (A2, wording).** The proof says "since N > m". It also needs N ≠ m + 1, so that position j + m + 1 is not j. Here N = (m+1)(2m−1), so this holds.
- **G3 (Lemma A1 / Lemma B corollaries not written out).** The sentence "So for m odd, χ'_c(K_n − P_3) ≠ n − 2/m" omits a step. *Completion:* an (mn−2, m)-colouring has p = N and gcd(m, mn−2) = gcd(m, 2) = 1. The window argument of A1 then gives single-edge classes, hence a perfect sequencing, which contradicts Lemma B. More generally: **if t ≤ min(m−1, m+1), gcd(m,t) = 1 and F is not a matching, then χ'_c(K_n − F) > n − t/m.** Part D says that for 2t > m "only n − t/m ≤ χ'_c" is proved, so this strengthening is missing there.
- **G4 (unverifiable claims, now checked).** (a) "No perfect sequencing of K_11 − 2K_2" relied on a file outside the deliverables (`/home/claude/cms/ladder.c`). I confirmed it with my own exhaustive search from the definition: 0 sequencings, 1.36·10⁹ nodes, 6 minutes. So 53/5 is excluded for 2K_2 at n = 11 too, and that row is correct. (b) "Upper bound 17/2 for K_9 minus any 3 edges (earlier-session SAT data, not in colourings.json)". I found and checked (17,2)-colourings for all five 3-edge graphs (`k9_t3_17_2.json`). The authors should add these to `colourings.json`.
- **G5 (table row n = 9, t = 3, understated).** The row says "(33,4) undecided". In fact (33,4) is impossible for every 3-edge F. Here p = 33 = N and gcd(4,33) = 1, so a (33,4)-colouring would give a perfect sequencing. Lemma B rules out the four non-matching F. For 3K_2, my exhaustive search (all 44 F with t ≤ 5 on 9 vertices, `lemmaB_9.out`) finds no sequencing. So **χ'_c(K_9 − F) ∈ {25/3, 17/2} for every 3-edge F**. The only open case is (25,3).

## Checks performed

1. **Reduction (Lemma 0, A1).** Verified by hand. χ' = n because N/m > n − 1 when t < m. Also n − 1 < p'/q' < n and p' ≤ N < mn, so q' < mn/(n−1) = m + ½ and q' ≤ m. Then p'/q' ≤ n − 1/q' ≤ (mn−1)/m. In A1, p = mn − 1 = N. Each window W_j is a matching because colours within m−1 of each other are at circular distance less than q = m. The window sizes add up to mN = mp, so |W_j| = m for every j. Then |C_{j+m}| = |C_j|, and gcd(m, mn−1) = 1 gives |C_j| = 1. Every step is present and correct.
2. **Lemmas A2–A6 and Theorem A.** Each verified line by hand: A2 (H_j, a_j, b_j); A3 (N = (m+1)(2m−1); m−1 stays for a full vertex; all stays for u and v; r_u ≠ r_v); the block paragraph; A4 (the period-2m lift, the discrete intermediate-value step, and the signs of δ(±1)); A5; A6, including the wrap. The final contradiction needs two different ordinary classes, which requires m − 1 ≥ 2. Count check: K_{2m−1} on the full vertices splits into m−1 Hamiltonian cycles, one per ordinary class, and A6 forces them to coincide. For **m = 2** there is one ordinary class, so ρ' = ρ. A6 then only gives a shift c ≡ 0 (mod 3), which is consistent, so the proof does not prove too much. My code confirms shift 0 on every K_5 − e sequencing. For **m = 3** there are two ordinary classes, which would have to carry complementary 5-cycles, but A6 forces them to be the same. Nothing breaks at m = 3.
3. **Independent search** (`seqsearch.c`, from the definition, rotation fixed). K_5 − e: 4 sequencings with e_0 fixed, 36 counting all rotations and reversals. K_7 − e: 0. K_9 − e: 0. K_5 and K_7 (t = 0): 0. K_11 − 2K_2: 0. My search and the author's `perfect_sequencings` agree on 390 graphs, 37 of them with positive counts, including two m = 3 graphs with sequencings. `lemma_check.py` checks A2 (including e_{j+m} = H_j a_j and H_{j+1} = b_j), A3, the block structure, A4, A5 (bijection and z_{k−1}z_k edges) and A6 (slot arithmetic and rotation) on all 36 K_5 − e sequencings: all pass. On m = 3 sequencings of K_7 − (K_3 ∪ 2K_2) and K_{3,4}: A2 holds at all 4800 positions, and A4 holds at all 768 positions where both ends have the same degree.
4. **Lemma B** tested on every F with t ≤ m+1 for n = 5, 7, 9 (7 + 18 + 44 iso classes). There are no counterexamples. Sequencings exist only for K_5 − K_2 and K_5 − 2K_2.
5. **Author scripts.** `verify.py`: all 16 colourings verified. My own checker (`colcheck.py`) independently confirms all 16 and every table value it supports. `verify_seq.py`: output matches PROOF.md (4 / 0 / 0, and 0 for K_7 − P_3 and K_7 − 2K_2, 26 s). Its scope is as noted in E4. I did not run `verify_sat.py` (no long SAT runs). The n = 7 row does not need it: p = 19 = N and gcd(3,19) = 1, so the exhaustive sequencing search excludes (19,3) for both F. I reproduced that.
6. **Candidate lists.** n = 7: only 19/3 lies in [19/3, 13/2). n = 11: {53/5, 32/3, 43/4, 54/5}. n = 9, t = 3: {33/4, 25/3}. All checked by hand and correct.
7. **Conjecture H.** It is stated as a conjecture, and every proved value and interval in the table is consistent with it: t = 1 for all m; 2t = m for n = 9, 13, 17, 25, 41; 2t > m for n = 7 and n = 9 (t = 3); 2t < m for n = 11, 13. Note that for 2t > m it predicts n − ½, well above the proved lower bound n − t/m.
8. **Comparison with the first proof.** The new proof is logically independent. The first proof uses Guichard's acyclic-colouring lemma, longest-path levels and a 2h-column table. The new one uses Vince's numerator bound, the window/gcd argument and residues mod m+1. They share no lemma. The two are structurally parallel: the first proof's columns {r₁, r₂, r₁+h, r₂+h} mod 2h correspond to the two special classes mod h = m+1, and its |P| = h − 2 = m − 1 corresponds to the number of ordinary classes. Both fail at d = 4 for the same reason, a single non-special class. The new proof is shorter and, by my reading, complete.
