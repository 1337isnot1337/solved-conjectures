# Liang’s 0.3123 slice problem

**Status:** solved. This answers Open Problem 6.2 in Liang’s *Quaternary games with infinite misère quotients*. The smaller heap’s residue modulo seven, the gap’s residue modulo seven, and the equality flag determine the bulk outcome. The proof gives an exact table reduction for all pairs in the stated slice.

This does not claim to solve arbitrary heap sums of 0.3123 or to reprove its quotient infinitude, which Liang proved separately. Not Lean-formalized.
