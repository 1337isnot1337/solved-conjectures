# Komjáth’s property B problem

**Lean status:** none.

There is an almost-disjoint family of infinite sets on a countable ground set, with no singleton intersections, that admits a proper two-coloring yet defeats every attempt to put two points of each color in every edge.

The construction can be chosen closed in the space of infinite subsets. The ordinary property B question asks for one point of each color per edge and remains open. The positive case with bounded higher-order intersections uses the minimal-transversal theorem of Csernák and Soukup. [Komjáth’s question as recorded by Erdős](https://www.erdosproblems.com/602)
