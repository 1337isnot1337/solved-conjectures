# Audit of the oriented-tree formula

## Source and priority screen

- [Original paper, §3.4 and Problem 5.2](https://arxiv.org/html/2604.15909#S3.SS4): Lemma 3.7 bounds the number by the number of leaves from below; Theorem 3.8 gives equality with sinks plus near-sinks for out-arborescences, and reversal handles in-arborescences. Figure 5 shows that the general bounds in the paper are not exact. Problem 5.2 explicitly asks for a formula for arbitrary oriented trees.
- [Current survey §§5.9 and 6](https://arxiv.org/html/2501.19385v5#S6) still lists an oriented-tree formula as open and distinguishes it from the spectrum, which varies the orientation.
- Searches on 2026-11-26 combined the exact problem and author terminology with “chain partition”, “antichain”, “recurrence”, “dynamic programming”, and “linear time”. They covered the papers and later survey, bibliographic and public repository searches, and adjacent directed-geodesic and poset literature. The tree formula was not found. This is a bounded priority screen, not a claim that a short reduction cannot have circulated privately.
- The min–max theorem invoked is [Greene–Kleitman's 1976 theorem](https://doi.org/10.1016/0097-3165(76)90077-7), not a new theorem about arbitrary posets. [Felsner and Raghavan](https://ftp.cs.ucla.edu/tech-report/1993-reports/930014.pdf) study general weighted poset families; the proof here instead computes the weighted tree optimum in linear time from the original edges.
- No Lean formalization or outside verification is claimed.

## Exact independent checks

Run `python3 verify.py` in this directory. Every labeled tree through order 5 is generated by Prüfer words; all 2,143 orientations were compared with exhaustive set search using directed BFS and geodesic equalities. All 2,143 were also compared with exact enumeration and minimization over chain partitions. The same run checks 584 weighted and general-k variants, including negative weights, and directly validates the recovered witness.

Run `python3 verify.py --atlas` with NetworkX installed to test all orientations of the nonisomorphic underlying trees through order 9. This added a separate sweep of 15,943 orientation inputs, 967 exact chain-partition checks and 2,364 weighted checks. Some inputs overlap with the first run. The code borrows neither the recurrence nor the chain-partition theorem for its independent geodesic oracle; the exhaustive chain partition implementation is an extra comparison. The analytic proof applies at every order and is not based on enumeration.
