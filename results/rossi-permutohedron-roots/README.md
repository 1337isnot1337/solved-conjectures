# Rossi’s permutohedron characteristic-polynomial conjecture

**Proved.** For every integer n at least 3, the characteristic polynomial has n distinct positive roots: n−2 below one, one at one, and one above one. This is Conjecture 6.16, without the separate q-deformation.

The proof constructs a uniform sign grid for the corresponding shifted Eulerian polynomial. An alternating exponential expansion controls the endpoints, and conjugate poles control the bulk. Exact integer signs cover the finite initial range.
