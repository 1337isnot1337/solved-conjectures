# Merlini–Sala–Sala conjecture

Complete proposed unconditional refutation of the logarithmic and all-ε subpower growth conjecture for the tiny Li term: limsup |λtiny(n)|/n^(1/4)=∞. The authors’ weaker linear stability conjecture is not resolved.

**Status:** complete proposed result for the stated scope; internally reviewed, not Lean-formalized or externally refereed. Prior-art findings are bounded; exclusive priority is not claimed.
