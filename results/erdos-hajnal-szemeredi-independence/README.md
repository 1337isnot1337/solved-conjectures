# Erdős–Hajnal–Szemerédi independence-ratio problem

**Lean status:** none.

A graph of cardinality at most the continuum is countably colorable if its finite subgraphs have bounded vector chromatic number. Finite graphs can have bounded Hall ratio and arbitrarily large vector chromatic number.

The finite separation uses Hall ratio at most $`4+\varepsilon`$ and a vector chromatic lower bound of order $`\sqrt{\log\log n}`$. Whether an uncountably chromatic graph forces arbitrarily large finite Hall ratios remains open. [Erdős, Hajnal and Szemerédi](https://users.renyi.hu/~p_erdos/1982-11.pdf)
