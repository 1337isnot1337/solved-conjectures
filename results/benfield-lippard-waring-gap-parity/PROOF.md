# Benfield–Lippard's stable Waring-gap parity conjecture

Benfield and Lippard's [Conjecture 10.4](https://arxiv.org/html/2404.08193v2#S10.Thmtheorem4) says that, for every exponent e≥2, the largest stable positive offset not expressible by e-th powers and the number of such offsets are both odd. The conjecture holds. In fact, with a=2^e−1, the largest offset is congruent to −a and the size to −(a−1)/2 modulo 2 when e is odd and modulo 2^{v₂(e)+2} when e is even.

## Proof

Let S be the additive monoid generated by m^e−1 for m≥2, with zero included. A positive integer n is a stable exception exactly when n∉S: writing j+n as a sum of exactly j positive e-th powers is equivalent to writing n as a sum of at most j shifted powers m^e−1, with padding by 1's. If a uniform stabilization argument is desired, Benfield–Lippard's Theorem 1.1 (crediting Zenkin) gives a fixed j for which only finitely many positive offsets are missing. Among those finitely many, wait until each offset in S has acquired its finite expression and use padding. No assumption on the minimum stabilizing length is required.

The gcd of the generators is 1. Otherwise, a prime q dividing every generator would divide q^e−1, which is impossible. Some finite subset therefore has gcd 1, so S is cofinite. Indeed, modulo any one positive generator, the residues generated by such a finite set form the whole finite cyclic group; take one nonnegative representative in each residue and then add any number of copies of the modulus.

Write a=2^e−1 and let w_r be the smallest element of S congruent to r modulo a, for r=0,1,…,a−1. A composite base m=uv is redundant by

    (uv)^e−1 = u^e(v^e−1)+(u^e−1).

Thus one can use only prime-base generators. No representation of w_r using these generators involves a copy of a: removing it gives a smaller element of the same residue. Every other prime base is odd, so each w_r is even, including w_0=0. More strongly, if e is even, every odd p satisfies 2^{v₂(e)+2} | p^e−1: p²≡1 (mod 8), and each subsequent squaring raises the guaranteed exponent of 2 by at least one. Thus all w_r are multiples of the claimed modulus M, which is a power of 2.

The largest gap in residue r is w_r−a if any nonnegative gap lies in that residue, and the number of its gaps is (w_r−r)/a. Taking the maximum and summing, respectively, gives the Frobenius number F and genus G:

    F = max_r w_r − a,
    aG = sum_r w_r − a(a−1)/2.

The first gives F≡−a (mod M). Since a is odd it is invertible modulo M, so the second gives G≡−(a−1)/2 (mod M). In particular both are odd, because e≥2 yields a≡3 (mod 4). These are the largest member and cardinality of the stable exception set.
