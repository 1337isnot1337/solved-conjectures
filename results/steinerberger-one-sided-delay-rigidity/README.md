# Steinerberger’s one-sided delay rigidity conjecture

**Status:** Written disproof, pending independent review. **Formalization:** none.

A mean-zero, sign-changing, smooth periodic function can satisfy the shifted differential identity at every negative point without being sinusoidal. Such examples exist for every least positive period T with 1/T nonintegral, and there is an exact elementary obstruction at the remaining periods.

[Proof](PROOF.md) · [Source and scope audit](AUDIT.md) · [Coordination issue #1092](https://github.com/1337isnot1337/solved-conjectures/issues/1092)

This does not resolve the separate conjecture about finitely many maximizing radii or contradict the theorem for the globally imposed periodic delay equation.
