# Shumyatsky’s conjugate prime-spectrum conjecture

**Proved.** Every finite group $`G`$ contains two conjugate elements whose generated subgroup has the same prime divisors as $`G`$. This answers [Kourovka Notebook Question 17.125](https://arxiv.org/pdf/1401.0300v50#page=123). The proof lifts conjugate pairs through products of simple groups using independent labels on closed walks, and uses an almost-simple generation theorem for the singleton factors.
