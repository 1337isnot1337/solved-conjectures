# Sharp uniform thresholds for normalized numerical-semigroup modules

This note concerns [Almirón–Moyano-Fernández, Question 4.13](https://arxiv.org/html/2012.01358v3#S4.SS2), separately from their [Question 4.8](PROOF.md) and from the original Wilf conjecture. Throughout, modules are normalized: $\Delta\subseteq\mathbb N_0$ contains $0$ and satisfies $\Delta+S\subseteq\Delta$. We count every generator in an $`S`$-generating set, including $0$, as in the source's introduction and Theorem 4.14 for $[0,g]$. The source's §2 instead attaches the index $r$ to $[0,g_1,\ldots,g_r]$; if $r$ excludes $0$, shift the index of our generator-refined thresholds by one. The least-integer thresholds below use positive integers. If $0$ is included in $\mathbb N$, it works exactly for classes in which every admissible module has conductor zero, including empty classes; all other thresholds are unchanged. Without normalization there is no finite threshold: $\Delta=t+\mathbb N_0$ for $t>0$ is a module with conductor $t$ and no elements below conductor.

Let $`m`$ be the multiplicity of $`S`$. If $S\ne\mathbb N_0$, then
```math
\min\{k\in\mathbb N_{>0}:k\delta(\Delta)\ge c(\Delta)\text{ for every normalized }S\text{-module }\Delta\}=m.
\tag{1}
```
Indeed every such $\Delta$ contains $`S`$, hence all multiples of $`m`$. There are $\lceil c(\Delta)/m\rceil$ of these below its conductor, proving that $k=m$ works. The module $`\{0\}\cup[m,\infty)`$ has $\delta=1$, $c=m$ and attains the bound: adding a positive element of $`S`$ always lands in its tail. If $S=\mathbb N_0$, the only normalized module is $\mathbb N_0$ and $k=1=m$ works. This gives an exact answer to Questions 4.13(1)–(2) under the normalization implicit in using $`\{0,g_1,\ldots\}`$.

## Sharp when the module generator count is also prescribed

Fix integers $m\ge2$ and $1\le r\le m$. Among all multiplicity-$`m`$ semigroups $`S`$ and normalized $`S`$-modules with exactly $r$ minimal $`S`$-generators, the smallest uniform integer $k$ in (1) is again $`m`$.

The upper bound is (1). For sharpness, take
```math
S=\{0,m,\ldots,(q-1)m\}\cup[qm,\infty)
```
and adjoin $`r-1`$ distinct generators $g_j=qm-m+j$ with distinct $`j\in\{1,\ldots,m-1\}`$. Let
```math
\Delta=S\cup\bigcup_j(g_j+S).
```
No $g_j$ belongs to $`S`$ and no positive difference between two distinct chosen generators belongs to $`S`$ (all those differences are smaller than $`m`$). Hence $0$ and the chosen $g_j$ form the full minimal $`S`$-generating set. The only additions below $qm$ are the chosen numbers themselves. For $q\ge2$ the previous block's last value $qm-m-1$ remains a gap, so $c(\Delta)\ge qm-m$, and $\delta(\Delta)\le q+r-1$. Thus
```math
\frac{c(\Delta)}{\delta(\Delta)}
  \ge \frac{qm-m}{q+r-1}\longrightarrow m.
```
For any fixed $m,r$ and sufficiently large $q$, this ratio is strictly larger than $m-1$. The case $r=1$ also follows directly from $\Delta=S$. There cannot be more than $`m`$ minimal $`S`$-generators in any module: of two elements with the same residue modulo $`m`$, the larger is generated by the smaller.

## At a fixed semigroup, the generator-refined threshold is not determined by (1)

For every $m\ge4$ the preceding construction with $r=2$ gives multiplicity-$`m`$ semigroups on which the two-generator module threshold is $`m`$. In contrast, for $S=\langle m,m+1\rangle$ the authors' Theorem 4.14 gives threshold at most 3: every normalized two-generator module is precisely $\Delta_g=S\cup(g+S)$ for a gap $g$. Thus the answer to Question 4.13(4), if read as determining the exact fixed-$`S`$ threshold for a specified module generator count solely from the all-module threshold, is negative.

A finite characterization at fixed $`S`$ is as follows. On the finite gap set $\mathcal G(S)$, write $x\preceq y$ if $y-x\in S$. The $`r-1`$ positive minimal module generators form an antichain $A$, and conversely every such antichain gives exactly one normalized module. Its remaining gap set is $D_A=\mathcal G(S)\setminus\uparrow A$. If $D_A\ne\varnothing$, the exact least positive integer $k$ for that module is
```math
\left\lceil\frac{1+\max D_A}{1+\max D_A-|D_A|}\right\rceil.
```
If $D_A=\varnothing$, the module is $\mathbb N_0$ and every positive $k$ works. Maximizing this expression over the antichains of size $`r-1`$ therefore computes the fixed-$`S`$ generator-refined threshold. This formula does not assert an efficient algorithm in the size of the gap set. If there is no antichain of the specified size, the uniform least positive $k$ is 1 vacuously.

## Which modules meet the threshold at their generator count?

For Question 4.13(5), use the antichain parameter $A$ above and put $r=1+|A|$. If the question refers to the threshold of the individual module, the following is the complete fixed-$`S`$ description. Include $mathbb N_0$ (the case $D_A=\varnothing$). For all other antichains, include exactly those satisfying
```math
 |D_A|le \frac{r-1}{r}(1+max D_A).
```
Indeed, this inequality is equivalent to $rdelta(Delta)ge c(Delta)$ by the two counts above. If the threshold in (5) is interpreted literally as the uniform quantity in (3), include all modules having generator count $r$ if and only if the same inequality holds for **every** size-$`r-1`$ gap antichain with $`D_A e\varnothing`$; otherwise include none of that count. Thus both interpretations give an explicit finite criterion in the gap poset of the fixed semigroup, without referring back to a Wilf threshold.

Finally, an assertion that $W_\Delta(r)\ge0$ holds for *every* normalized module with its own generator count $r$ forces $S=\mathbb N_0$: the module $\Delta=S$ has the single $`S`$-generator $0$ and $W_S(1)=-|\mathbb N_0\setminus S|$. The converse is immediate. This addresses Question 4.13(6) with the explicit convention of counting the minimal module generators, not the distinct ordinary semigroup embedding dimension of $`S`$.

### The exact two-generator-module threshold over a two-generated semigroup

The bound in the source's Theorem 4.14 is sharp exactly when the semigroup multiplicity is at least 3. If $S=\langle m,b\rangle$ with $3\le m<b$, it is symmetric: $x$ is a gap if and only if $F-x\in S$ for $0\le x\le F=c-1$, and $2\delta(S)=c$. Thus its next-largest gap after $F$ is $F-m$. The module $\Delta_F$ removes only $F$ from the gap set, so its conductor is $c-m$ and its left count is $\delta(S)-m+1$. Consequently
```math
W_{\Delta_F}(2)=2-m<0.
```
Together with the source's $W_{\Delta_g}(3)\ge0$ for all gaps, the exact threshold is 3.

The source's proof already states $W(g)=0$ for multiplicity 2, citing its earlier work. To make the exact thresholds explicit, if $S=\langle2,b\rangle$ with odd $b\ge5$, every gap $g$ is odd and $\Delta_g$ consists of the evens and odd numbers at least $g$. At $g=1$ it has conductor zero; otherwise it has conductor $g-1$ and left count $(g-1)/2$, so the uniform threshold is 2. For $S=\langle2,3\rangle$ the only such module is $\Delta_1=\mathbb N_0$ and the least positive threshold is 1. Thus the last sentence of Theorem 4.14 giving the exact value 3 without a multiplicity qualification overstates its proven bound in these multiplicity-two cases.

Targeted searches for the authors' Question 4.13, normalized-module Wilf thresholds, and the exact multiplicity or two-generator conclusions found the original statement and its Theorem 4.14, but did not locate an earlier explicit all-module characterization or the fixed-generator-count comparison. Classical module generator and gap-poset descriptions are not claimed as new.
