# Wang–Yang's conjecture

Complete proposed disproof of the author-manuscript Conjecture 1.10: for every fixed coefficient index, the signed forward differences of the Xi coefficients have infinitely many values of each strict sign. Final journal wording has not been checked; the adjacent logarithmic conjecture is separate.

**Status:** complete proposed result for the stated scope; internally reviewed, not Lean-formalized or externally refereed. Prior-art findings are bounded; exclusive priority is not claimed.
