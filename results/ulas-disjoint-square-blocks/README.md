# Ulas’s disjoint-block square-product conjecture

Lean formalization is **incomplete**. The checked [general construction and reduction](../../lean/Conjectures/UlasDisjointSquareBlocks.lean) proves infinitely many collections at every positive multiple of a constructed count, for every positive block length. Prime-avoiding tail counts remain unformalized. See [exact scope and remaining work](FORMALIZATION.md) and the [verification receipt](../../docs/verification/lean-ulas-20261124-162051/verification.json).

**Proved.** For every fixed common block length, proves infinitely many disjoint square-product collections at every sufficiently large fixed number of blocks. An affine-polynomial family gives one repeatable block count; multiplicative signs and binary codes fill the remaining residues.
