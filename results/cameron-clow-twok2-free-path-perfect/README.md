# Cameron–Clow’s 2K₂-free path-perfect conjecture

**Status:** Disproved.

Cameron and Clow conjectured that excluding an induced pair of
disjoint edges forces a graph to be path-perfect. The proof gives
infinitely many vertex-critical counterexamples. In each, the
whole graph needs one more color than the vertices of any path.

The same graphs refute the stronger $P_5$-free conjecture and
show that five is the least forbidden induced-path order for
which path-perfectness can fail.
