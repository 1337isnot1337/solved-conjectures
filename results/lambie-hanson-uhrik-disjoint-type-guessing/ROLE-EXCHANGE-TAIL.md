# Which ladder coordinate can be made arbitrarily high?

Lambie-Hanson and Uhrik’s Definition 2.6 permits exchanging the two roles in a disjoint type. The extra conclusion of their Theorem 2.7 specifies the chronological orientation. Here we keep the cofinality requirement on the **earlier** ladder and allow the two type roles to be exchanged. These conventions have different sharp thresholds. [Original paper, Definition 2.6 and Theorem 2.7](https://arxiv.org/pdf/2312.01828#page=5)

Normalize each type $`t_k`$ to end in 1. Its width is $`n_k\ge1`$, its depth $`d_k`$ counts the ones before the final zero, and its lower reach $`r_k`$ counts the zeros before the last such one, or is zero when $`d_k=0`$. Write $`C_\alpha[n]`$ for the first $`n`$ points of the increasing ladder, and $`C_\alpha(j)`$ for the point of index $`j`$, starting at zero.

**Theorem (ZFC).** A single ladder system on the nonzero countable limit ordinals works for all type sequences with both depth and lower reach bounded. For every countable coloring $`f`$ there is a color $`k`$ and a stationary set of ordinals $`\beta`$ of this color with a fixed full prefix $`C_\beta[n_k]`$. For every such $`\beta`$ and every $`\eta\lt\beta`$ there is a limit $`\alpha\lt\beta`$ of the same color such that the prefixes are disjoint and
```math
\mathop{\mathrm{type}}(C_\beta[n_k],C_\alpha[n_k])=t_k,
\qquad C_\alpha(d_k)>\eta .
```
The chronologically later vertex plays the zero role throughout. The increasing ladder also has $`C_\alpha(n_k)>\eta`$. When $`d_k>0`$, neither assignment of the two roles can make the point of index $`d_k-1`$ unbounded in a fixed $`\beta`$. This determines the earliest possible coordinate.

## Stationary fibers of the first few coordinates

Take the original ladder system in which every finite increasing tuple occurs as an initial segment on a stationary set. It exists by partitioning the countable limit ordinals into disjoint stationary sets, one for each tuple, and prescribing the tuple above its maximum. Choose a finite $`L`$ greater than both bounds. Take a nested chain of countable elementary submodels $`M_0,\ldots,M_{L-1}`$ of a sufficiently large $`H(\theta)`$, containing the parameters and with each earlier height in the later models. Write $`\delta_j=M_j\cap\omega_1`$. The heights are strictly increasing. For some $`k`$, stationarily many vertices of color $`k`$ have $`(\delta_0,\ldots,\delta_{L-1})`$ as a prefix, by countable completeness of the nonstationary ideal. Below write $`n,d,r`$ for the width, depth and reach of this color.

We first fix the entire zero-side prefix. We give the stationary-prefix construction since the heights that remain free are needed in the next step. For a tuple of length $`r+1`$, let $`P_{r+1}`$ mean that it occurs as a prefix on a stationary set of color $`k`$. Define $`P_j(u)`$ downwards by requiring unboundedly many $`\xi`$ with $`P_{j+1}(u^\frown\xi)`$. Then $`P_j(\delta_0,\ldots,\delta_{j-1})`$ holds for every $`j\le r+1`$. At each downward step the set of eligible next coordinates belongs to $`M_j`$ and contains $`\delta_j`$. If it were bounded in $`\omega_1`$, its supremum would belong to $`M_j\cap\omega_1`$. This proves the induction.

Write the normalized type as $`\sigma 0^{n-r}1^{n-d}`$, with $`\sigma`$ empty if $`d=0`$. For each of the $`r`$ zeros in $`\sigma`$, let $`s`$ be the number of preceding ones. Use $`P_j`$ successively to choose its coordinate inside $`M_s`$, above the previously chosen coordinates and above $`\delta_{s-1}`$ when $`s>0`$. The next-coordinate set is unbounded and belongs to $`M_s`$, since the earlier coordinates are in this model. The chosen coordinate is therefore below $`\delta_s`$. Use $`M_d`$ in the same way for the first zero after $`\sigma`$. For $`d=r=0`$ this simply chooses the first zero below $`\delta_0`$. We now have a tuple of length $`r+1`$ with a stationary color-$`k`$ fiber. Each remaining prefix coordinate on that fiber is regressive. Finitely many applications of pressing down give a full completion of length $`n`$ with stationary fiber. This existence assertion has all its parameters in $`M_d`$, so we may choose the completion there. Write $`a`$ for the resulting tuple and $`A`$ for its stationary color-$`k`$ fiber. Every entry of $`a`$ is below $`\delta_d`$. They have the prescribed relative order with respect to $`\delta_0,\ldots,\delta_{d-1}`$.

## Varying the earlier ladder

Set $`b=(\delta_0,\ldots,\delta_{d-1})`$, using the empty tuple for $`d=0`$. The set of countable ordinals $`\xi`$ for which $`b^\frown\xi`$ occurs on a stationary set of color $`k`$ is defined from parameters in $`M_d`$. It contains $`\delta_d`$ by the initial choice of color. It is therefore unbounded, by the same supremum argument. For each $`\eta\lt\omega_1`$ choose such a $`\xi>\max(\eta,\max a)`$, and choose $`g(\eta)`$ from its stationary color-$`k`$ fiber. In particular $`C_{g(\eta)}(d)=\xi\lt g(\eta)`$.

Intersect $`A`$ with the club of limit ordinals $`\beta`$ closed under $`g`$. For any $`\eta\lt\beta`$, set $`\alpha=g(\eta)\lt\beta`$. Its first $`d`$ points are exactly $`b`$, and its next point exceeds both $`\eta`$ and every point of the fixed zero-side prefix $`a=C_\beta[n]`$. The rest of its one-side prefix is still higher. This proves the displayed type identity and the cofinality assertion simultaneously for every bound at the same $`\beta`$.

For sharpness, suppose $`d>0`$. If the earlier ladder plays the one role, its point of index $`d-1`$ precedes the last zero, namely $`C_\beta(n-1)`$. If it plays the zero role, even its final prefix point precedes the terminal one, again $`C_\beta(n-1)`$. Thus that fixed ordinal below $`\beta`$ bounds all witnesses at the previous coordinate, including when their roles may vary. For $`d=0`$ there is no earlier coordinate to test.

## Consequence for guessing

Under the proper forcing axiom restricted to posets of size $`\aleph_1`$, a type family admits guessing with the role-exchange tail requirement **if and only if** its depths and lower reaches are bounded. The equivalence also holds in every countable forcing extension of such a model, including for type families first appearing in the extension. Indeed the present positive theorem is in ZFC, and the role-exchange tail requirement implies ordinary guessing by forgetting the tail. The published negative result for ordinary guessing therefore gives necessity. For the forward chronological orientation the distinct width cutoff is proved in the [oriented tail theorem](TAIL-COORDINATE.md). The family $`01\,0^{k+1}1^{k+1}`$ has unbounded width with $`d_k=r_k=1`$, so it separates the two conventions in those models. This is a supplement to the existing solution of Question 6.1. [Countable-forcing preservation](COUNTABLE-FORCING.md) · [Original Questions 6.1 and 6.2](https://arxiv.org/pdf/2312.01828#page=15)

## The literal tail clause for arbitrary supplied orientations

Theorem 2.7 specifies the word with the earlier ladder first. For an arbitrary supplied family, let $`F`$ contain the indices of words ending in 1. Compute $`d_k,r_k`$ after normalization for every color. In the same forcing-axiom models, including their countable forcing extensions, the exact criterion for the literal tail clause is **bounded widths on $`F`$ and bounded depths and lower reaches outside $`F`$**. A bound on an empty class is vacuous.

Sufficiency holds in ZFC. Choose $`L`$ strictly above the indicated bounds. Again stationarily many vertices of some color $`k`$ have the $`L`$ model heights as their first points. If $`k\notin F`$, the construction above puts the earlier ladder in the one role of the normalized word. Thus the literal type with the earlier ladder first is the supplied word ending in zero.

If $`k\in F`$, its width $`n`$ is less than $`L`$. Use the same downward induction for tuples of length $`n+1`$ in place of $`r+1`$. The initial stationary fiber exists because the common prefix includes $`\delta_n`$. Choose all $`n`$ earlier-ladder prefix coordinates in their prescribed gaps among the fixed later-ladder coordinates $`\delta_0,\ldots,\delta_{n-1}`$. Maintain the next-coordinate assertion after each choice, using the model at the upper end of each gap as above. Every zero has a following one because the supplied word ends in 1. After choosing the $`n`$ earlier prefix points, the induction guarantees unboundedly many next coordinates $`\xi`$, each realized on a stationary set of color $`k`$. For each bound $`\eta`$, first choose an available $`\xi>\eta`$, then choose $`g(\eta)`$ in its stationary fiber so that $`C_{g(\eta)}(n)=\xi>\eta`$. Intersect the original stationary fiber of the $`L`$ heights with the club of closure points of this function. Every resulting later vertex has witnesses with its literal supplied type and with $`C_\alpha(n)>\eta`$ for every $`\eta\lt\beta`$. Here all the earlier prefix points are below $`C_\beta(n-1)`$, so index $`n`$ is optimal.

For necessity, if widths are unbounded on $`F`$, enumerate an infinite subfamily there with unbounded widths. Apply the [forward oriented obstruction](TAIL-COORDINATE.md) to any proposed ladder system on that subfamily, then relabel its countercoloring by the original color indices. If depth or lower reach is unbounded outside $`F`$, use the failure of ordinary guessing on an unbounded subfamily of those colors and relabel in the same way.

If a supplied color asks for cofinality specifically at index $`j_k`$, the same bounds suffice as long as $`j_k\ge n_k`$ on $`F`$ and $`j_k\ge d_k`$ outside $`F`$. These pointwise restrictions are necessary already in ZFC by taking a constant coloring at a violating index and bounding its earlier coordinate by the last later-ladder prefix point. For the variant permitting either assignment at every color the corresponding restriction is $`j_k\ge d_k`$.
