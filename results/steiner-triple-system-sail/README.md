# The Steiner triple system sail problem

Every red–blue coloring of the blocks of a sufficiently large Steiner triple system contains a monochromatic sail. At least $1/49-o(1)$ of all sails have one color. This answers Gyárfás’s Question 2.8 by counting the colors between a point and a block, then comparing the parities between two disjoint blocks. The draft is awaiting independent review.
