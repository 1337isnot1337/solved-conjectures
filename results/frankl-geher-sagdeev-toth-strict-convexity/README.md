# Frankl–Gehér–Sagdeev–Tóth’s strictly convex coloring conjecture

**Lean status:** none.

There is a strictly convex norm on real five-space and a fixed countably infinite set such that every coloring with countably infinitely many colors has an isometric copy missing a color. This does not resolve the separate two-color question.

A family of independent choices on arcs forces a whole arc to be monochromatic. For each arc a second copy of the same configuration has a tail in that arc, so this copy uses only finitely many colors.

[Question following Theorem 2.1](https://doi.org/10.1007/s00454-024-00702-5) · [Proof](PROOF.md) · [Independent review and sources](AUDIT.md) · [Tracking issue #856](https://github.com/1337isnot1337/solved-conjectures/issues/856)

Run `python3 results/frankl-geher-sagdeev-toth-strict-convexity/verify_dim5.py` from the repository root. The earlier [strictly convex plane proof](FINITE-SPHERES.md) and [polynomial-norm proof](POLYNOMIAL-NORMS.md) of Cinna Davis remain valid in their stated scopes.
