# Frankl–Gehér–Sagdeev–Tóth’s strictly convex coloring conjecture

**Lean status:** none.

Every isometric copy of a prescribed infinite configuration can receive every color infinitely often in a single countable coloring of a strictly convex normed plane, or of a polynomial normed space in any finite dimension.

Here a polynomial norm means that some positive integer power of the norm is a polynomial. The conjecture for arbitrary strictly convex norms in higher dimensions remains open. Independent mathematical review of both arguments is pending. [Frankl, Gehér, Sagdeev and Tóth, following Theorem 2.1](https://doi.org/10.1007/s00454-024-00702-5)
