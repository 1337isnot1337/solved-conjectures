# Burstein’s descent-top shape-Wilf conjecture

**Disproved.** For every suffix permutation, there is a Ferrers board on which the two conjectured pattern classes have different descent-top distributions. This refutes Conjecture 16 and its equivalent ascent-bottom formulation in Conjecture 17 for nonempty suffixes.

The separating fiber consists of traversals whose first block increases. Its two counts differ by exactly one. The ordinary square-board conjecture is not addressed.
