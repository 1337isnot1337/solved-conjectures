# Gravgaard–Lee’s mixed Lüroth sumset conjecture

**Proved.** Proves that the mixed bounded-digit Lüroth sum represents every residue modulo one, with an explicit ordinary interval in the sum. A seven-state graph-directed certificate needs only fifteen rational interval containments.
