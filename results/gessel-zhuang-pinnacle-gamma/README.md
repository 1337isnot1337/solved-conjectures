# Gessel–Zhuang’s pinnacle-set gamma-positivity conjecture

**Proved.** For every permutation length and every specified pinnacle set, the inverse-descent polynomial is gamma-positive with the center stated in Conjecture 7.3. Summation gives Conjecture 7.2; the different inverse-peak conjecture 7.1 is not claimed.

The proof refines the pinnacle height path by the last inserted value’s location among its gaps. Each fixed path then gives a real-rooted, symmetric polynomial.
