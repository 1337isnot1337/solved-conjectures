# Chappelon–Ramírez Alfonsín–Stamate’s leaf-type conjecture

**Disproved.** An infinite family of numerical semigroup leaves exceeds the proposed half-genus type bound. Moreover the maximum type at every sufficiently large genus is two thirds of the genus minus a deficit of square-root order.

The lower bound comes from an explicit interval additive basis. The upper bound counts possible pairs of offsets that must represent remaining gaps; this forces the square-root deficit.
