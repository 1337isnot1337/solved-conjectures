# Multicolor Steiner triple system sail problem

**Lean status:** none.

For every fixed number of colors, almost every Steiner triple system has a positive density of monochromatic sails in every vertex subset of fixed positive density, simultaneously for all block colorings.

A deterministic bound also gives nearly spanning disjoint sail packings in systems with a sufficiently small independence number. The arbitrary-host multicolor question remains open. The previously settled two-color question has a [separate proof](../steiner-triple-system-sail/PROOF.md). [Granath, Gyárfás, Hardee, Watson and Wu](https://users.renyi.hu/~gyarfas/Cikkek/182_jcd1.pdf)
