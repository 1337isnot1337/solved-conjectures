# Nuttall's conjecture

Complete proposed proof of Conjecture 1 in §4.5: for each finite order r, every sufficiently high repeated-tail cumulant of the Riemann theta kernel is strictly reverse regular through order r on the entire nonnegative node domain. The separate RH-equivalent Toeplitz positivity problem remains unresolved.

**Status:** complete proposed result for the stated scope; internally reviewed, with [partial Lean verification](FORMALIZATION.md), not externally refereed. Prior-art findings are bounded; exclusive priority is not claimed.
