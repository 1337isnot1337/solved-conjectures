# Blitvić–Kammoun–Steingrímsson packing cutoff question

**Lean status:** none.

For every $`L\ge2`$, two patterns of length $`3L+1`$ at the same overlap have identical packing counts through $`L`$ occurrences and different counts at $`L+1`$. This rules out every absolute cutoff. Whether a small cutoff depending on pattern length suffices remains open. [Part I, §7, item 8](https://arxiv.org/pdf/2610.29846v1)
