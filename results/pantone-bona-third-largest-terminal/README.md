# Pantone–Bóna’s third-largest-terminal asymptotic conjecture

**Proved.** The number of permutations avoiding `12345`, `12354`, `13452`, and `23451` is asymptotic to $9^n/n^3$ times exactly $9\sqrt3/(16\pi)$.

This is Conjecture 6.2 in the original paper. A shape-location identity for Robinson–Schensted and a shared band for longer suffixes isolate the one-entry tail as the entire leading contribution. The same method covers the third-largest-terminal family at every fixed pattern length at least five.
