# Heim–Neuhauser’s plane-partition polynomization conjecture

**Proved.** The consecutive nth roots of the plane-partition polynomials strictly decrease for every $n\ge1$ when $x>5$, and for every $n\ge6$ when $x\ge1$. These are both clauses of [Conjecture 1 of *Polynomization of Sun’s conjecture*](https://doi.org/10.1007/s11139-026-01435-0).
