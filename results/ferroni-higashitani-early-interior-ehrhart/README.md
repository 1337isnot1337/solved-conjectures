# Ferroni–Higashitani’s first-three interior Ehrhart question

**Answered yes.** There is an explicit family of lattice polytopes with the integer decomposition property whose first three interior lattice-point counts fail log-concavity. This answers Question 5.12(a), which remains distinct from the previously settled unrestricted-index part (b).

The construction refines a lattice in six cosets, preserving integer decomposition and moving the relevant interior counts to explicit box sums. It yields a 170-dimensional witness and arbitrarily large failure ratios.
