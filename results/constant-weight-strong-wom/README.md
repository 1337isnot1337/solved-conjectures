# En Gad–Yaakobi–Jiang–Bruck constant-weight strong WOM coding problem

A deterministic write-once memory encoder attains the known capacity with exact output weight for every state and message. Its decoder reads the written subset alone. Code construction, encoding and decoding take polynomial time. The full candidate proof is on the research branch pending independent review.
