# Oriented general position spectrum nonconstancy conjecture

**Proved.** Every connected finite graph on at least three vertices admits two orientations with different directed general position numbers. In fact, among all finite graphs, exactly the disjoint unions of edges and isolated vertices have a singleton spectrum.

This settles [Conjecture 4.3 of Chandran–Di Stefano–Erskine–Haritha–Thomas–Tuite](https://arxiv.org/html/2604.15909v1#S4.SS1). A greedy path partition yields a low orientation and an induced endpoint set that can be enlarged by one vertex in a high orientation. The proof does not decide whether intermediate values are attained.
