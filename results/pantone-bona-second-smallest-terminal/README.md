# Pantone–Bóna’s second-smallest-terminal asymptotic conjecture

**Proved.** The number of permutations avoiding `12345`, `12354`, `12453`, and `23451` is asymptotic to $9^n/n^3$ times exactly $9\sqrt3/(16\pi)$.

This is Conjecture 6.1, the $A_{5,2}$ case. A shared interval of admissible values is forced to decrease, which makes its contribution to long tails small enough to control. As in the distinct third-largest-terminal case, one-entry tails supply the whole leading term.
