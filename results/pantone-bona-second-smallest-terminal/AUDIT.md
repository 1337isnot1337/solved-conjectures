# Source and review

The exact target is [Conjecture 6.1 in Bóna–Pantone](https://arxiv.org/html/2103.06918v2#S6.SS1), for the $A_{5,2}$ basis rather than the different $A_{5,3}$ basis. The source already proves the exponential base $9$ and introduces the rank split. It cites an existing Callan–Mansour generating function for the $A_{4,1}$ class used in this proof. The sharper $A_{5,2}$ equivalence, including the leading constant, does not follow from the exponential estimate alone. A targeted Nov. 24, 2026 search by original source, exact forbidden set, conjecture number, and asymptotic scale found no earlier resolution of the stated equivalence. No exclusive priority is claimed.

Independent audit:

- The companion [tableau survival](../pantone-bona-second-largest-terminal/PROOF.md) argument uses only the unconditioned probability of the allowed extracted coordinates and uniform survival/endpoint bounds conditional on those coordinates. Restricting the first $g$ row steps to the first $b$ rows replaces the probability by $(b/3)^g$ with the same polynomial loss. By [fixed-shape location invariance](../pantone-bona-third-largest-terminal/PROOF.md), that conclusion applies to every consecutive value interval, not only the first one.
- If a shared band value preceded the second entry of a fixed witness, it could replace the witness’s first entry and violate the maximal lower endpoint. Thus it comes after this witness’s first entry. An increasing pair of band values then combines with that first entry to make a witness whose second entry violates the minimal upper endpoint. This establishes the needed decreasing-band restriction, stronger than merely lacking a triple.
- The post-maximum tail avoids $A_{4,1}$ because the first witness entry lies below every value of that tail and can be prepended to any offending subsequence. The previously published growth rate $2+\sqrt5<5$ is sufficient, not a guessed exponential rate.
- Interpolating the two upper bounds on viability gives a band-placement generating function with a radius above $5/9$. This makes the long-tail series lower order, leaving $n f_{n-1}$ and the stated constant.

[verify.py](verify.py) checks literal counts, the single-entry tail formula, and both the decreasing-band and tail-avoidance implications through length eight. It does not form part of the asymptotic proof. Internally reviewed; not Lean-formalized or externally refereed.
