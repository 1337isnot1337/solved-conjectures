# Route prescribed parity directly through the odd clique

This is an alternative proof of the odd-clique case of [Chen's prescribed-parity problem #1012](https://github.com/1337isnot1337/solved-conjectures/issues/1012). It uses the same rooted-grid construction as [the odd-brick case](ODD-BRICK-ROUTING.md), rather than invoking a separate parity-routing theorem.

Fix the target \(t\) and let \(q=18t\). Take \(g\ge q+2\) and \(n>q(g+2q)\), as in the odd-brick case. Suppose the eligible-path tangle has an aligned odd \(K_p\)-expansion, with \(p\ge 2n^2\). Take the free set \(X\) of terminals of \(9t\) complete demands. The order of the clique tangle is \(\lceil 2p/3\rceil>q\).

Color each branch tree properly with bits in \(\mathbb Z_2\). For the chosen connector \(uv\) between branch trees \(i,j\), let \(b_{ij}=1+\gamma_i(u)+\gamma_j(v)\). The oddness of every expansion triangle says that \(b_{ij}+b_{jk}+b_{ki}=1\). Keep the coloring of branch 1 fixed and flip the coloring of each branch \(i\ne 1\) by \(b_{1i}+1\). The resulting connector bits are all 1: this is immediate for those incident to 1, and follows from the triangle with 1 for every other connector.

Assign one distinct base branch tree to each vertex of the square \(n\)-grid. Use a single connector for every vertical edge and for each horizontal edge in an odd row. For each horizontal edge in an even row, use two connectors through its own additional branch tree. The latter route uses the unique internal tree path between the connector endpoints in that auxiliary branch, possibly of length zero. The number of auxiliary branches is \(\lfloor n/2\rfloor(n-1)<n^2\). These routes meet only in their designated base trees. To put them into the usual grid model, absorb the auxiliary portion and the first connector of each two-connector route into its first base branch tree, leaving its final connector as the grid model edge. Every enlarged grid cell is a tree, since it is the original base tree with disjoint trees attached by single edges.

Every model unit face lifts to an odd cycle. Its parity is obtained by summing the connector bits of its expanded closed walk in the clique model: proper-tree endpoint colors telescope around the walk. There are two vertical connectors, one connector on the odd-row horizontal edge, and two on the even-row horizontal edge. Thus the sum is \(1\bmod 2\). This statement does not depend on the choice of ports or on the internal lengths of the branch trees.

For each separation \((A,B)\) of order \(<q\) with \(X\subseteq V(A)\), no entire model row lies in \(B\). Otherwise, that row contains \(n>q\) different base branch trees, so at least one of them avoids the separator. It lies in \(B\setminus A\). By adjacency of all branch trees, \(B\) intersects every clique branch tree. Therefore the clique tangle, and hence the eligible-path tangle, orients this separation towards \(B\). This contradicts freeness of \(X\).

Apply Marx–Seymour–Wollan Statement 2.1 to this particular grid model. As in the odd-brick proof, it preserves the model connectors and trees and adds roots on distinct rows of the first column. The selected subgrid still has all unit faces odd. The private-face switches in the odd-brick proof now route \(t\) of the given whole pairs with the required parities and vertex congestion at most two. This substitutes for the only use of Kawarabayashi–Wollan–Reed in the complete proof draft; it does not claim the integral packing supplied by their separate result.
