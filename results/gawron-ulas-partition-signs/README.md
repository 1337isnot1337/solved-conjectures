# Gawron–Ulas’s partition-sign nonperiodicity conjecture

**Proved.** Oblique root-of-unity growth proves each sign occurs infinitely often on every index progression, for all coprime odd permitted-part steps at least three.

**Lean status:** complete for the original Conjecture 4.3. The Lean proof rules out eventual periodicity for parts congruent to 1 modulo 3; it does not formalize the stronger progression-by-progression claims.
