## Formalization

The finite case is checked for every finite abelian group generated by the two
differences. `Motzkin.finite_two_difference_theorem` supplies both an attaining
independent set and an attaining circle character. The normalized counting
density equals the best character value.

`Motzkin.finite_density_eq_characterValue` states the equality for the actual
measurable-set and continuous-character suprema. The general lower bound
`Motzkin.characterValue_le_density` is also checked. These statements are in
[`MotzkinFiniteTheorem.lean`](../../lean/Conjectures/MotzkinFiniteTheorem.lean)
and [`MotzkinDensity.lean`](../../lean/Conjectures/MotzkinDensity.lean).

The eight new modules passed source checks; all 115 Motzkin theorem declarations
passed the standard-axiom audit. Independent kernel replay passed for their
entire 12-module local project closure. The arbitrary compact-group upper
bound, the later evaluations and cyclic criteria, and the exact algorithmic
complexity claims remain unfinished. See
[the status report](../../docs/lean-status.md) for the precise scope.
