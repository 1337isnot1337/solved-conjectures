# Barrett–Evans–Hall–Kempton’s spectrally extreme graph conjecture

**Status: proved.** For every weighted graph on at least five vertices, with edge weights between zero and one, let $`x`$ and $`y`$ be the algebraic connectivities of the graph and its weighted complement. Then $`x+y-2xy/n\ge1`$. When both connectivities are less than one, equality holds exactly for the authors’ $`SE(s)`$ graphs.

The proof reduces arbitrary real weights to endpoints of a one-edge interpolation. It uses an analytic estimate for all orders at least 36 and reproducible integer certificates below that threshold. This is a computer-assisted proof of the full conjecture, not a finite-order confirmation. No Lean verification or external refereeing is claimed.
