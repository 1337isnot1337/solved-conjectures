# Erdős’s primitive sequence problem

**Screened.** Research note. [Pinned entry](https://github.com/1337isnot1337/solved-conjectures/blob/d676ae52308b71d65beac020fb2a1a591a9e6d34/docs/research-results/erdos-primitive-sequence/README.md).

## Recorded scope

The source describes the result as follows.

> The construction and proof establish the required peaks for every prescribed exponent set with at most $K H^\sigma$ points in each interval of length $H\ge1$, for any fixed $\sigma<1$ with $\sigma>0$. In particular this includes all $n_i=\lfloor i^\alpha\rfloor$ with $\alpha>1$. The construction uses one primitive set for all requested scales. The full-counting-dimension extension also allows every uniformly bounded interval count $N_E(H)\ll H\exp(-c(\log H)^a)$ for $1/2<a<1$. For example, it covers $n_i=\lfloor i\exp((\log i)^a)\rfloor$, for which no upper bound $N_E(H)\ll H^\sigma$ with fixed $\sigma<1$ holds.
