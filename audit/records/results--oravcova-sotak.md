# Oravcová–Soták conjecture for five to eight distances

**Screened.** Ranked. Rank 162 on the original main table, marker 🟢. [Pinned entry](https://github.com/1337isnot1337/solved-conjectures/blob/d676ae52308b71d65beac020fb2a1a591a9e6d34/results/oravcova-sotak/README.md).

## Recorded scope

The source describes the result as follows.

> For a primitive distance set of size `k` in `{5,6,7,8}`, the chromatic number is `k+1` exactly for `{1,...,k-1,ks}`, `{1,2,3,5,8}`, `{1,4,5,6,7}` and `{1,2,3,4,5,7,12}`. The classification is conditional on the repository's five- to eight-speed spectrum results. **Contributed by @aadrianvv.**
