# Erdős essential-component conjecture

**Screened.** Catalogue note. [Pinned entry](https://github.com/1337isnot1337/solved-conjectures/blob/d676ae52308b71d65beac020fb2a1a591a9e6d34/docs/erdos-essential-component-research.md).

## Recorded scope

The source describes the result as follows.

> Write $S_q$ for the image of $A\cap[0,q]$ in $\mathbb Z/q\mathbb Z$ and let ```math g_k=\min_{X\subseteq\mathbb Z/2^k\mathbb Z,\ |X|=2^{k-1}}   \frac{|X+S_{2^k}|-|X|}{2^k}. ``` **Theorem.** The conjecture is equivalent to $\liminf_{k\to\infty}g_k\gt0$. If the liminf is zero, then for every $0\lt\alpha\lt1$ there is a set $B$ for which both $\sigma(B)$ and $\sigma(A+(B\cup\{0\}))$ equal $\alpha$. In that construction both lower asymptotic densities also equal $\alpha$.
