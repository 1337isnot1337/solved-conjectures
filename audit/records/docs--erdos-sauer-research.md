# Erdős–Sauer conjecture

**Screened.** Catalogue note. [Pinned entry](https://github.com/1337isnot1337/solved-conjectures/blob/d676ae52308b71d65beac020fb2a1a591a9e6d34/docs/erdos-sauer-research.md).

## Recorded scope

The source describes the result as follows.

> **Theorem.** Fix $r\ge3$. Define $\gamma_3=20/7$ and $\gamma_r=r-1$ for $r\ge4$. Uniformly over $n$-vertex $r$-graphs, ```math D(G)\ \le\ \operatorname{ex}_r(n,K)-(r-\gamma_r)\nu(G)+o(n^r). ``` Consequently the maximum decomposition number is $\operatorname{ex}_r(n,K)+o(n^r)$. Every sequence attaining that value to within $o(n^r)$ is within $o(n^r)$ edge deletions of a $K$-free sequence with $\operatorname{ex}_r(n,K)-o(n^r)$ edges. For any fixed $\epsilon\gt0$, the exact conjectured bound holds for sufficiently large $n$ if $|E(G)|\ge\operatorname{ex}_r(n,K)+\epsilon n^r$.
