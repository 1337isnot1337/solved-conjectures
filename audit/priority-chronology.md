# Which proof came first?

All seven withdrawals have a dated outside proof of the exact catalogue target before the earliest evidence I found that the project had obtained that result. The comparison counts a dated research proof, including work on another branch or before public release. A later independent solution leaves an earlier project result eligible. A reservation establishes when work started. A record with the theorem and its argument can establish when the researcher already had it.

## The November 21 weighted-bond work

The project really was working on González D’León and Wachs before Omega. On November 21, issue 202 and the accompanying commit documented tests of Conjectures 6.21 and 7.3, and a counterexample to 4.13(2) that was already public. The code computes the source recurrence on an input graph. It can evaluate individual complete graphs. Question 7.1 asks for a formula across all complete graphs and all finite numbers of equal colors greater than two. The November 21 notes and code contain no such evaluation. [November 21 issue](https://github.com/1337isnot1337/solved-conjectures/issues/202) · [Research notes](https://github.com/1337isnot1337/solved-conjectures/blob/1fa89960d313f318b5fcd89723bf72f8f05054c7/research/gonzalez-dleon-wachs-screening/RESEARCH.md) · [Recurrence implementation](https://github.com/1337isnot1337/solved-conjectures/blob/1fa89960d313f318b5fcd89723bf72f8f05054c7/research/gonzalez-dleon-wachs-screening/screen.py) · [Question 7.1](https://arxiv.org/html/2608.08692v2#S7.Thmtheorem1).

Omega's proof commit is dated November 23 at 16:44:49. The proof PR opened at 19:05:56 and merged at 19:39:18 that day. The project's November 24 issue describes the Laguerre and Gamma-moment result at 14:02:41, **18 hours, 23 minutes and 23 seconds after the outside merge**. This compares the later outside milestone with the earlier project issue. The supplement on `main` preserves the Gamma-moment representation, strict coefficient log-concavity, and real-zero count. [Omega proof commit](https://github.com/the-omega-institute/trureturing/commit/c2b6eb6394095a488aa375334816a36295043122) · [Omega PR](https://github.com/the-omega-institute/trureturing/pull/33676) · [Project issue](https://github.com/1337isnot1337/solved-conjectures/issues/482) · [Retained supplement](https://github.com/1337isnot1337/solved-conjectures/tree/d5dfad5148d8e88bdea39fe9f475beecc8f8c01b/docs/weighted-complete-graph-moments).
