# Web fonts

The site self-hosts the following SIL Open Font License fonts from the Google
Fonts repository. The license files are included in this directory.

- Newsreader variable roman and italic, by the Newsreader Project Authors:
  <https://github.com/google/fonts/tree/main/ofl/newsreader>
- Geist variable, by the Geist Project Authors:
  <https://github.com/google/fonts/tree/main/ofl/geist>

The WOFF2 files retain variable weight axes. They are subsets of the upstream
TrueType fonts, produced with FontTools. The subsets include Unicode ranges
U+0000–024F, U+1E00–1EFF, and U+2000–22FF. This includes extended Latin names and
the punctuation used by the catalogue. Mathematical equations use native MathML
with the browser's mathematical font.

No third-party font request is made by the published pages.
