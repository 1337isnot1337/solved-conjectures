# Source, verification and independent review

The theorem first established here excludes every competitor with exactly one extra leaf for a generic subdivision of any fixed reduced tree. It relies on the repository's minimum-leaf theorem, the marked one-extra-leaf contradiction and the bounded-surplus reduction. The last result decided that a finite test exists but ran the one-extra-leaf exclusion only for targets with a single high-degree vertex. Here all degree patterns are covered. This is a supplement to the existing Stanley project. His 1995 question concerns the chromatic symmetric functions of all finite trees. Larger leaf surpluses and exceptional target lengths remain outside the new theorem. [Stanley](https://math.mit.edu/`rstan/pubs/pubfiles/100.pdf) · [Original research issue](https://github.com/1337isnot1337/solved-conjectures/issues/315) · [Earlier finite reduction](LEAF-SURPLUS-KERNEL.md)

The bounded prior-work search compared the theorem with both repository branches, the earlier minimum-leaf and finite-kernel results, generic reconstruction papers on metric trees, and reconstruction from weighted path multisets and leaf-distance data. The prior weighted-path algorithm takes a supplied tree topology. The positive metric results using local distance profiles have access to a family of distributions. The new comparison has only a single global distance histogram and allows arbitrary rival topologies. No prior source found in this search contains the one-extra-leaf theorem. [Bartha, Burcsi and Lipták](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.CPM.2016.10) · [Mémoli and Needham](https://arxiv.org/abs/1810.09646) · [Martin, Morin and Wagner](https://arxiv.org/abs/math/0609339) · [Prior project source comparison](ROBUST-HUB-SOURCES.md)

The coordinating researcher in the WadeDavis session derived the four-coordinate row basis, the stronger terminal count, the joint degree and rank enumeration, and the two case contradictions. The researcher who established the degree-free kernel independently checked the path telescoping construction, cancellation budget and both terminal contradictions. They wrote a second enumeration using full positive hub weights, a different global cutoff of 155 rival leaves and an independent loop order. Both implementations leave precisely the same degree profile and rank pairs. A third researcher independently checked the fixed-chain argument in the internal-rank-one case, including the four disjoint outward branches.

The primary enumerator uses integer arithmetic and the Python standard library. Run `python3 verify_one_extra_leaf.py` in this directory. It tests all integer partitions in the proved degree bounds and asserts equality of the complete output with the two terminal records. A trivalent hub contributes zero to a recorded profile and is recovered from the leaf count in each comparison. The reviewed final argument then excludes each terminal record. The status is an internally reviewed computer-assisted written proof without Lean verification or external refereeing. [Theorem](ONE-EXTRA-LEAF.md) · [Exhaustive verifier](verify_one_extra_leaf.py)
