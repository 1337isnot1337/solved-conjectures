# Gaussian cold spots of high-rank type-A root lattices

For every fixed lower cutoff $`a>0`$, there is a rank threshold above which the deep holes of the root lattice $`A_n`$ are **exactly** the global minimizers at **every** Gaussian scale $`\alpha\ge a`$. In the standard realization by zero-sum integer vectors with $`N=n+1`$ coordinates, all coordinate residues of a minimizer equal $`k/N`$ modulo one, with $`k`$ nearest to $`N/2`$. This gives one class for even $`N`$ and two for odd $`N`$. [Half-line theorem and proof](HALF-LINE.md) · [Compact-interval proof](PROOF.md)

Bachoc, Moustrou, Vallentin and Zimmermann proved stability for each fixed root lattice at sufficiently large scales. Taking the finite maximum of their thresholds in the remaining low ranks gives a single sufficiently large scale above which the minimizer classification holds in **every rank**. Both thresholds in this partial result are existential, and the root lengths have squared norm two. The all-scale question for every fixed root rank remains open in general, as does control of arbitrary scales tending to zero with the rank. The dual $`A_n^*`$ has its own all-rank, all-parameter theorem. [Source question, §1.6](https://arxiv.org/html/2502.08819v2#S1.SS6) · [Dual type-A theorem](../dual-a-universal-cold-spots/README.md) · [Tracking issue #967](https://github.com/1337isnot1337/solved-conjectures/issues/967)

Two Python scripts use exact arithmetic and explicit tail bounds for finite examples. The proof is internally reviewed, with no Lean formalization or external referee report.
