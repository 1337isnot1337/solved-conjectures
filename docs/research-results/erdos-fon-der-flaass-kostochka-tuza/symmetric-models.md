# Limits for families specified by finitely many vertex classes

Fix the local sample size $p\ge3$ and a number $d$ of vertex classes. A model consists of Presburger formulas describing allowed parameter tuples and allowed edge occupancies $a=(a_1,\ldots,a_d)$ in classes of sizes $n_1,\ldots,n_d$. These formulas use integer addition, order, constants and quantifiers. Fixed congruences are allowed. Every actual subset having an allowed occupancy is an edge, and every edge has positive rank $r=\sum_i a_i$. The class sizes and any fixed number of other integer parameters can vary. This includes complete families, independent choices within classes, and the two-class parity construction of Fon-Der-Flaass, Kostochka and Woodall. In the latter example the model admits every occupancy with an odd number of points in a designated class. [1999 paper, Theorem 1](https://kostochk.web.illinois.edu/docs/2000/dm1999FlaWoo.pdf)

Let $g(R)$ be the largest transversal number among members of the model having rank *at most* $R$ and satisfying the local condition. Use $g(R)=0$ if there are none. We take the local condition on at most $p$ edges. It agrees with the source definition as soon as there are at least $p$ edges.

**Theorem.** There is a rational $c\ge0$ such that $g(R)=cR+O(1)$, and the error is eventually periodic. This proves the existence of a slope for the upper envelope of each such model. For an exact-rank maximum the same conclusion holds when that maximum is eventually nondecreasing, for example when the model can pad one rank at a time while preserving the transversal number and the local condition.

**Proof.** The local condition and the transversal number can both be expressed in Presburger arithmetic with $p,d$ fixed. For the global condition, a set with $t_i$ points in each class fails to be a transversal precisely when there is some allowed occupancy $a$ with $a_i\le n_i-t_i$ for every $i$. Quantify over $0\le t_i\le n_i$ and minimize their sum subject to being a transversal.

For the local condition, use integer variables $x_{i,S}$ for $i\le d$ and $S\subseteq[p]$. They count the points of class $i$ belonging to exactly the edges with indices in $S$. Their class sums must be $n_i$ and their marginal sums $\sum_{S\ni j}x_{i,S}$ must give an allowed occupancy vector for every edge $j$. These constraints suffice to realize the whole tuple by assigning the indicated numbers of points in each class. It has no transversal of size at most two precisely when for every $S,T$ with $S\cup T=[p]$, the total count of $S$ or the total count of $T$ is zero. Allowing $S=T=[p]$ correctly excludes a single common point. Repeated edges are allowed, so tuples of length $p$ test all nonempty subfamilies of size at most $p$. Exclude the resulting finite quantified obstruction.

For any nonempty positive-rank family with this local condition, $\tau\le 2r$: three disjoint edges are impossible, and the union of any maximal matching is a transversal. Thus the set of attainable transversal numbers at rank at most $R$ is bounded by $2R$. Selecting its maximum gives a Presburger definition of the graph of $g$.

By the Ginsburg–Spanier characterization this graph is a finite union of linear sets in $\mathbb N^2$. Every nontrivial period vector in a linear component of a function graph has positive first coordinate. Any two period vectors of that component must have the same slope: otherwise common-multiple first coordinates give different second coordinates. The first coordinates in that component eventually form arithmetic progressions with modulus the greatest common divisor of its positive periods (the elementary numerical-semigroup property). Thus beyond a finite prefix the function is affine and rational on each residue class modulo a common period. On adjacent residue classes, monotonicity forces their slopes to be in nondecreasing order, including the wraparound to the first residue class. All slopes are consequently equal, and the finitely many intercepts give the periodic error. [Ginsburg–Spanier, *Semigroups, Presburger formulas, and languages*](https://msp.org/pjm/1966/16-2/pjm-v16-n2-s.pdf)

The unrestricted extremum permits an unbounded number of classes and arbitrary collections of occupancy profiles. The proof supplies one constant per fixed model. An approximation theorem that preserves the local condition and loses $o(r)$ in the transversal number would be needed to pass from these models to all hypergraphs.
