# Li44 original hosted verification evidence

The original [run 44599210697, job 135825706963](https://github.com/1337isnot1337/solved-conjectures/actions/runs/44599210697/job/135825706963)
passed all 44 fresh strict source checks, all 25 literal contracts, the complete
owned-name axiom audit, and 44 exact singleton stock-kernel replays. The audit
contains 1,247 declarations, 932 theorems, 95 private names and 71 required
theorem endpoints. Only `propext`, `Classical.choice`, and `Quot.sound` occur
as transitive axioms.

`artifact/` preserves all 228 UTF-8 members byte for byte, including the
original receipt, all source snapshots, logs, process profiles, generated
literal/audit sources and declaration inventory. `controls/` preserves the
13 original verification controls. The original artifact contained another
44 binary `.olean` files; their exact hashes remain in `manifest.json`,
`archive-members.json`, and the original receipt. They are not embedded here.
The original archive is artifact `14568527194`; a byte-identical copy is also
inside backup artifact `14569584489` from the later raw audit.

No receipt or proof source was rewritten to produce this preservation copy.
Absolute execution paths in historical receipts are retained. The relative
paths in `manifest.json` identify the copies stored in this repository.
The authenticator and independent root review bind the source/object/import
hashes, commands, logs, profiles, original git controls and compiler hashes.

The selected-name audit and stock checker do not by themselves establish
coverage of differing serialized theorem bodies. The completed
[raw-occurrence supplement](../li-hosted44-raw-44606051622/README.md) checks
that remaining scope against exactly these original objects.
