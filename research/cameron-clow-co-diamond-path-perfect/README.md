# Cameron–Clow’s co-diamond path-perfect conjecture

Every co-diamond-free graph is path-perfect. Every induced
subgraph has a path whose vertex span preserves its full
chromatic number. Color criticality forces enough connectivity
to apply the Chvátal–Erdős theorem. An alternative proof uses
a matching of connector labels to gaps between paths.

This is the entire co-diamond-free assertion raised by
Cameron and Clow. It does not settle their separate
two-disjoint-edges assertion or the unrestricted
Erdős–Hajnal odd-cycle problem.
