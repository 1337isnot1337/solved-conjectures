# Finite common neighborhoods in prescribed uncountable subsets

This research reduction extends Cinna Davis’s [basic-block condition](REDUCTIONS.md) for [the ordinal pentagon problem](https://github.com/1337isnot1337/solved-conjectures/issues/984). Codex in the WadeDavis research session obtained the localization below and checked it against the current research notes. The original five-cycle question remains open.

Set $`\kappa=\omega_1`$ and $`\alpha=\kappa^{\omega+1}`$. Partition the ordinal into consecutive blocks $`B_i`$ of type $`\kappa`$ indexed by $`i\lt\alpha`$, using $`\kappa\cdot\alpha=\alpha`$. Let a graph on this ordinal have no independent subset of inherited type $`\alpha`$.

**Block localization.** Fix a positive integer $`k`$. Outside a set of block indices of order type strictly below $`\alpha`$, every uncountable subset $`S\subseteq B_i`$ contains uncountably many common neighbors of some $`k`$ distinct vertices. The witnesses may depend on the subset. The assertion also applies inside an induced graph on any full-index family of blocks each thinned to an uncountable subset, with all witnesses chosen inside that induced graph.

Suppose instead that failing indices form a set of type $`\alpha`$. For each failing block choose an uncountable subset $`S_i`$ that contains no such common neighborhood. Choose a finite witness set $`W_i`$ of largest possible cardinality whose common neighbors in $`S_i`$ form an uncountable set $`R_i`$. The empty witness set is allowed, with common neighborhood equal to $`S_i`$. Maximal cardinality exists and is less than $`k`$. For every vertex $`v\notin W_i`$, the set $`R_i\cap N(v)`$ is countable, since otherwise $`W_i\cup\{v\}`$ would be larger.

Use $`k`$ colors on the vertices, putting uncountably many vertices of every color in each $`R_i`$. This is possible by partitioning the disjoint sets $`R_i`$ separately and extending the coloring to all other vertices. Each $`W_i`$ omits a color. Finite indivisibility of $`\alpha`$ yields a full-type set of failing indices with a common omitted color. From each retained $`R_i`$ require $`\kappa`$ vertices of that color. There are $`\kappa`$ requirements altogether. Enumerate them in type $`\kappa`$. At any stage the previously selected vertices are outside the current $`W_i`$ and rule out only a countable union of countable neighborhoods and previously chosen points. A new nonadjacent vertex is always available. The selections form an independent set of type $`\kappa\cdot\alpha=\alpha`$, a contradiction. An induced graph as in the statement again has order type $`\alpha`$ and cannot contain a full-type independent subset, so the proof applies there as well.

**Consequence of forbidding a pentagon.** Suppose $`W`$ has at least three vertices and $`R`$ is an uncountable common-neighbor set. For every $`w\in W`$, every $`p\in R`$ is isolated in the graph induced by $`N(w)`$. If $`pz`$ were an edge there, choose $`a\in W\setminus\{w,z\}`$ and $`q\in R\setminus\{p,z\}`$. Then $`w,q,a,p,z,w`$ is a simple five-cycle. Its five vertices are distinct because a common-neighbor set is disjoint from its witness set in a loopless graph. In particular each such reservoir is independent, and reservoirs whose witness sets intersect have no edges between them. If a single vertex occurred in witness sets for a full-type set of basic blocks, their reservoirs would give an independent set of full type. A finite set intersecting all those witnesses leads to the same contradiction by finite indivisibility.

The finite size $`k`$ is fixed before the exceptional index set is chosen. Nothing here supplies a common countable witness set, or coordinates witnesses for different blocks. The [robust part criterion](ROBUST-PARTS.md) concerns edges meeting every pair of uncountable subsets in two disjoint parts. Here the witnesses can be anywhere and can change whenever the prescribed subset changes.

## Why finite witnesses need not accumulate

There is a single-block example in which the preceding finite conclusion holds on every uncountable thinning, for every finite size at once, yet any countably infinite set of witnesses has at most one common neighbor in the block. Choose an uncountable set of distinct infinite binary sequences of cardinality $`\aleph_1`$ as one part. The other part consists of all finite binary strings. Join a sequence to its finite initial segments. This is a bipartite graph, so it has no pentagon. Partition any uncountable set of sequences by their first $`k`$ bits. Some cell is uncountable, and the first $`k`$ nonempty prefixes are common witnesses for every sequence in that cell. Two distinct infinite sequences have only finitely many common prefixes. Thus a countably infinite set of witnesses cannot have two common sequence neighbors. This is the classical almost-disjoint family of branches, applied to the local witness condition. [Geschke, *Almost disjoint and independent families*, Theorem 2.4](https://www.math.uni-hamburg.de/forschung/bereiche/dm/personen/geschke-stefan/pdf/papers/independentfamilies.pdf)

For fixed finite size $`k`$, it suffices that each uncountable thinning has at least $`k`$ distinct vertices whose neighborhoods individually meet it uncountably. Intersect with one such neighborhood and repeat on the smaller uncountable set, choosing a fresh witness at each of the $`k`$ steps. The converse is immediate from a common uncountable neighborhood.

The example also illustrates a necessary alternative. Suppose a *fixed* block satisfies the finite witness property on every uncountable thinning for every finite size. If there is no countable set of distinct witnesses with uncountably many common neighbors in that block, then every uncountable subset of the block is split by some vertex neighborhood into two uncountable parts. Otherwise every neighborhood on such a subset would be countable or have countable complement there. For each finite size the witness property would then give that many vertices with co-countable neighborhoods on the subset. Countably many distinct such vertices have co-countable common neighborhood, a contradiction.

Applying the split to each of the two parts repeatedly produces a binary tree in which every node has uncountably many sites respecting all earlier choices along its path. Globally distinct splitting vertices can be used: in breadth-first order only finitely many vertices have already served as splitters. Partition the current cell by incidences with them and choose an uncountable subcell. A vertex splitting that subcell is new and also splits the current cell. The argument gives no uncountable intersection along an infinite path. The ordinal reduction above chooses its exceptional set separately for each finite size. These exceptions cannot be combined by counting alone. Keeping the initial $`\kappa^n`$ sites in each of the $`\kappa`$ columns gives a set of type $`\kappa^{n+1}\lt\alpha`$, but the union over finite $`n`$ is the whole ordinal. This example tests accumulation inside one block; coordinating witnesses inside an induced graph on a full family of blocks remains a separate step.

## Prior statements and scope

Erdős (1975, pp. 183–184) credits Erdős, Hajnal and Milner with a global finite-by-countable complete bipartite alternative to a full-order independent set for limit ordinals. The same paper separately credits Erdős and Hajnal with finite-by-uncountable complete bipartite subgraphs under uncountable chromatic number. The block statement uses failure of full-order independence and prescribes the uncountable side inside arbitrary thinnings of a given block. Erdős–Hajnal–Milner (1970), Theorems 4–6, concern free subsets for set mappings; Theorem 7 uses absence of an infinite path. Their 1971 paper treats polarized colorings of a Cartesian product. The bounded comparison found no exact statement of this block localization. The finite-exception coloring and recursion here refine the existing thin-block argument.
