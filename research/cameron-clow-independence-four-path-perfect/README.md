# Cameron–Clow’s independence-four path-perfect conjecture

**Status:** Proved.

Every graph with independence number at most four is path-perfect.
For every induced subgraph, there is a path whose vertices span a
subgraph with the full chromatic number. The universal threshold is
sharp: a previously known critical graph with independence number
five has chromatic number four, but every path span is 3-colorable.

The proof combines the coloring constraints across a two-vertex cut
with a structural characterization of graphs of small independence
number that have a spanning path.
