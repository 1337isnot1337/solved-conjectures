# Anchored differences and exact extraction from a low-degree cofactor

Status: research. The Shub--Smale tau conjecture and the unrestricted
consecutive-root all-multiples problem remain unresolved. Section 2 gives
an explicit extraction when the cofactor degree is a parameter. Its cost
is polynomial in that degree, which may be exponential in the input
program length. Sections 3--4 state the precise limitations of two
universal oracle approaches. No novelty claim is made.

Throughout,


```math
F_N(x)=\prod_{j=1}^{N}(x-j),\qquad N\ge1.
```


Programs begin with `1,x` and use binary addition, subtraction, and
multiplication. Every integer constant is charged. A nonzero constant
multiple of `F_N` is distinguished from `F_N` itself.

## 1. An endpoint-anchored difference operator

Let `E` denote translation, `(EP)(x)=P(x+1)`, and let
`Delta=E-1`. The identity


```math
(x-N)F_N(x+1)=xF_N(x)
\tag{1.1}
```


holds by matching the factors on both sides. Define the rational linear
operator


```math
(\mathcal T_N H)(x)
 =\frac{(x-N)H(x+1)-xH(x)}x.
\tag{1.2}
```


It is defined on the rational-function field. On the ideal generated by
`F_N`, it is a polynomial operator:


```math
\mathcal T_N(F_NQ)=F_N\Delta Q.
\tag{1.3}
```


Indeed, substitute `H=F_NQ` in (1.2), apply (1.1), and cancel the common
nonzero rational function `x`. The resulting identity is in `Z[x]`
whenever `Q` is in `Z[x]`. In particular the operator lowers the degree
of every nonconstant cofactor by one; it kills a constant cofactor.
It uses the prescribed endpoint `N` and the explicit variable `x`.

If `Q` has degree `q` and leading coefficient `a!=0`, repeated finite
differencing gives


```math
\mathcal T_N^q(F_NQ)=q!\,a F_N.
\tag{1.4}
```


For completeness, if a polynomial has degree `r>=1` and leading
coefficient `b`, its forward difference has degree `r-1` and leading
coefficient `rb`, by the binomial theorem. Induction proves (1.4).
When `q=0`, the original output already has the required form.

## 2. A division-free implementation independent of the output degree

### Lemma 2.1. Exact division by a known polynomial of small degree

Let


```math
R(x)=\prod_{i=0}^{q-1}(x-a_i)\in\mathbb Z[x]
```


be monic, where the integers `a_i` are supplied by charged constant
programs. Repetitions among the `a_i` are allowed. Suppose a
division-free program of length `L` computes `K=RS` in `Z[x]`.
Then a division-free program computes `S` using at most
`2(q+1)^3 L` gates in addition to the constant programs and `O(q)`
setup gates. This bound does not depend on `deg K` or `deg S`.

**Proof.** Work over `Z[x]` with a second formal variable `t`. Set


```math
\beta_0(t)=1,\qquad
\beta_j(t)=\prod_{i=0}^{j-1}(t-a_i)\quad(1\le j\le q).
```


These monic polynomials form a basis of the free module


```math
\mathbb Z[x,t]/\bigl((t-x)R(t)\bigr).
```


In this basis, multiplication by `t` is the lower bidiagonal matrix


```math
M=\begin{pmatrix}
a_0&0&\cdots&0&0\\
1&a_1&\cdots&0&0\\
0&1&\ddots&0&0\\
\vdots&\vdots&\ddots&a_{q-1}&0\\
0&0&\cdots&1&x
\end{pmatrix}.
\tag{2.1}
```


The formula follows from
`t beta_j=beta_(j+1)+a_j beta_j` for `j<q`, and
`t beta_q=x beta_q` in the quotient. It is valid when nodes repeat.
Modulo `(t-x)R(t)`, the identity `K(t)=R(t)S(t)` gives


```math
K(t)\equiv R(t)S(x)=\beta_q(t)S(x),
```


because `S(t)-S(x)` is divisible by `t-x`. Therefore the coefficient
of `beta_q` in `K(M)e_0` is `S(x)`, or equivalently


```math
S(x)=K(M)_{q,0}.
\tag{2.2}
```


Evaluate the original program on matrices, replacing the input `1` by
the identity matrix and the input variable by `M`. Addition and
subtraction of `(q+1)`-square matrices use at most `(q+1)^2` scalar
gates. Ordinary matrix multiplication uses at most `2(q+1)^3` scalar
gates. The required entry is an existing output register. All matrix
entries and operations lie in `Z[x]`; no inverse, interpolation
division, or zero test occurs. This proves the bound. QED.

The case `q=0` means `R=1`, `M=(x)`, and requires no division.
An available scalar constant can be used as a scalar matrix without
rebuilding its constant program at every entry. Only its diagonal
entries are that constant; all off-diagonal entries use the one shared
zero register.

### Theorem 2.2. Removing an arbitrary cofactor of degree q

Suppose a length-`s` constant-free program computes
`H=F_N Q!=0`, where `Q` is in `Z[x]`, has degree `q`, and has leading
coefficient `a`. There is a constant-free division-free program for


```math
q!\,a F_N
```


of length


```math
O\bigl((s+1)(q+1)^4+\log(N+1)\bigr).
\tag{2.3}
```


The implied constant is absolute. The statement is an existence bound;
it does not require an algorithm to detect `q` from a circuit with
cancellations.

**Proof.** Assume `q>=1`, since `q=0` needs no transformation. Put


```math
A=\frac{x-N}{x}E,
\qquad \mathcal T_N=A-1.
```


Composition gives


```math
A^jH(x)=\frac{P_j(x)}{R_j(x)}H(x+j),
\quad
P_j=\prod_{i=0}^{j-1}(x+i-N),
\quad
R_j=\prod_{i=0}^{j-1}(x+i).
\tag{2.4}
```


This follows by induction: applying `A` shifts all factors by one and
introduces the factor `(x-N)/x`. The identity operator commutes with
`A`, so the ordinary binomial expansion is valid for `(A-1)^q`.
Define


```math
S_j(x)=\prod_{i=j}^{q-1}(x+i),
```


with empty products equal to one. Clearing the common denominator
`R_q` yields the polynomial


```math
K(x)=\sum_{j=0}^{q}(-1)^{q-j}\binom qj
          P_j(x)S_j(x)H(x+j)
     =R_q(x)\mathcal T_N^q H(x).
\tag{2.5}
```


The following construction charges all constants and uses no division.
Construct `N` in `O(log(N+1))` gates by binary doubling and addition.
Construct `x,x+1,...,x+q` successively. Replay the input program at
those `q+1` inputs. Compute all `P_j` by prefix products and all `S_j`
by suffix products. Obtain the binomial coefficients in row `q` of
Pascal's triangle using `q(q-1)/2` additions, with the endpoints equal
to the existing input one. Form the terms of (2.5), using subtraction
for their signs, and add them. Apart from the scalar constant programs,
the number of gates is at most


```math
(q+1)s+8q+3.
\tag{2.6}
```


By (1.4), `K=R_q q!a F_N`, so it is exactly divisible by `R_q`.
Apply Lemma 2.1 with `a_i=-i`. Construct these `q` integers by successive
subtraction from a shared zero. Its matrix program computes
`K/R_q=q!a F_N`.

In this last evaluation, precompute `N` and the Pascal coefficients
as scalars, then supply their scalar matrices. Thus their program
length is paid once, not multiplied by the matrix dimension. The
remaining gate count is bounded by


```math
2(q+1)^3\bigl((q+1)s+8q+3\bigr)
 +\frac{q(q-1)}2+O(q+\log(N+1)).
\tag{2.7}
```


This implies (2.3). Since `a!=0`, the output is a nonzero constant
multiple of `F_N`. QED.

### What this does and does not remove

The construction uses the two endpoint factors in (1.1) and the full
input circuit. It does not need a program for `Q`, a list of its roots,
or a circuit for `F_N` in advance. The exact-division step pays for
`q`, not for the usually much larger degree `N+q` of `H`.

For unrestricted circuits, `q` may be as large as `2^s-N`. Substituting
this bound into (2.3) gives an exponential bound, not a polynomial
bound in `s` and `log N`. The missing step is an implementation that
uses the circuit structure to compress the `q`-th anchored difference,
or a different extractor with no polynomial dependence on `q`.
Simply writing `(A-1)^q` by repeated squaring of an operator does not
provide an arithmetic circuit for its action on `H`.

This is consistent with the known low-divisor-degree approach. Dutta,
Jindal, Pandey, and Sinhababu, *Arithmetic Circuit Complexity of Division
and Truncation*, CCC 2021, Article 25, Theorem 13, give the analogous
univariate quotient and remainder bound with arbitrary field constants.
Their Problem 1 asks for degree-independent division elimination.
Their Section 4 explicitly includes division by `x^d` with exponentially
large `d` among the unresolved cases at that paper's date. The charged
matrix argument above does not assume a degree-independent division
theorem. Primary version:
<https://drops.dagstuhl.de/storage/00lipics/lipics-vol200-ccc2021/LIPIcs.CCC.2021.25/LIPIcs.CCC.2021.25.pdf>.

As a transcription check, exact symbolic calculations verified (2.5)
and the bottom-left matrix entry for `1<=N<=5`, `0<=q<=5`, and
`Q=sum_(j=0)^q (-1)^j(j+1)x^j`. All 30 cases passed. These finite
checks are separate from the proofs.

## 3. Why the universal linear shift expansion cannot be shortened

Fix `q>=0`. For any distinct integers `b_1,...,b_m`, the functionals
`Q -> Q(x+b_i)` on polynomials of degree at most `q` are independent
over `Q(x)` whenever `m<=q+1`: their matrix on `1,t,...,t^(m-1)` is
a Vandermonde matrix with nonzero determinant.

Consequently, if


```math
\Delta^q Q(x)=\sum_{i=1}^{m}c_i(x)Q(x+b_i)
\tag{3.1}
```


holds for every polynomial `Q` of arbitrary degree, the usual forward
difference expansion shows that every one of the `q+1` nodes
`0,1,...,q` must occur, with its usual nonzero binomial coefficient.
To see uniqueness without a degree restriction, take the union of
the two node sets and apply the same Vandermonde argument to a basis
of size equal to that union. Thus any universal linear translation
formula has at least `q+1` distinct translated samples.

Even if the formula is required only for cofactors of degree at most
`q`, at least `q+1` nodes are necessary to recover `q!` times the
leading coefficient universally. Indeed, with `m<=q` nodes the
polynomial


```math
t^{q-m}\prod_{i=1}^{m}(t-x-b_i)\in K[t]
```


has degree `q`, leading coefficient one, and vanishes at every queried
node, contradicting such a formula. An identity stated for all
`Q in Q[t]` of degree at most `q` extends `K`-linearly to `K[t]`,
so this counterexample is legitimate in the coefficient-field argument.

This proves a limitation of a universal linear oracle formula. It
does not rule out nonlinear use of a particular circuit, reuse of its
intermediate registers, or a different extraction operation.

## 4. Translation equivariance and fixed finite rational probes

### Proposition 4.1. Translation equivariance preserves longer intervals

Fix `N>=1`. Suppose an operation `E_N` is defined on every nonzero
polynomial divisible by `F_N`, returns a nonzero polynomial divisible
by `F_N`, and commutes with every integer translation whenever both
inputs are in its domain. Then, for every `L>=N`,


```math
F_L\mid E_N(F_L).
\tag{4.1}
```


**Proof.** For `0<=t<=L-N`, the polynomial `F_L(x+t)` has all roots
`1,...,N`. The output condition and equivariance imply
`E_N(F_L)(j+t)=0` for `1<=j<=N`. As `j,t` vary, their sums cover
`1,...,L`. All these roots are distinct, proving (4.1). QED.

In particular no such operation can return the fixed polynomial
`F_N` for every multiple, or even bound the output degree solely in
terms of `N`. Fixed translations, differentiation, rational arithmetic,
monic gcd/lcm, and squarefree normalization commute with translation
on their domains, so compositions of them have this obstruction when
they use no explicit variable-dependent anchor. Equation (1.2) escapes
the hypothesis by using `x` and `x-N` explicitly.

### Proposition 4.2. A fixed finite rational probe cannot cancel every cofactor

Let `K=Q(x)`. Choose distinct nonconstant rational functions
`z_1(x),...,z_r(x)` in `K` and positive integers `m_1,...,m_r`.
Let `M=sum m_i`. For `H=F_NQ`, consider the `M` probes


```math
H^{(j)}(z_i(x)),\qquad 1\le i\le r,\quad 0\le j\lt m_i.
\tag{4.2}
```


Here the derivative is taken in the polynomial's own argument before
substitution. Suppose one fixed rational function
`R in K(U_1,...,U_M)` is defined on a Zariski-dense set of the probe
vectors from `Q in Z[t]`, and its value is the same element `B(x) in K`
for every such `Q`. Then `R=B(x)` in `K(U_1,...,U_M)`; it has no
dependence on the probe variables.

**Proof.** Restrict to `Q(t)=sum_(k=0)^(M-1) c_k t^k` with integer
coefficients. Hermite evaluation


```math
Q\longmapsto\bigl(Q^{(j)}(z_i)\bigr)_{i,j}
```


is an invertible `K`-linear map on the `M` coefficient coordinates.
Indeed, a degree-less-than-`M` polynomial in its kernel is divisible
by `prod_i(t-z_i)^(m_i)`, a monic polynomial of degree `M`, and is
therefore zero. Multiplication by `F_N` induces an invertible triangular
map on each jet block, by the product rule: its diagonal entries are
`F_N(z_i)!=0`. Nonconstant rational `z_i` cannot be a constant root
of `F_N`. Thus the full map from coefficient vectors to probes is an
invertible `K`-linear transformation.

The set `Z^M` is Zariski dense over `K`. A polynomial over `K` that
vanishes on this grid is zero, by induction on the number of variables
and the fact that a nonzero univariate polynomial has only finitely
many roots. An invertible linear transformation preserves this
density. Clear the denominator in `R-B`; its numerator vanishes on
a dense subset and is therefore zero. QED.

Distinct affine shifts and characteristic-zero root-of-unity probes
are included by the same proof after extending `Q` to the fixed
cyclotomic coefficient field. A divided difference is a rational
combination of its underlying probes. A fixed probe at a prescribed
root gives the known value zero and can be discarded; higher jets
there can be treated after dropping the identically zero initial jet
coordinates. This observation does not assert independence for
arbitrary adaptive evaluation nodes.

The proposition concerns one expression valid for every unrestricted
cofactor. It does not apply to a circuit-dependent extractor, to a
finite bounded-length family of cofactors, or to a branching procedure
that inspects coefficients. In particular it does not prohibit
Theorem 2.2, whose order `q` varies with the cofactor and which returns
the cofactor-dependent scalar `q!a` times `F_N`.

For the following quantitative statement, the outer circuit starts
only from `1,x` and its probe inputs: every scalar or rational-function
coefficient in the outer expression must itself be computed and charged.
Allowing arbitrary free coefficients in `K` would permit the desired
output to be hidden in those coefficients.

If a division-free outer circuit has a cofactor-independent output,
the independent probe inputs can simply be replaced by zero to obtain
the same output without the oracle. For a valid rational outer circuit
of `t` gates, they can instead be replaced by integers of bit length
`O(t+log(t+1))` avoiding all its divisors. To justify this quantitatively,
clear numerators and denominators syntactically at each gate. Their
degrees in the probe variables are at most `2^t`. The product of the
nonzero divisor numerators has degree at most `t 2^t`; the grid
`{0,...,t 2^t}^M` contains a point where it does not vanish. Only
`O(t)` distinct probe inputs can be used by a binary size-`t` circuit,
so these constants cost `O((t+1)^2)` constant-free gates. The resulting
rational circuit contains no oracle inputs. If its output is a
polynomial, clearing its final denominator gives a nonzero `Z[x]`-multiple
of that polynomial with `O((t+1)^2)` gates. This last
statement is not degree-free elimination of variable divisions while
preserving the exact polynomial.
