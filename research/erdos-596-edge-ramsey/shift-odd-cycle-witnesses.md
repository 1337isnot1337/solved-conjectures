# Erdős–Hajnal’s finite-to-countable edge Ramsey problem

## Odd-cycle shift witnesses and the triangle barrier

This is a structural positive family for [Erdős Problem 596](https://www.erdosproblems.com/596): for the pairs below a countable-colour witness exists in ZFC, so they are not exceptions to the finite-to-countable implication. This is not a classification of the remaining nonbipartite pairs or a solution to the separate triangle problem #595.

Write $`S_t(L)`$ for the graph on increasing $`t`$-tuples from a linear order $`L`$, with an oriented edge
```math
(a_1,\ldots,a_t)\longrightarrow(a_2,\ldots,a_t,b)
\quad(a_t\lt b).
```
We take subgraph containment, not induced containment, unless indicated otherwise. Let $`\mathcal A_t`$ be the finite subgraph age of $`S_t(\mathbb Q)`$. It is also the finite subgraph age of $`S_t(\kappa)`$ for every infinite ordinal $`\kappa`$, by transferring the finite set of coordinates in any embedding.

**Shift-age criterion.** If $`H\in\mathcal A_t`$ and $`F\notin\mathcal A_t`$, some $`F`$-free graph arrows $`H`$ in countably many edge colours, and for every finite number of colours a finite $`F`$-free graph arrows $`H`$. Indeed, each increasing $`(t+1)`$-tuple indexes exactly one edge. Apply Erdős–Rado at $`\kappa=(\beth_t(\aleph_0))^+`$ to the induced colouring of $`[\kappa]^{t+1}`$. A homogeneous finite coordinate set supporting the chosen embedding makes every edge of that copy monochromatic. Finite Ramsey proves the finite assertion in the same way. In fact, this captures exactly the finite targets which these hosts can arrow, since any such target must be a subgraph.

### Explicit nonbipartite families

For $`t\ge2`$ the shift graph has odd girth $`m=2t+1`$, and its finite age contains every forest of $`C_m`$-copies, with gluing at a vertex or an edge; in particular it contains every unicyclic graph with cycle $`C_m`$. Here a forest of copies is built by adding one copy at a time, with intersection empty or exactly a vertex or edge together with its subfaces. Ordinary pendant trees can also be attached to any vertices.

To see the embeddability, take two increasing tuples $`A,B`$ with all entries of $`A`$ below all entries of $`B`$. The consecutive windows in $`AB`$ give a directed $`A`$-to-$`B`$ path of length $`t`$; the windows in $`AxB`$, for $`x`$ strictly in the gap, give one of length $`t+1`$. Each internal vertex on the latter path contains $`x`$, so their union is a simple $`C_m`$. For a vertex gluing, identify an arbitrary one tuple with the old vertex and choose all other coordinates fresh in the proper intervals of $`\mathbb Q`$. For an edge gluing, place the old edge at any edge of the shorter $`AB`$ path, transferring the $`t+1`$ shared coordinates in order. The only vertices of this copy using exclusively those coordinates are the two endpoint windows: all other $`AB`$ windows use another coordinate, and internal $`AxB`$ windows use $`x`$. With all other coordinates fresh, no additional vertex collision occurs. Added edges between copies, if any, are harmless for subgraph containment. Pendant attachments use infinitely many available incoming or outgoing tuples at any vertex. Disjoint additions use fresh coordinate sets.

The shift-age criterion therefore applies to every target just described and every forbidden graph with an odd cycle of length less than $`m`$. There is also a forbidden family with *the same* odd girth. Given any odd cycle $`C`$, form $`D(C)`$ by adding for every $`v\in V(C)`$ a private vertex adjacent to the two cycle neighbours of $`v`$. A shift graph with $`t\ge2`$ contains no $`D(C)`$: on an odd cycle some vertex has one incident edge oriented in and one out (otherwise sources and sinks alternate). If $`A\to V\to B`$ is that directed 2-path, $`V`$ is the unique common neighbour of $`A,B`$. A common successor would require equal $`(t-1)`$-suffixes, impossible since the last coordinate strictly increases twice; a common predecessor would require equal $`(t-1)`$-prefixes, ruled out by the first coordinate. A reverse directed 2-path is impossible by the same coordinate order, and any $`A`$-to-$`B`$ intermediate has its first $`t-1`$ entries fixed by $`A`$ and its last $`t-1`$ by $`B`$. The private alternate midpoint contradicts uniqueness. In particular the criterion works whenever $`F`$ contains a two-fold independent blow-up of an odd cycle, since such a blow-up contains $`D(C)`$. For $`C=C_m`$, both $`D(C)`$ and its blow-up host have odd girth exactly $`m`$: mapping private midpoint copies back onto their cycle vertices is a homomorphism onto $`C_m`$, and $`C_m`$ remains a subgraph.

### Why pure tuple types cannot reach triangle Ramsey without a $`K_4`$

Take the vertex set to consist of full finite-tuple sorts over one infinite linear order, with countably many sorts; membership of an edge depends only on the sorts and weak order type of the two tuples. This includes finite unions of type graphs on ordinal tuples. Colour each edge by its sorts and weak order type, reading the two tuples in lexicographic order when their sorts agree. Use a fixed sort order when they differ. There are countably many colours.

If three vertices form a monochromatic triangle, they have the same sort: three unordered pairs of sorts cannot all be the same distinct-sort pair. Order the three vertices lexicographically. Every ordered pair in this triangle has the same type $`\tau`$. To prescribe $`N`$ purported clique vertices, assign all comparisons within a tuple from its sort, and between each pair of tuple indices from $`\tau`$, always in increasing index order. Every comparison of three coordinates is consistent with a total preorder: it uses at most three tuple indices, and can be read on the observed triangle. Thus the full finite set of coordinates is totally preordered; realizing the ordered equivalence classes in the underlying infinite order gives $`N`$ distinct vertices (each pair has type $`\tau`$) and a $`K_N`$. In particular any $`K_4`$-free graph of this form has a countable edge colouring without a monochromatic triangle. Structural conditions beyond pure pairwise order type are needed for a triangle witness.

### Priority and scope

The shift graph and its odd-girth bound are classical, not claimed here. See [Hajnal's lecture notes, Definition 42](https://www.mathtube.org/sites/default/files/lecture-notes/Hajnal.pdf), [Avart–Łuczak–Rödl, *On generalized shift graphs*](https://www.impan.pl/en/publishing-house/journals-and-series/fundamenta-mathematicae/all/226/2/88526/on-generalized-shift-graphs), and [Rödl et al., *The chromatic number of finite type-graphs*](https://doi.org/10.1016/j.jctb.2016.10.004). [Aher–Lakshmanan](https://arxiv.org/abs/2509.23929) explicitly give the shift-edge/hyperedge bijection and its finite Ramsey use. The point of this note is the countable-colour application to the precise finite-to-countable question, the vertex/edge gluing and same-girth forbidden families, and the limitation of pure tuple order types. The [working literature report](https://www.erdosproblemaday.com/report/596) still leaves the arbitrary pair open. No claim is made about optimal cardinality of the hosts.
