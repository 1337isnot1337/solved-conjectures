# Lyapunov determinant factorization

Research only. This package proves a complementary-minor identity and an exact multiplicity statement for the generic symmetric determinant. It is not a named-conjecture resolution.

[PROOF.md](PROOF.md) gives the argument, coordinate signs, singular-matrix nondivisibility proof, and primary-source audit. The source paper by Dettling, Homs, Améndola, Drton, and Hansen contains separate divisibility results in arXiv v1 Corollary 43, v2 Corollary 44, and published Corollary B.2. None of those versions states the exact-product conjecture attributed to the paper by MathDB 356020.

The paper's actual sum-of-squares conjecture for simple graphs remains unresolved by this work. The trace-sign method used here has an explicit antecedent in the paper's identifiability proof.

No Lean work was performed. The proof is symbolic and applies to all matrix sizes; no finite computation is used as a substitute for that proof.
