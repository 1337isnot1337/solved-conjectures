# An exact three-color target always forces parity

**Theorem.** In the balanced [three-block setting](PAIR-GRAPHONS.md), if there is one part \(X\) into which almost every outside vertex sends exactly three of the four cross colors, then zero rainbow-six-cycle density implies an exact parity cut. This closes the exact-three profile regime with no restriction on the missing-label masses. It does not address a target with a mixture of different profile sizes.

By [PAIRED-THREE-COLOR-TARGET.md](PAIRED-THREE-COLOR-TARGET.md), it remains to establish two equal \(A\)-row classes and a common pairing when exactly three missing-label classes have measure at least \(t=1/6\). The cases of at most two and of four heavy classes were proved there. Use deterministic refinement as before. Denote the three heavy labels by \(a,b,c\), with the fourth \(\ell\) light. For a heavy label \(a\) write \(P_a\) for the matching of palettes \(\{a,\ell\}\mid\{b,c\}\); define \(P_b,P_c\) in the same way. Write \(M_i\) for the outside vertices missing \(i\) into \(X\).

A root failing to have all palette returns can lack only one unordered palette, say \(\{b,c\}\), because only heavy pairs can be absent and absent pairs are disjoint at each root. Write \(E_{bc}\) for these roots. At such a root the color \(b\) is confined to \(M_c\) and the color \(c\) to \(M_b\), with neighborhood mass \(t\) for each. Every edge from the root to \(M_a\) is consequently \(\ell\): neither \(b,c\) can reach \(M_a\), and \(a\) is missing there. The only incomplete matching at these roots is \(P_a\). Define the other exceptional sets analogously.

## The two row classes exist

Every present nonlight color neighborhood of a typical outside vertex lies in a single \(A\)-row class. Take another present nonlight color as companion, possible with three present colors. The complementary palette then includes \(\ell\), so it cannot be absent as an unordered palette at any typical root. The actual two-color path through the outside vertex supplies the first palette, and the complementary-palette argument gives homogeneity. As usual this inference holds for almost all paths by Fubini.

Call an outside vertex *mixed* when its \(\ell\)-neighborhood is not in one \(A\)-row class (an absent \(\ell\) is not mixed). For a mixed vertex of \(M_a\), its \(b\)-neighbors are confined to \(E_{ac}\), and its \(c\)-neighbors to \(E_{ab}\). Otherwise factoring through one such neighbor would find the complementary palette to a return in colors \(b,\ell\) or \(c,\ell\) and make the \(\ell\)-neighborhood homogeneous. In particular both exceptional sets have positive measure if a positive measure of \(M_a\) is mixed. At roots in \(E_{ab}\), the \(b\)-neighbors of mass \(t\) in \(M_a\) cannot be mixed, since mixed vertices of \(M_a\) send \(b\) only to \(E_{ac}\). This proves that every heavy \(M_a\) has at least \(t\) mass of nonmixed vertices, whether some of it is mixed or not.

The three monochromatic neighborhoods of any typical nonmixed vertex cover \(X\) by at most three row classes. The class size bound \(t\) and the exclusion of three classes give two classes of mass \(t\). In these types a mixed vertex of \(M_a\) has \(b,c\) in opposite types: if both were in one type, their total degree would have to equal \(t\) by the cap on \(\ell\), and \(\ell\) would fill the opposite type.

## No mixed vertices survive

Whenever \(E_{bc}\) has positive measure, it lies in one \(A\)-type: a nonmixed \(M_a\) vertex sends \(\ell\) to all of it. At one typical root in \(E_{bc}\), every \(M_a\) vertex is reached in color \(\ell\), and both palettes \(\ell b,\ell c\) have complete matching tests there. Hence the row types assigned to \(b,c\) are fixed across \(M_a\). If some \(M_a\) vertices were mixed, these types would be opposite for all \(M_a\) vertices. At every nonmixed \(M_a\) vertex, \(\ell\) has the type of \(E_{bc}\), so the heavy color sent into the opposite type is the same singleton color for the whole nonmixed group. This group has mass at least \(t\) and exhausts that color at every root of the opposite type. The same color cannot then also have positive degree into that type from a positive mass of mixed vertices. Thus \(M_a\) cannot be mixed on positive measure if \(E_{bc}\) is present.

It follows that a remaining mixed group, say \(M_a\), requires exactly two positive exceptional sets \(E_{ab},E_{ac}\), with \(E_{bc}\) null. All \(M_b,M_c\) vertices are nonmixed. Let the types of \(E_{ac},E_{ab}\) be zero and one respectively; they are different because a mixed \(M_a\) vertex uses \(b,c\) in opposite types. Then \(M_b\) sends \(\ell\) to type zero and \(M_c\) sends \(\ell\) to type one.

The matching \(P_a\) is now complete at every typical root. A mixed \(M_a\) vertex has colors \(b,c\) respectively into types zero and one; through these two neighborhoods it forces \(P_a\) to be opposite-type at a positive mass of roots of each of \(E_{ac}\) and \(E_{ab}\). At roots in \(E_{ac}\) the color into every \(M_b\) vertex is \(\ell\), so the palette \(\ell a\) implies the \(a\)-neighborhood of \(M_b\) is of type one. By the same reasoning \(M_c\) sends \(a\) into type zero. Moreover the type of the third color \(c\) at \(M_b\) is fixed across all of \(M_b\), using the complete palette \(\ell c\) at a root of \(E_{ac}\); the corresponding third color \(b\) at \(M_c\) also has a fixed type. Each group thus has a common singleton color to a fixed type and must have mass exactly \(t\), because the singleton color is saturated and each group was heavy.

The families \(M_b,M_c\) now both use pairings in \(\{P_b,P_c\}\), since \(a,\ell\) are in opposite types for each. On type zero \(P_c\) is complete, because its sole possible deficient roots are \(E_{ab}\) in type one. If \(M_c\) uses \(P_b\), its singleton \(a\) is on type zero and the \(a,b\) palette forces \(P_c\) opposite there. Then \(M_b\) cannot use \(P_c\) (which would pair \(c,\ell\) together on type zero), so it uses \(P_b\). If \(M_c\) uses \(P_c\), the \(a,b\) colors share type zero, forcing \(P_c\) same there, and then \(M_b\) must use \(P_c\) too. Thus both groups use the same pairing. Swap \(b,c\) and the type names if necessary, so the common pairing is \(P_b\). In particular every \(M_c\) vertex sends singleton \(a\) to type zero and the pair \(b,\ell\) to type one.

Take a typical type-one root seeing a mixed \(M_a\) vertex in color \(\ell\). That vertex also sends color \(c\) to type one, so if \(P_c\) is complete at the root it must be same-type there. The root cannot send any \(b\) into \(M_c\), since a return through the singleton \(a\) of an \(M_c\) vertex would make \(P_c\) opposite. Hence the root sends \(\ell\) to all of \(M_c\). If instead \(P_c\) is incomplete, the root lies in \(E_{ab}\) and again sends \(\ell\) to all of \(M_c\) by the exceptional-root rule. Since \(M_c\) has mass \(t\), either case exhausts the root's \(\ell\)-degree, contradicting the purported \(\ell\)-edge into mixed \(M_a\). The positive-measure \(\ell\)-neighborhood in type one required by mixing is impossible.

## A single pairing

All outside color neighborhoods are now homogeneous. For each complete matching on a root, the same- or opposite-type test has a fixed outcome. If an outside vertex uses a pairing \(P\) complete on its whole double type, no other pairing can occur on positive measure: \(P\) is same on that double type; a different pairing forces \(P\) opposite either on its whole singleton type if that is the original double type, or on a positive part of the common double type. This is the same two-palette test used in [the paired target proof](PAIRED-THREE-COLOR-TARGET.md).

It remains to find such a vertex. For every positive \(E_{bc}\), write \(p_a\) for its row type, so \(P_a\) is complete on type \(1-p_a\). Assume no outside pairing is complete on its own double type. Any pairing used is then indexed by a nonnull exceptional set, and its double type is the bit of that set. Also no vertex of \(M_a\) can use \(P_a\): if \(E_{bc}\) is null it is globally complete, and if it is present then \(\ell\) would be the singleton of type \(p_a\), making the double type \(1-p_a\).

If all three exceptional sets are positive, each heavy \(M_a\) must choose \(P_i\) for an index \(i\ne a\) with \(p_i=p_a\), because \(\ell\) belongs to the double type. Thus no \(p_a\) is unique among the three and all are equal to one bit \(p\). If precisely two sets are positive, indexed by \(b,c\), each of \(M_b,M_c\) must choose the other's pairing, so \(p_b=p_c=p\). In both cases all heavy \(M_i\) send \(\ell\) only to type \(p\): with two indices this also holds for the third heavy group \(M_a\), which chooses only \(P_b,P_c\) and has \(\ell\) in the double type. Vertices in \(M_\ell\) never send \(\ell\). This gives no \(\ell\)-degree at roots of type \(1-p\), contrary to balance. With only one exceptional set the same assumption would make every \(M_i\) use its sole incomplete pairing, which is impossible for the heavy group indexed by it. With no exceptional sets every pairing is complete.

A common pairing exists in all cases. The [paired target theorem](PAIRED-THREE-COLOR-TARGET.md) therefore gives the global parity cut. Coordination: [#870](https://github.com/1337isnot1337/solved-conjectures/issues/870).
