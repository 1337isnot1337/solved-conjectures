# Cameron–Clow’s claw-free path-perfect conjecture

**False.** There is a claw-free graph of chromatic number
four in which the vertices of every path span a graph
of chromatic number at most three. The least forbidden-star
leaf count in Cameron and Clow's Problem 7.1 is three.

The construction gives a 52-vertex line graph and an
infinite family. A Hamilton path would require a dominating
trail to negotiate three branches with only two endpoints.
The coloring-criticality certificate comes from explicit
edge-critical building blocks.
