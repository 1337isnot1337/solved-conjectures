# Fresh analytic target screening

## Kalmykov–Karp’s conjecture

Conjecture 2 of arXiv:1611.06724 is excluded. The complete prior public argument appears in [TrureTuring issue 20945](https://github.com/the-omega-institute/trureturing/issues/20945). For the second parameter block a=(1), b=(1/2,...,1/2) of length q, and first blocks empty (or equal and cancelling), take mu=1 and alpha=beta=1/2. The x coefficient equals

```math
\frac{45\pi}{16}2^{-q}-4\left(\frac{16}{9\pi}\right)^q-6\left(\frac{16}{15\pi}\right)^q.
```

It is negative for every q at least 7, using the elementary bound pi<3.15 as proved in the issue body. The hypotheses reduce to 2^{-q}<=q 2^{1-q}. This is a full prior analytic counterfamily to the original conjecture, not only a numerical observation or a research reservation. No new result is claimed. Checked 21 November 2026.

## Krasniqi’s conjecture

Conjecture 23 of arXiv:2609.28707 is excluded: [TrureTuring issue 24826](https://github.com/the-omega-institute/trureturing/issues/24826) explicitly reproduces the ordinary full proof already recorded on 3 October 2026 in issue 12669 and docs/develop/theory/KrasniqiBoundaryContact.md. It uses a signed-Laplace filter, exact rational partition, and global tail argument to prove unique quadratic contact for every parameter. Pending Lean work does not make that mathematical result new.

## Kovalev’s conjecture

The positivity conjecture from arXiv:2507.04544 has a public claimed exact counterexample in [MathDB369172](https://mathdb.com/p/369172/positivity-conjecture-for-trigonometric-polynomials-from-squ). Its distinct zero-free conjecture has an archived solution in PrincipiaMathOrg/math-solutions/site-backup/mathdb-369171. Neither is being counted or pursued before reading those public solutions.
