# Erdős–Graham two-set permutation problem

**Open research, 26 November 2026.** Can the positive integers be partitioned into two sets, each admitting a one-sided enumeration with no increasing or decreasing three-term arithmetic progression as a subsequence? Adding one to every integer gives the same existence question on the positive and the nonnegative integers. A solution must treat arbitrary orders and the requirement that each integer has a finite position. [Erdős problem 197](https://www.erdosproblems.com/197) · [Project issue 926](https://github.com/1337isnot1337/solved-conjectures/issues/926).

Davis, Entringer, Graham and Simmons prove that every enumeration of all positive integers contains an increasing three-term progression. They give a partition into three admissible sets and pose the two-set question in concluding remark 3. Geneson constructs one admissible set of upper density at least $2/3$. Kasel proves that alternating full dyadic intervals fail as a two-set partition. The catalogue, its discussion, the papers and the project claim search on 26 November 2026 yielded no resolution of the two-set question. [Davis et al.](https://mathweb.ucsd.edu/~ronspubs/77_06_no_long_aps.pdf) · [Geneson](https://arxiv.org/abs/2608.12604) · [Kasel](https://arxiv.org/abs/2609.02939) · [Catalogue discussion](https://www.erdosproblems.com/forum/thread/197#post-8586).

## Finite blocks cannot contain every monochromatic progression

Consider a partition into colours $A,B$. Suppose every fixed endpoint belongs to only finitely many monochromatic three-term progressions. Pick $a\in A$ and $b\in B$ of the same parity. Such a pair exists unless a parity class is monochromatic, in which case there are already infinitely many progressions sharing one endpoint.

Put $t=(b-a)/2\ne0$. For all sufficiently large $y\in A$, the point $2y-a$ belongs to $B$, by the endpoint assumption at $a$. If $y+t$ belonged to $B$, the endpoint assumption at $b$ would instead give $2(y+t)-b\in A$. These are the same point. Consequently $y\in A$ implies $y+t\in A$ for every sufficiently large $y$. On each residue class modulo $|t|$ the membership indicator of $A$ is eventually monotone, with the direction determined by the sign of $t$. It therefore stabilizes. The colouring is eventually periodic, which gives a monochromatic infinite arithmetic progression and contradicts the endpoint assumption.

Thus at least one fixed endpoint belongs to infinitely many monochromatic progressions. In particular, a two-colour construction cannot confine all monochromatic progressions to finite, disjoint blocks in their respective colours. Geneson uses this separation between stages for a single admissible set. The order of different monochromatic blocks must play a role in a two-colour construction of this kind. [Geneson, Section 3](https://arxiv.org/abs/2608.12604).

## Reflected copies forced in the other colour

Suppose an infinite $S$ has an admissible enumeration. For every finite $F\subset S$, there are arbitrarily large $y\in S$ satisfying $(2y-F)\cap S=\varnothing$. Otherwise start beyond $\max F$ and the last exception and repeatedly choose $a_i\in F$ with $y_{i+1}=2y_i-a_i\in S$. The sequence increases strictly. For every sufficiently large $i$, the position of $y_i$ exceeds the positions of all members of $F$. The progression $a_i,y_i,y_{i+1}$ therefore forces $y_{i+1}$ to precede $y_i$. An infinite decrease of positions is impossible. This is a consequence of Kasel’s finite-anchor orbit lemma. [Kasel, Lemma 4](https://arxiv.org/abs/2609.02939).

In a putative partition every infinite arithmetic subprogression meets both colours infinitely often, since a cofinite monochromatic tail on that subprogression already contains a copy of all positive integers. Apply the preceding argument after restricting and rescaling to the subprogression. Every finite monochromatic run on it forces arbitrarily distant runs of at least the same length in the opposite colour, along that same subprogression. For example, a partition that gives exactly one member of every pair $\{2n,2n+1\}$ to each colour fails. If a part contains $2j+1,2j+2$, reflecting those two anchors in any sufficiently large $y$ produces a whole even–odd pair, which meets that part. If it contains no such pair, its parity choices are a binary sequence with no transition from one to zero, hence are eventually constant.

## What a fixed finite construction can test

Let the old anchors be finitely many fixed integers and the new values be $tN+u$ for a fixed finite list of integer coefficients with $t>0$. Once $N$ is sufficiently large, a progression of new values projects to an arithmetic progression in each coordinate. Order distinct $t$ by their least significant differing bit, putting zero first. Order the offsets in each fibre by the same rule. For signed offsets in a finite list, the rule can be applied to residues modulo a power of two large enough to distinguish all entries. At the first differing bit of a nonconstant progression, its endpoints have the same bit and its midpoint has the opposite bit. The resulting order thus avoids every progression of three new values. With one old term, that term must be an endpoint and the coefficients of the two new terms must be $t,2t$. The binary order places $2t$ before $t$. Two old terms and one new term cannot form a progression for sufficiently large $N$. Consequently this fixed-size, single-scale test always permits placing all the anchors before the new points, subject to avoiding progressions wholly inside the old list. The order gadget in Kasel’s dyadic obstruction grows with the scale. [Kasel, Sections 5–6](https://arxiv.org/abs/2609.02939).

## Reproducible finite checks

Run `python check.py` with `python-sat==1.9.dev25`. The script uses CaDiCaL 1.9.5. It checks each positive model directly. Negative results below are solver decisions on the displayed finite encodings. No proof-assistant verification or independent certificate replay has been performed. [Check script](check.py).

1. **Prescribed geometric block orders, variable colours.** Each order visits $[1,b+s),[b+s,b^2+s),\ldots$ chronologically and sorts each block by one of six binary rules. The search takes $2\le b_A\le5$, $2\le b_B\le6$, offsets $(s_A,s_B)\in\{(0,0),(0,1),(1,0),(0,2)\}$ and independent binary rules. For each progression monotone in the first order, one clause excludes assigning all three points to $A$. The second order gives the corresponding exclusion in $B$. Each order on $[1,200]$ restricts to its order on $[1,100]$. Of 2,880 order pairs, 75 support a partition on $[1,100]$ and none supports one on $[1,200]$.
2. **Fixed colours, variable orders.** For odd $m$, colour $x$ by $\lfloor\log_2(x^m)\rfloor\bmod2$. Within each colour allow any order in which $x$ precedes every $y>16x$. The Boolean variables orient all pairs, two clauses for each triple give transitivity, and two clauses make the midpoint of each arithmetic progression extremal. On $[1,160]$, an order exists only for colour one when $m=3$, and for neither colour when $m=5,7$. All band indices are computed with integer bit lengths.

For $m=3$ and positive $x<y<z$ in an arithmetic progression, $z<2y$ implies that when $y,z$ have the same colour, they belong to the same band or to bands two indices apart. At a fixed early endpoint $x$, the second case can occur near the bottom of the earlier band and the top of the later band. A construction must also order all the comparable-scale progressions and allow arbitrarily large displacement if needed. The unrestricted problem remains open.
