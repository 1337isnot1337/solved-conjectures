# Erdős–Galvin–Hajnal’s four-configuration avoidance problem

## The original Cohen witness can be specialized by a ccc quotient

Let \(P\) be the sealed finite-condition poset from [the Cohen refinement](https://github.com/1337isnot1337/solved-conjectures/commit/39676805360f6a8f01ba4c4715aef6bfcb5e788f), and \(\dot H\) its generic triple system. Over \(V^P\) there is ccc forcing \(Q\) which makes this particular triple system countably colourable. Furthermore \(P*Q\), like \(P\) alone, is forcing-equivalent **over \(V\)** to \(\operatorname{Add}(\omega,\omega_1)\). This does not identify the quotient \(Q\) with Cohen forcing; in fact it is not equivalent to any \(\sigma\)-3-linked poset by the preservation argument below.

In \(V^P\), let \(Q\) consist of finite partial maps \(f:\omega_1\rightharpoonup\omega\) which are not constant on any hyperedge contained in their domains. Order by extension. To add any one point, assign it a colour not used so far, so the generic union is a countable proper colouring.

Consider the following dense presentation \(D\) of the iteration. Conditions are pairs \((p,f)\) with \(p\in P\), where \(f:s_p\to\omega\) is **total on the finite support**, and no triangle of the finite shadow graph of \(p\) is monochromatic. The order extends both coordinates. The finite map \(f\) is genuinely forced to be in \(Q\): the induced graph on its domain is already permanently settled. For density, first decide an arbitrary name for a finite partial map, then include each of its vertices in the graph condition. The decided map cannot colour any triangle of the expanded condition monochromatically. Assign each additional vertex a distinct fresh colour so as to get a map total on the support. This proves density.

To prove the ccc for \(D\), use the same initial-root \(\Delta\)-system argument as for \(P\), thinning also to a constant finite colour map on the root. Free graph union preserves all graph data; any triangle lies wholly in one old support. The union of the two partial colour maps agrees with each old map and is proper. This proves the ccc of \(D\) and hence \(P\Vdash Q\text{ is ccc}\).

For any initial ordinal segment \(\delta\), restrict the entire pair to \(\delta\). This is a complete projection onto \(D_\delta\). Indeed a strengthening of the restriction freely amalgamates at the graph level by the sealed-page lemma. At the colouring level the new condition already agrees with the total existing map on the shared support. No triangle using the two outside parts can arise, so the union map is proper. Totality on the support is essential; if an old condition left a shared vertex uncoloured, the new condition could supply the last colour in a monochromatic triangle on the old side.

As for \(P\), the subposets on \(\omega\cdot\xi\), \(\xi<\omega_1\), form a continuous tower of complete embeddings. After forcing with one stage, the next quotient is countable and atomless. For any quotient condition pick two fresh vertices in the new interval, assign thresholds zero and the same arbitrary colour to both, and choose whether their mutual graph edge is present. There are no triangles incident to them, so both choices are legal; they give incompatible extensions with the same projection. Hence the successor quotient is Cohen. Finite supports give a Cohen product at the limit.

For comparison, any \(\sigma\)-3-linked forcing preserves the uncountable chromatic number of a fixed ground-model 3-uniform hypergraph. If a condition forces a countable colouring, for each vertex choose a stronger condition deciding its colour; assign the vertex the pair of its decided colour and that condition's linked-class index. A monochromatic ground triple then has three deciding conditions with a common extension, contradiction. Thus \(Q\), which specializes \(\dot H\), cannot have a \(\sigma\)-3-linked dense presentation. In particular it is not equivalent to \(\operatorname{Add}(\omega,\omega_1)\) over \(V^P\): that product is \(\sigma\)-centred. To see the latter for any index set of size at most the continuum, assign distinct binary real codes to all bit coordinates. Over all finite lengths \(m\), there are only countably many tables from \(2^m\) into \(\{0,1\}\). Each finite condition agrees with one such total bit assignment by choosing a prefix length distinguishing all its coordinate codes, and the finite conditions agreeing with a fixed assignment are centred.

The final model of \(P*Q\) still has some four-pattern witness, because it is itself an \(\operatorname{Add}(\omega,\omega_1)\) extension of \(V\). Only the designated first-stage witness is destroyed. This is not a way to force the global nonexistence statement and does not prove or refute the one-Cohen-real question.
