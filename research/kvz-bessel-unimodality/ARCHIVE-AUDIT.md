# Expanded public solution archive audit

Audit date: 20 November 2026.

This supplement concerns only the complete unimodality assertion for
I_nu1(a1 x)/I_nu2(a2 x), with nu1 >= nu2 > -1 and 0 < a1 <= a2.
The stronger log-concavity clause already refuted by Trure remains
excluded. The mathematical proof and its previous reviews are unchanged.

## Reason for the expanded screen

Full solution bodies in public GitHub archives supplied exact earlier
proofs of other targets after ordinary web searches found none.
Consequently this screen uses source identifiers, archive catalogues,
and full nearby solution texts. A database's open label and a negative
name search are not sufficient evidence of an unresolved conjecture.
