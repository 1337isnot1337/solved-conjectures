# Ma–Tang’s random subset-sum threshold conjecture

**Incomplete formalization.** Deterministic grouped- and ordered-fiber components have passed local Lean verification; the other three Mathlib draft modules remain unverified. No catalogue completion status change.

Existing result: [main catalogue entry](https://github.com/1337isnot1337/solved-conjectures/tree/main/results/ma-tang-random-subset-sums), [recorded proof](https://github.com/1337isnot1337/solved-conjectures/blob/main/results/ma-tang-random-subset-sums/PROOF.md), [discovery issue #490](https://github.com/1337isnot1337/solved-conjectures/issues/490), and [publication PR #492](https://github.com/1337isnot1337/solved-conjectures/pull/492). ## Scope

The second [checked core module](../../lean/Conjectures/MaTangCoreIndexed.lean) eliminates the assumption that the input is already grouped. It handles an arbitrary ordered list of column labels and integer coefficients (including zeros), constructs an actual binary selection list of the same length, and proves invariance of the ordinary subset sum modulo three under every type-constant flip fixing the zero type. The endpoint `MaTangCoreIndexed.not_covers_of_type_fibers` then proves that an arbitrary first-coordinate map cannot cover every pair of first coordinate and ternary residue, under the explicit hypothesis that its fiber differences have the specified type-flip representation. This is the deterministic noncoverage reduction from equations (4)–(5); the actual linear-map kernel representation and random occupancy/distribution/asymptotic arguments remain to be verified. Both core modules passed strict compilation, a transitive audit of all 57 source-named declarations (only the three standard axioms), and stock kernel replay. [Reproduce](verify_indexed.py) and see the [exact log](verification/indexed-reproduction.log). Indexed module SHA256 `983c021c9e0bb930d34571517065c28c1ba923e400f91fc75e253d5b28e88388`.

The [checked Init-only module](../../lean/Conjectures/MaTangCoreBalance.lean) proves sign balancing for arbitrary integer representatives modulo three, including zero coefficients, and constructs an exact list of annotated grouped coefficients for which every type-constant binary flip preserving the zero type leaves the ternary sum unchanged. This is the deterministic grouped-list component of equations (4)–(5), not the full subset-sum conjecture. Its endpoint is `MaTangCoreBalance.exists_grouped_constant_fiber`; it does not yet connect the lists to a random linear map or prove the limiting threshold. The pinned Lean 4.35.0 strict compilation passed; all 25 source-named declarations were checked transitively and only `propext` and `Quot.sound` occurred; stock `leanchecker` replay passed. Reproduce with [verify_core.py](verify_core.py); [log and source hash](verification/core-reproduction.log). The scoped source hash is `ddb959fd9a40f664dead70a468aee434a492ec14375941ea567885f3d42a3b80`. This source-named check is narrower than the repository's environment-wide all-owned audit.

The draft [Lean module](../../lean/Conjectures/MaTangRandomSubsetSumsCore.lean) follows equations (4) and (5) of the recorded proof. It replaces the pairing/tripling sign construction by a subset of size (2n mod 3), where n is the number of occupied indices in a nonzero type. It groups the finite signed sum by binary kernel-column types and shows that the second-coordinate subset sum is constant on the chosen first-coordinate fiber.

The endpoint `MaTangRandomSubsetSums.not_surjective_of_kernel_columns` is an attempted formalization of the deterministic noncoverage implication, under an explicit fiber representation and no-singleton hypothesis. It is not an asymptotic or probabilistic theorem.

The second draft [kernel module](../../lean/Conjectures/MaTangRandomSubsetSumsKernel.lean) attempts to discharge the representation hypothesis for an actual binary linear map using a basis of its kernel. The endpoints are `kernel_basis_represents_fiber` and `not_surjective_of_kernel_basis`. A canonical finite-dimensional kernel basis is supplied as a definition; no claim is made about its distribution.

A separate standard-library [finite check](check_core.py) passed 6,361 admissible pairs of column labels and coefficients with k ≤ 4 and r ≤ 2, checking every type-constant flip that preserves the zero type. This validates the tested mathematical construction only. It does not establish any Lean theorem.

The third draft [occupancy module](../../lean/Conjectures/MaTangRandomSubsetSumsOccupancy.lean) counts words with exactly one occupied letter of a given type by a hit/miss equivalence, then bounds a union using an injection into the disjoint union of hit-position classes. Its specialization `singleton_occupancy_card_le` bounds the number of bad words by (2^r-1) k 2 (3·2^r-2)^(k-1). The total number of words is (3·2^r)^k; their uniform normalization would produce the source's union bound. The finite checker also confirmed the exact single-type count and union bound for all 15 pairs 0 ≤ r ≤ 2, 0 ≤ k ≤ 4. This module is still an uncompiled draft, not a verified lemma.
