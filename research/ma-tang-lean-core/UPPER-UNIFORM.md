# Ma–Tang’s random subset-sum threshold conjecture: uniform finite upper bound

`MaTangCoreUpperUniform.uniform_coverage_gt_half` proves strictly greater than half coverage for the actual unordered sample of size `upperSampleSize n` in any commutative associative alphabet model with invertible translations, for `n ≥ 65536`. Every finite abelian group satisfies these algebraic hypotheses, taking the inverse translation of x by a to be x−a. `coveredB_spec` states that the covering numerator counts precisely the samples whose literal subset sums contain every point.

The bridge first checks that permutation leaves literal subset-sum membership unchanged. Each unordered subset has the same number of orderings, and the same factor appears in both numerator and denominator; the strict inequality transfers. The proof reuses the [existing lower-bound sampling infrastructure](../../lean/Conjectures/MaTangCoreUniformSubset.lean) and the [checked occupancy upper proof](UPPER-COLLISION.md).
