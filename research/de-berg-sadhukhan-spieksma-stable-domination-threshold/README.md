# de Berg–Sadhukhan–Spieksma’s stable domination threshold

**Resolved.** In the vertex-arrival model, minimum dominating
set admits a stable approximation scheme precisely for
maximum-degree bounds at most two. At maximum degree three,
even on bipartite graphs, some fixed approximation guarantee
strictly greater than one requires linear worst-case
recourse. The proof uses an online degree reduction and a
bounded-size block algorithm for the positive direction.
