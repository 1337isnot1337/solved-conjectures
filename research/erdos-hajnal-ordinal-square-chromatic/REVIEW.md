# Mathematical review and extension

An independent internal review independently reconstructed the square transfer, checked the original question and its forcing inputs against the source audit, and found the finite-power extension below. This is a written mathematical review, not external refereeing or formal verification.

For the square, the reviewers used two local arguments. The main proof bounds the degree of the projected graph on nonfull rows. Alternatively, the row cutoffs define a closure club in the regular cardinal. Intervals between consecutive closure points have size below the cardinal, and an edge between nonfull rows cannot cross such a point. Both arguments use precisely the strict inequality in the edge rule and apply even if the nonfull rows collectively form an unbounded set. A row of full size gives a cofinal color in any coloring with fewer than the cardinal's colors. The two quoted model results concern cardinal-local noncompactness; neither is by itself a prior resolution of the ordinal question. The separate smaller-chromatic-number question remains outside the independence claim.

## Finite ordinal powers

Fix a regular uncountable cardinal $`\kappa`$ and infinite cardinals $`\mu<\theta\le\kappa`$. For each positive integer $`d`$, the existence of a graph of chromatic number $`\theta`$ on $`\kappa^d`$ with every subset of smaller inherited order type $`\mu`$-colorable is equivalent to the cardinal-local assertion on $`\kappa`$.

The reverse implication is immediate since a subset of cardinality below $`\kappa`$ has order type below $`\kappa`$. For the forward construction, induct on the finite power, using the cardinal-local assertion for the first power. Let $`H`$ be the graph at order type $`\eta=\kappa^d`$ and choose a bijection $`r:\eta\to\kappa`$. Replace each row index $`i<\eta`$ by a row of length $`\kappa`$, ordered lexicographically with index first. The vertex order is $`\kappa\cdot\eta=\kappa^{d+1}`$. For row indices $`i,j`$ with $`r(i)\lt r(j)`$, join $`(i,s)`$ to $`(j,t)`$ exactly when $`\{i,j\}\in E(H)`$ and $`r(j)\lt s`$. The bijection is only a label for the edge rule; it is not assumed to preserve the ordinal row order.

Projection gives the upper chromatic bound. In any putative coloring with fewer than $`\theta`$ colors, select one cofinal color in each row. The two selected colors on an edge of $`H`$ must differ: in the earlier-in-label row, choose a vertex of its selected color past the later row's label, and in the later row choose a vertex of its selected color. This proves the lower chromatic bound.

For a subset of smaller order type, the inherited order type of its set of full rows is strictly below $`\eta`$: otherwise the full rows alone have order type $`\kappa\cdot\eta`$. Thus the induction hypothesis colors the projection of the full rows. For each nonfull row, the labels of earlier possible neighbors and the cutoff on later possible neighbors are bounded below $`\kappa`$, so the projected graph restricted to nonfull rows has degree less than $`\kappa`$ at each vertex. Each component has cardinality less than $`\kappa`$, by regularity and uncountability. Its set of row indices therefore has order type less than $`\eta`$ and is colorable by the induction hypothesis. Color all these components in one palette and use a disjoint palette on the full rows. Two palettes still use only $`\mu`$ colors.

If $`\theta=\kappa`$, no other order type in the closed interval from $`\kappa`$ to $`\kappa^\omega`$ is possible. Below $`\kappa^\omega`$, choose the largest finite power $`\kappa^d\le\alpha`$; if the inequality is strict, the ordinal division $`\alpha=\kappa^d\cdot\xi+\tau`$ has $`\xi<\kappa`$ and $`\tau<\kappa^d`$. This partitions the vertices into fewer than $`\kappa`$ sets each of order type less than $`\alpha`$. At $`\kappa^\omega`$ use the countably many intervals between successive powers instead. In either case fresh palettes for the parts use fewer than $`\kappa`$ colors, a contradiction.
