# Simon's Le Roy complete-monotonicity conjecture

The completed result is published in [results/simon-le-roy](../../results/simon-le-roy/README.md).

The exact counterexample interval has $\alpha=1/3$, $\gamma=2$, and
$13/30\leq\beta<\frac13(1+\log(32/21)/\log4)$. The [main proof](EXPLICIT_PROOF.md) uses Dufresne's classical construction and gives the interval explicitly. The [alternative density proof](CANDIDATE_PROOF.md) is retained as an independent argument.

The [source audit](NOVELTY.md) records the bounded prior search and full-text access limits. The [root review](AUDIT-ROOT.md), [algebra review](AUDIT-ALGEBRA.md), and [Dufresne audit](DUFRESNE-AUDIT.md) are separate internal reviews. Both written proofs passed, and the exact verifier passed independently in two lanes.
