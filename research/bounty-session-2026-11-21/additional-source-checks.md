## Gaussian fourth-power exclusions

The [2011 primary article by Filip Najman](https://www.math.okayama-u.ac.jp/mjou/mjou53/_04_najman.pdf), printed p.78, invokes Hilbert's theorem that `x^4 ± y^4 = ±z^2` has only trivial solutions in Gaussian integers. Signatures reducing to this equation are already excluded by existing mathematics. Finite searches in those signatures are verification provenance, not new negative results.

## Gaussian Catalan classes

The [sponsor's own Catalan paragraph](https://mathpuzzle.com/Gaussians.html) already lists

```math
(78+78i)^2+(23i)^3=i,
```

```math
1+(1-i)^5=(1+2i)^2,
```

```math
i+(11+11i)^2=(3i)^5.
```

The ordinary class `1^r+2^3=3^2` is also old. Allowing a unit raised to a larger exponent can satisfy the reciprocal-exponent inequality, but does not create a new power triple. All four classes were added to the root search's exclusion checker. No claim is made that this finite list exhausts the prior literature.
