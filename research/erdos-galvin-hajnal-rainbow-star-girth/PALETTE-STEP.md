# Erdős–Galvin–Hajnal’s rainbow-star girth problem

## A $`C_4`$-free infinite-palette witness against every finite vertex palette

There is a graph of girth six with a fixed countably infinite edge palette such that every finite vertex colouring gives a vertex seeing infinitely many neighbours of its own colour at **each** edge label. The host is necessarily uncountable by the [countable negative theorem](../../results/erdos-galvin-hajnal-rainbow-star-girth/PROOF.md). This also disproves any absolute finite bound on the number of classes needed to partition arbitrary $`C_4`$-free graphs into induced locally finite graphs. This is a larger-host supplement to the published Problem 7 result; it is not a new solution of that countable problem.

**Palette step.** Fix an infinite edge-label set $`I`$ and an infinite target multiplicity $`\mu`$. Say a graph is good for $`k`$ if every $`k`$-colouring (not necessarily surjective) gives some vertex with at least $`\mu`$ same-colour neighbours at each label. Suppose a graph $`H`$ of size $`\theta`$ is good for $`k`$, and
```math
|I|<\mathop{\mathrm{cf}}(\theta),\qquad \mu\le\theta.
```
There is a graph $`H'`$ of size $`2^\theta`$ good for $`k+1`$, with no triangle, four-cycle or five-cycle unless there is one already in $`H`$.

Take an independent anchor set $`A`$ of size $`\theta`$. For each injection $`f:V(H)\to A`$ and each $`i\in I`$, take $`2^\theta`$ fresh disjoint copies of $`H`$. In each such copy, join every copy vertex $`v^*`$ to its one anchor $`f(v)`$, using label $`i`$. Retain the existing labels inside copies. There are at most $`\theta^\theta=2^\theta`$ injections, so this uses exactly $`2^\theta`$ vertices.

In a purported avoiding $`(k+1)`$-colouring, assign to every anchor some label at which it has fewer than $`\mu`$ neighbours of its own colour. Since $`|I|<\mathop{\mathrm{cf}}(\theta)`$, some $`\theta`$ anchors have both the same vertex colour $`a`$ and the same deficient label $`i`$. Fix an injection $`f`$ into those anchors. Across the corresponding $`2^\theta`$ copies, the chosen anchors together are incident with at most $`\theta\cdot\mu=\theta`$ same-colour spokes of label $`i`$. There is a whole copy having no such spoke, so none of its vertices has colour $`a`$. Its induced $`k`$-colouring contradicts the property of $`H`$.

For the girth claim, a cycle that uses exactly one anchor would have to return to that anchor through a second neighbour in the same copy, impossible by injectivity unless it visits another anchor. In a cycle with at least two anchors, travelling from one anchor to the next requires a spoke at each end and at least one intra-copy edge, because each copy vertex has only one anchor. Thus any such cycle has length at least six. If $`H`$ has an edge, two copies from a single $`(f,i)`$ group give a six-cycle using that edge in each copy and the two shared anchors. This obstruction to girth above six is specific to this repeated-copy step, not a universal upper bound.

**Consequences in ZFC.** For $`I=\omega,\mu=\aleph_0`$, the [rectangular-colouring construction](TWO-COLOUR-SUCCESSOR.md) starts at $`\theta_2=\aleph_1`$ with a graph good for two and girth eight. Put $`\theta_{k+1}=2^{\theta_k}`$. König’s theorem gives $`\mathop{\mathrm{cf}}(2^{\theta_k})>\theta_k`$, so the step continues. The disjoint union of one resulting graph for each finite $`k\ge2`$ has cardinality $`\sup_k\theta_k`$ and girth six, with the asserted property against every finite vertex palette. There is no need to make one fixed finite $`k`$ work by increasing the graph order on a finite search; the single constructed infinite host treats all finite palettes.

**Sharpness under local GCH.** If $`2^{\aleph_j}=\aleph_{j+1}`$ for $`1\le j<n`$, the construction gives at $`\aleph_n`$, for every $`n\ge1`$, a $`C_4`$-free graph good for $`n+1`$, with the same countable edge palette and infinite multiplicity. The [list-colouring upper bound](SUCCESSOR-HOSTS.md) gives an avoiding $`(n+2)`$-colouring for every $`C_4`$-free graph on at most $`\aleph_n`$ vertices, in ZFC. For $`n=0`$ a countable labelled star gives sharpness. Thus the full finite-successor hierarchy of bounds is sharp under GCH, and the first successor is already sharp in ZFC. The construction does not assert sharpness at $`\aleph_n`$ in arbitrary continuum patterns, or arbitrarily large ordinary girth for the single all-finite-palettes witness.

**Source boundary.** [EGH (1975), §9 Problem 7](https://www.renyi.hu/~p_erdos/1975-24.pdf#page=42) asks for countable hosts. The [same-cardinality supplement](FINITE-PALETTES.md) takes palette and host of the same cardinality in its girth obstruction. Neither is contradicted: here the edge palette is held fixed while the host grows. The two-colour base case uses Moore's theorem, which is credited in its proof.
