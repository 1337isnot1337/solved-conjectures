# Arithmetic and affine-system routes for Shallit 14

Status, 2026-11-21: literature check and exact reductions. No decision algorithm for the full problem, undecidability proof, Lean verification, submission, or prize claim. Coordination: [issue 229](https://github.com/1337isnot1337/solved-conjectures/issues/229).

The target is to decide, from a base-$`k`$ synchronous DFA relation $`R\subseteq\mathbb N^2`$, whether

```math
\exists p,q\quad R(p,q)\land p>0\land p\mid q.
```

Zero-numerator cases are regular and can be checked separately. The [target note](README.md) records the original statement, the personal £50 offer, and the distinction from the 2017 undecidability theorem for base-power quotients.

## A correct Presburger subcase

Suppose an effective Presburger formula $`\varphi(p,q)`$ is supplied for $`R`$. Presburger quantifier elimination converts it to an existential formula, allowing congruence predicates with fixed integer moduli. The sentence

```math
\exists p,q\quad \varphi(p,q)\land p>0\land p\mid q
```

then belongs to existential Presburger arithmetic with divisibility. This gives a terminating procedure by [Lechner–Ouaknine–Worrell](https://www.cs.ox.ac.uk/james.worrell/LICS-main.pdf), Corollary 15.

A more specific reduction uses the quotient as the sole parameter. For an existential Presburger input formula, form

```math
\psi(t):=\exists p,q\quad
\varphi(p,q)\land p>0\land t\ge0\land q=tp.
```

All products introduced have the form “parameter times variable.” Thus $`\psi`$ belongs to one-parametric Presburger arithmetic. Existence of a parameter value satisfying $`\psi`$ is precisely the satisfiability problem treated in [Mansutti–Starchak](https://arxiv.org/html/2506.23730v1), Theorem 3. Their NP upper bound applies to the size of this supplied existential formula. It is not an NP bound in the size of an arbitrary DFA.

The obstacle is mathematical, not merely a missing conversion implementation. The set of powers of $`k`$ is radix-automatic and is not ultimately periodic, hence is not Presburger-definable. An arbitrary DFA relation therefore need not be semilinear. Replacing a word by its Parikh vector also discards positional information: the binary strings `10` and `01` have the same digit counts and different values.

This section records a restricted consequence of existing theorems. It is not a new bounty solution.

## Why the Büchi and Semënov procedures do not combine automatically

The Büchi valuation function records the largest power of a fixed base dividing an integer. In the prime-base case, it describes one prime's valuation. Ordinary $`p\mid q`$ requires the valuation inequality at every prime dividing the variable $`p`$. Substituting a single valuation relation changes the target.

There is a separate expressiveness problem. [Haase–Różycki](https://www.cs.ox.ac.uk/people/christoph.haase/home/publication/hr-21/hr-21.pdf), Theorem 1, exhibits an automatic set without an existential Büchi definition; their example uses the language $`\{01,10\}^*`$. Their Theorem 2 gives a definition with an additional quantifier alternation. Therefore a decision theorem restricted to existential Büchi formulas is not a general DFA decision theorem. Their polynomial-growth result does not remove the extra divisibility atom either.

The 2024 generalized Semënov theorem is closer: it explicitly permits arbitrary regular predicates. Its normal form is a conjunction of linear equations, equations $`x=2^y`$, and regular predicates. Introducing a quotient variable yields $`q=pr`$, which is outside that normal form. Knowing that $`r=2^s`$ would still leave the variable product $`p2^s`$; it is not the same operation as a single exponential atom.

The paper's counter-system result is similarly restricted. Definition 5 pairs a counter that eventually increments at every step with a counter that updates by doubling and adding a bit; acceptance equates each pair. Proposition 9 proves emptiness decidable for this restricted class. It does not decide arbitrary affine-counter reachability or permit subtraction of one counter's current value from another. Those are the operations needed by the direct formulation below.

No closure theorem inspected here allows one to combine the separate decidable arithmetic signatures while retaining decidability.

## Exact affine-counter formulation

There is a direct reduction with only two integer counters. It isolates a concrete class for further investigation, without solving its reachability problem.

First intersect the input DFA with the regular condition $`p>0`$. Start counters $`(x,y)=(0,0)`$. For a most-significant-digit-first edge labeled $`(a,b)`$, update

```math
(x,y)\longmapsto(kx+a,ky+b).
```

After an accepting DFA path, the counters contain its represented pair $`(p,q)`$. Add a one-way transition into a second phase with the single loop

```math
(x,y)\longmapsto(x,y-x).
```

Then allow a one-way transition into a third phase with the single loop

```math
(x,y)\longmapsto(x-1,y).
```

The final target is exactly $`(0,0)`$ in the third phase. If the second and third loops are repeated $`r,s\ge0`$ times, the final vector is

```math
(p-s,q-rp).
```

It is zero if and only if $`s=p`$ and $`q=rp`$. Thus target reachability is equivalent to the original divisibility question. The same argument works with nonnegative-counter semantics: a successful subtraction path never becomes negative. With integer-counter semantics, negative values introduce no false positive, because the displayed final-value formula is exact.

The linear parts of all transitions belong to the commuting family generated by

```math
D=kI_2,\qquad
S=\begin{pmatrix}1&0\\-1&1\end{pmatrix},\qquad I_2.
```

The affine maps themselves do not commute: their translation vectors matter. The matrix monoid is infinite because the powers of $`D`$ are distinct. It is not the all-ones-matrix monoid from the LMCS 2021 positive result. Conversely, undecidability for general monogenic affine systems does not imply undecidability for these two-counter systems with this fixed phase order.

**Concrete missing theorem.** Decide zero reachability for an arbitrary regular first phase of radix updates, followed by one shear loop and one unit-decrement loop. Proving this would resolve Shallit 14. Merely reformulating the question as this reachability problem does not do so.

## Rational-subset encoding and its two gaps

Let

```math
G_k=\mathbb Z[1/k]^2\rtimes\mathbb Z,
\qquad
(u,m)(v,n)=(u+k^m v,m+n).
```

Map a digit pair $`(a,b)`$ to $`((a,b),1)`$. Read an accepted word in reverse, so its digits are least significant first. The group product is then $`((p,q),\ell)`$, where $`\ell`$ is its length. Reversal preserves regularity, so the input DFA gives a rational subset of $`G_k`$.

The desired target is

```math
T=\{((p,q),\ell):p>0,\ q\ge0,\ \ell\ge0,\ p\mid q\}.
```

The ICALP 2020 theorem is about
$`\mathrm{BS}(1,k)\cong\mathbb Z[1/k]\rtimes\mathbb Z`$,
which has one translation coordinate. Moving to $`G_k`$ requires an additional theorem. Even a membership algorithm for rational subsets of $`G_k`$ would still leave the need to decide intersection with $`T`$. Membership of one specified group element and intersection with the union of all integer-slope lines are different tasks. No effective rational or other permitted presentation of $`T`$ has been established here.

## A growth obstruction to the almost-commuting route

This is an elementary consequence of [Pimpalkhare–Kincaid–Reps](https://www.cs.princeton.edu/~zkincaid/_static/pub/popl26b.pdf), Definition 1. It is stated to rule out a direct faithful representation, without a novelty claim.

**Lemma.** For any finite subset $`A`$ of a standard almost-commuting monoid, the number of distinct products of at most $`n`$ elements of $`A`$ is polynomially bounded in $`n`$.

**Proof.** Use the definition's finite set $`F`$, commutative monoid $`C`$, and action $`\triangleleft`$. Choose a decomposition $`1=f_0\triangleleft c_0`$. For every $`a\in A`$ and $`f\in F`$, choose one decomposition

```math
af=f_{a,f}\triangleleft c_{a,f}.
```

If a suffix product is $`f\triangleleft c`$, prepending $`a`$ gives, by the reassociativity and action identities,

```math
a(f\triangleleft c)
=(af)\triangleleft c
=f_{a,f}\triangleleft(c_{a,f}+c).
```

Consequently every product of at most $`n`$ generators has a representation

```math
f\triangleleft\left(c_0+
\sum_{(a,g)\in A\times F}m_{a,g}c_{a,g}\right),
\qquad 0\le m_{a,g}\le n.
```

There are at most $`|F|(n+1)^{|A||F|}`$ such representations, so at most that many distinct products. The action need not be injective; collisions only reduce the count. $`\square`$

Now consider the two radix maps $`f_0(x)=kx`$ and $`f_1(x)=kx+1`$. Their $`2^n`$ words of length $`n`$ are distinct affine maps: each has slope $`k^n`$ and a different translation whose length-$`n`$ radix expansion uses only digits zero and one. This contradicts the lemma's polynomial bound. Thus the radix-update monoid is not a standard almost-commuting monoid. The paired-digit version contains the same obstruction.

This rules out a faithful application of that framework to all radix maps. It does not rule out a different abstraction preserving only the decision answer, a special input class, or an unrelated decision algorithm.

## What remains unresolved

The inspected results give restricted algorithms and several precise failures of proposed theorem applications. They do not decide the full target. A useful next advance would be one of the following:

- a decision theorem covering the exact two-counter phase structure above;
- a complete effective criterion for intersection of the corresponding rank-two affine rational set with $`T`$;
- a sound undecidability reduction in which every incidental integer quotient also implies a valid source computation.

The existing [finite-modulus obstruction](decision-approach.md) and [base-power promise theorem](power-only-promise.md) constrain simpler versions of these routes. None is counted as a solved bounty.
