# Sharp target overlap of full-rank Clifford branches

Status: exact overlap bounds for the specified full-rank branch class. The tagged and untagged sources have different bounds. Rank-deficient branch maps are not included in the sharp formulas.

Put $`q=2^n`$, $`N=M=2^u`$. The normalized target state is
```math
\psi=T_{q,N}/\|T_{q,N}\|,\qquad
T_{q,N}=U_{ACD}(q)U_{BCD}(q)W_{AB}(N).
```
At $`A`$, call the outer bits $`i`$ and flag bits $`f_A`$. At $`B`$, call them $`j,f_B`$. The $`C`$ bits are $`i_C,j_C`$; $`D`$ has the copied outer pair. Write Pauli labels additively over $`\mathbb F_2`$, ignoring their fixed eigenvalue phases when counting dimensions.

The subgroup $`K`$ of target stabilizers supported on $`ABC`$ is generated by
```math
Z_{A,i_\ell}Z_{C,i_\ell},\quad
Z_{B,j_\ell}Z_{C,j_\ell}\quad(1\le\ell\le n),
\qquad
Z_{A,f_t}Z_{B,f_t},\quad
X_{A,f_t}X_{B,f_t}\quad(1\le t\le u).
\tag{1}
```
It has dimension $`2n+2u`$. Its projection to $`C`$ is isotropic. Its $`AB`$ transfer algebra consists of flag operators, and its Pauli $`AB`$ transfers form the $`2u`$-dimensional flag symplectic space. It has no non-scalar common $`ABC`$ transfer.

For a stabilizer-code projector $`P`$ on $`ABC`$, its branch overlap means
$`\langle\psi,(P\otimes I_D)\psi\rangle`$. An arbitrary $`D`$ map cannot enlarge this branch support.

## 1. Tagged source: the maximum can be $`q^{-1/2}`$

The tagged source is
```math
\widehat S_{q,N}
 =U_{ABCD}(q)W_{CD}(q)W_{AD}(N)W_{BD}(N).
```
Its $`ABC`$ coefficient code has the $`2n`$ stabilizers
$`Z_{h,A}Z_{h,B}`$, $`Z_{h,A}Z_{h,C}`$. Apply arbitrary unitary Clifford maps at $`A,B,C`$. Let $`P_A,P_B,P_C`$ be the resulting injective commuting Pauli-label embeddings of $`V=\mathbb F_2^n`$. The source-code stabilizer label space is
```math
S=\{(P_A(v+w),P_B(v),P_C(w)):v,w\in V\}.
\tag{2}
```
It still has dimension $`2n`$.

The exact maximum overlap is
```math
\boxed{
\max\langle\psi,(P_S\otimes I_D)\psi\rangle
 =2^{-\max\{n-u,\lceil n/2\rceil\}}.
}
\tag{3}
```
In particular, for $`u\ge\lfloor n/2\rfloor`$, it is
$`2^{-\lceil n/2\rceil}`$. A universal tagged bound $`1/q`$ is false.

To prove the upper bound, identify $`H=S\cap K`$ with its preimage in $`V\oplus V`$. Let
```math
U=\{v:(v,0)\in H\},\qquad
W=\{w:(0,w)\in H\}.
```
Both kernels have dimension at least $`\dim H-n`$. If a nonzero label lay in $`U\cap W`$, both transfer equalities for that same label would hold on the target, giving a non-scalar common $`ABC`$ transfer. Therefore $`U\cap W=0`$, and
```math
2(\dim H-n)\le\dim U+\dim W\le n.
\tag{4}
```
Also, $`U`$ is a commuting subspace of the target's $`AB`$ flag-transfer space. It is isotropic, so $`\dim U\le u`$. Projecting $`H`$ onto its second coordinate now gives
```math
\dim H\le n+u,\qquad
\dim H\le\lfloor3n/2\rfloor.
\tag{5}
```
The overlap is zero if eigenvalue phases disagree. Otherwise it is
$`2^{\dim H-2n}`$. Equations (5) prove the upper bound in (3).

Here is a sharp construction. Let $`m=\min\{u,\lfloor n/2\rfloor\}`$. For each of $`m`$ disjoint two-label blocks, use one flag bit and one outer bit at each party, and set
```math
\begin{array}{c|cc}
 &e_1&e_2\\ \hline
P_A&Z_{A,f}&Z_{A,i}\\
P_B&Z_{B,f}&Z_{B,j}Z_{B,f}\\
P_C&Z_{C,i}Z_{C,j}&Z_{C,i}.
\end{array}
\tag{6}
```
The three independent target stabilizers in this block are the source $`AB`$ transfer for $`e_1`$, the source $`AC`$ transfer for $`e_2`$, and the source $`BC`$ transfer for $`e_1+e_2`$. Thus this block contributes three dimensions to $`H`$, although it has only two shared labels. No equal nonzero label has both $`AB`$ and $`AC`$ transfer.

For each remaining shared label, use
$`P_A=Z_{A,i}`$, $`P_B=Z_{B,j}`$, $`P_C=Z_{C,i}`$ on fresh outer coordinates. It contributes one target stabilizer. All displayed local label families are independent and isotropic and hence extend to Clifford changes of basis by symplectic basis completion. The total intersection dimension is $`3m+(n-2m)=n+m`$, attaining (5). The displayed intersection generators have matching positive phases, so the overlap is nonzero and equals (3).

## 2. Untagged source: the maximum is at most $`1/q`$

For the original source
```math
S_{q,N}=U_{ABC}(q)W_{CD}(q)W_{AD}(N)W_{BD}(N),
```
the $`ABC`$ coefficient code has $`3n`$ stabilizers: the two $`Z`$-transfer families and the additional
$`X_{h,A}X_{h,B}X_{h,C}`$ family.

After arbitrary unitary Clifford maps at $`A,B,C`$, the exact maximum overlap is
```math
\boxed{
\max\langle\psi,(P_S\otimes I_D)\psi\rangle
 =2^{-(2n-\min\{n,u\})}.
}
\tag{7}
```
For $`u\ge n`$, this equals $`1/q`$.

The projection of the source stabilizer space to $`C`$ is a nondegenerate $`2n`$-dimensional symplectic subspace, generated by the conjugated $`Z_h,X_h`$. The target's $`C`$ projection in (1) is isotropic. Consequently the $`C`$ projection of $`H=S\cap K`$ has dimension at most $`n`$. The kernel of this projection is made of source $`AB`$ $`Z`$-transfers lying in the target flag-transfer space. It is isotropic and has dimension at most $`\min\{n,u\}`$. Hence
```math
\dim H\le n+\min\{n,u\}.
\tag{8}
```
Using source dimension $`3n`$ gives (7).

For sharpness, on each of $`\min(n,u)`$ disjoint blocks choose the source logical Pauli images
```math
\begin{array}{c|cc}
 &Z_h&X_h\\ \hline
A&Z_{A,f}&X_{A,f}Z_{A,i}\\
B&Z_{B,f}&X_{B,f}Z_{B,j}\\
C&X_{C,i}&Z_{C,i}Z_{C,j}.
\end{array}
\tag{9}
```
Each row is a hyperbolic Pauli pair and extends to a local Clifford. The source $`AB`$ $`Z`$-transfer is a target flag stabilizer. Its $`X_AX_BX_C`$ stabilizer is the product of one target flag-$`X`$ stabilizer and the two copied-outer $`Z`$ stabilizers. Thus each such block contributes two intersection dimensions. Every remaining block uses the usual $`Z_h,X_h`$ images on the outer $`i,j,i_C`$ bits and contributes the one $`AC`$ copied-$`Z`$ stabilizer. This attains (8), with consistent phases.

## 3. Consequences for interference between full-rank branches

These overlaps concern the support codes, not selected normalized branch vectors. Arbitrarily large middle coefficients do not change them.

For two branch code projectors, the span lemma in
[CONTROLLED_STABILIZER_SPAN.md](CONTROLLED_STABILIZER_SPAN.md) gives
```math
\Pi_{\mathop{\mathrm{im}}P_1+\mathop{\mathrm{im}}P_2}
 \le\frac{P_1+P_2}{1-1/\sqrt2}.
\tag{10}
```
Thus two full-rank untagged Clifford branches cannot span the target when $`q\ge8`$, because their total overlap is at most $`2/q<1-1/\sqrt2`$. Two tagged branches cannot span it when $`n\ge5`$, because their total overlap is at most
$`2^{1-\lceil n/2\rceil}<1-1/\sqrt2`$.
These are restricted exact statements, not claims about arbitrary rank-deficient outside maps.

More generally, for branch stabilizer groups $`S_b,S_c`$, let $`d_{bc}\ge1`$ be the commutation rank when their code projectors do not commute. Formula (3) of the span note gives
$`\|P_bP_c\|\le2^{-d_{bc}/2}`$. Set
```math
\eta=\max_b\sum_{\substack{c\ne b\\P_bP_c\ne P_cP_b}}
 2^{-d_{bc}/2}.
```
Repeating its anticommutator proof yields
```math
\left(\sum_bP_b\right)^2\ge(1-\eta)\sum_bP_b.
\tag{11}
```
If $`\eta<1`$, any exact cover of the target therefore requires
```math
1-\eta\le\sum_b\langle\psi,P_b\psi\rangle.
\tag{12}
```
In the large-flag tagged case the right side is at most
$`r\,2^{-\lceil n/2\rceil}`$; in the untagged case it is at most $`r\,2^{-n}`$.

For example, if every noncommuting pair has
$`d_{bc}\ge2\log_2(2r)`$, then $`\eta<1/2`$. A number of such broadly separated codes polynomial in $`n=\log_2q`$ cannot cover the target for large $`n`$. A possible cover with a number of branches polynomial in $`n`$ must instead have sufficiently many tightly aligned code pairs with small commutation ranks, or leave this full-rank Clifford class. Equation (12) is the exact constraint; it does not by itself construct a cover when $`\eta\ge1`$.
