# An iid counterexample with jointly universally measurable evaluation

For each $`n\ge2`$ there is a VC-one class of distinct binary predictors on a standard Borel feature space, with a standard Borel name space and **jointly universally measurable** evaluation. The name sigma-algebra is generated by countably many prediction queries. The class has distribution-uniform convergence in outer probability. Yet for one iid law, every proper learner with measurable actual output in the completed experiment of Definition 3 has a size-$`n`$ sample with empirical optimum zero and expected empirical loss one.

There is also a single class and a single iid law with the same conclusion at every $`n\ge2`$. The single class has outer uniform convergence separately under every labeled law. No information upper bound is needed in either construction. The proofs are in ZFC. [Conjecture 6 and Definition 3](https://proceedings.mlr.press/v125/steinke20b/steinke20b.pdf)

## Full-outer matchings of the required cardinality

Let $`\kappa`$ be the least cardinality of a set of reals of positive Lebesgue outer measure. This is also the least cardinality of a non-Lebesgue-measurable set of reals. If $`\kappa<2^{\aleph_0}`$, a set of size $`\kappa`$ with positive outer measure cannot be measurable since a measurable set of positive measure has cardinality continuum. If $`\kappa=2^{\aleph_0}`$, every nonmeasurable set has cardinality continuum. By Grzegorek's theorem there is a set $`N\subseteq(0,1]`$ of cardinality $`\kappa`$ that is universally null, meaning it has outer measure zero under every atomless Borel probability. [Grzegorek's theorem, stated as Theorem 2.8 by Larson, Neeman and Shelah](https://shelah.logic.at/files/94751/947.pdf) · [Grzegorek's related projection construction](https://www.dml.cz/bitstream/handle/10338.dmlcz/701185/WSAA_08-1980-1_25.pdf)

For every $`m\ge2`$ we construct a full-outer-Lebesgue-measure $`G\subseteq[0,1]^m`$ of size $`\kappa`$ on which each coordinate projection is injective. When $`\kappa=2^{\aleph_0}`$, enumerate the positive-measure Borel subsets of the cube. At each step Fubini allows choosing a point in the current set one coordinate at a time. At each coordinate there are continuum many choices preserving positive measure of the remaining section, and fewer than continuum many values previously used in that coordinate. This produces an injective matching meeting every positive-measure Borel set. Its size is continuum because it has full outer measure in the cube, whose Lebesgue probability is isomorphic modulo null sets to that of the interval.

Suppose $`\kappa<2^{\aleph_0}`$. A positive-outer-measure set of size $`\kappa`$ is full outer relative to a Borel measurable hull, since removing a Borel subset of the hull disjoint from the set cannot lower the hull's measure. Normalize Lebesgue measure on the hull. The atomless standard probability isomorphism theorem, after discarding Borel null sets, takes the set to a full-outer-measure set $`E\subseteq[0,1]^m`$ of size at most $`\kappa`$. [Atomless probability isomorphism, Larson, Neeman and Shelah, Theorem 1.1](https://shelah.logic.at/files/94751/947.pdf)

For distinct $`x,y\in E`$, the polynomial $`\sum_{i=1}^m(x_i-y_i)t^{i-1}`$ is nonzero and has finitely many real roots. The union of the forbidden roots over all pairs has cardinality at most $`\kappa`$. Choose $`m`$ distinct real numbers outside it. The Vandermonde matrix $`L`$ with rows $`(1,t,\ldots,t^{m-1})`$ at these numbers is invertible, and every coordinate projection is injective on $`L(E)`$. Invertible linear maps preserve the measure-zero sets, so $`L(E)`$ is full outer relative to the parallelepiped $`L([0,1]^m)`$. Choose a closed axis-aligned box of positive volume in its interior and restrict to this box. Rescaling its coordinates separately gives the required matching in $`[0,1]^m`$. Its size is at most $`\kappa`$ by construction and at least $`\kappa`$ by full outer measure and the atomless probability isomorphism theorem.

Every nonempty coordinate projection of the matching has full outer measure in its smaller product cube. Otherwise the inverse image of a positive Borel set disjoint from that projection would be a positive Borel set disjoint from the full matching.

## Predictor class and joint universal measurability

Use either one level or countably many levels. At level $`j`$ take $`m_j\ge2`$ sectors, each a copy of $`[0,1]`$, and the preceding matching $`G_j`$. The feature space is the disjoint union of the sectors and one separate copy of $`[0,1]`$ for threshold queries. Take the entire standard Borel interval $`H=[0,1]`$ as the name space. Partition $`N`$ into sets $`N_j`$ of cardinality $`\kappa`$ indexed by the levels, and fix bijections $`\gamma_j:N_j\to G_j`$. The name $`h\in N_j`$ predicts one precisely at the sector points $`(j,i,\gamma_j(h)_i)`$ for $`1\le i\le m_j`$. Names outside $`N`$ predict zero on all sectors. At a threshold query $`t`$, any name $`h`$ predicts $`1_{\{t<h\}}`$. In particular name zero is the all-zero classifier.

The rational threshold queries recover the name as the supremum of those predicting one, with zero used when there are none. Thus predictors are distinct and the sigma-algebra generated by predictions is precisely the Borel sigma-algebra. For each sector point there is at most one positive name, and each name has only finitely many positive sector points. A pair of sector points either have the same unique positive name or cannot both be positive. A pair with one sector point cannot be shattered because a positive bit there fixes the name. Two threshold queries are nested. Thus no pair is shattered, while a single query is, giving VC dimension one.

To verify joint universal measurability, fix **any** Borel probability $`\rho`$ on the product of the name and feature spaces. Let $`\nu`$ be its name marginal and $`A`$ the countable Borel set of atoms of $`\nu`$. On $`A`$ the sector positive relation is a countable union of measurable rectangles, since the sector support of each name is finite. Outside $`A`$ it is contained in $`(N\setminus A)\times X`$, with $`X`$ the feature space. The restriction of $`\nu`$ to the complement of $`A`$ is atomless, so $`N\setminus A`$ has a Borel $`\nu`$-null cover. Thus the sector positive relation on that part is measurable in the completion of $`\rho`$. The threshold relation is jointly Borel. This proves the joint assertion, including for measures coupling the name and feature.

## Failure of the empirical bound in the actual iid experiment

Use a law $`D`$ with all labels one and with positive mass on each level, uniform sector within a level, and Lebesgue-uniform value within a sector. The feature marginal is atomless and gives the threshold copy no mass.

In any coupling of an output name with a feature of this marginal, sector prediction one has probability zero. Indeed take the name atoms as above. Outside the atoms a true positive requires a name in the universally null set. At a name atom the positive feature set is finite, so the probability of a hit there is zero by the atomless feature marginal. Sum over the countably many name atoms. This conclusion applies to the actual training pairs of any completed-measurable learner output. Its realized training loss is therefore one almost surely.

For the seeded formulation, restrict the actual output experiment to a fixed selector value of positive probability. The completed-measurable standard Borel output on training tuple, unused tuple and seed admits a product-measurable version. Since the output originally depends on training and seed only, Fubini gives a section at one unused tuple that agrees with the original output for almost every training tuple and seed. The jointly universally measurable evaluation pulls back to a completed-measurable loss for this version, under its joint law with the training features. Passing to the original output changes it only on a completed null set. Fubini now gives scalar expected training loss one for $`D^{\otimes n}`$-almost every training tuple. Seed expectations on individual samples are ordinary expectations, since evaluation at a fixed feature is Borel in the name. For a completed-measurable training kernel the same conclusion follows by integrating the loss under the joint law of the sample and output, then using a measurable version of the joint loss to identify the conditional expectations almost everywhere.

Choose a level $`j`$ with $`m_j\ge n`$ and condition on one pattern in which every row is in that level and their sectors are distinct. This event has positive probability. Conditional on the pattern the values have independent Lebesgue laws. The tuples that extend to an element of $`G_j`$ have full outer probability by the projection property. Each such tuple has empirical optimum zero, using the name of its matching element. Since the set of samples with scalar expected loss one contains a conull measurable subset under that pattern, at least one fitted tuple lies in it. Its expected excess is one. With one level take $`m_j=n`$ at the sample size under consideration. With countably many levels take unbounded $`m_j`$ and keep both the class and the mixture law fixed. The same argument then applies at each size $`n\ge2`$.

## Uniform convergence and the remaining scope

The outer uniform-convergence estimates for the [standard Borel name construction with separate evaluation](standard-borel-output-obstruction.md#quantifiers-and-convergence) apply to these classes as well. They use only disjoint finite sector supports and the threshold queries on a disjoint copy. For one level of size $`m`$, the measurable envelope has expected value at most $`11/(2\sqrt n)+m/n`$ under every iid labeled law. In the fixed class with countably many levels, truncate the sector supports to the finitely many levels up to $`J`$. The remaining deviation is bounded in expectation by twice the feature mass of later levels. The threshold bound is unchanged. For each fixed law send $`n`$ to infinity for fixed $`J`$, then send $`J`$ to infinity.

At the one-level counterexample size $`n=m`$, under $`D`$ every hypothesis has population loss one. Given the sector pattern, take the first row in each occupied sector. Its values lie in a projected matching on a full-outer-measure set. On those tuples some proper name hits at least all those rows. Thus the outer expected uniform deviation is at least the expected occupied fraction, $`1-(1-1/m)^m\ge1-1/e`$. The examples fail the sharp absolute VC uniform-convergence rate when the support sizes grow.

These classes have no jointly Borel parametrization by a standard Borel space. The all-one trace on the ordered complete sector tuple at a level is feasible precisely on $`G_j`$. A jointly Borel parametrization would make this projection analytic, hence measurable for the completed Lebesgue product. By Fubini each Borel subset of $`G_j`$ has measure zero since its last-coordinate sections have at most one point, contradicting full outer measure. The written disproof therefore covers joint universal measurability and the actual completed iid definition. The jointly Borel and sharply uniformly convergent version remains open here.
