# An actual iid information obstruction with standard Borel names

There is a VC-one class of distinct predictors for which both the feature space and the hypothesis space are standard Borel, the output Borel sigma-algebra is exactly the one generated by pointwise predictions, and evaluation is Borel in each argument separately. For every proposed constant $`c`$ in Conjecture 6, this construction gives a class with distribution-uniform convergence in outer probability on which the two rates cannot hold. There is also one fixed class and one iid law with the same obstruction for every $`c`$ at arbitrarily large sample sizes, with outer uniform convergence separately under each labeled law.

The lower bound uses the actual iid selector and independently randomized proper output in Definition 3. It requires completed measurability of that output. For a given named output, a jointly Borel test reads some of the selector bits from the supersample. This test works without any assumption that the realized training loss is jointly measurable on the training experiment. Evaluation of the class itself is separately Borel and fails joint Borel measurability. [Conjecture 6 and Definition 3](https://proceedings.mlr.press/v125/steinke20b/steinke20b.pdf)

## Hypothesis names and prediction queries

Use levels $`j`$ in a finite or countable index set, with $`m_j\ge2`$ sectors at level $`j`$. Let $`G_j\subseteq[0,1]^{m_j}`$ be a full-outer-Lebesgue-measure set in which distinct tuples differ in every coordinate. For completeness, enumerate all positive-measure Borel sets of the cube, using at most continuum many indices. At each step choose a tuple in that set using fresh values in every coordinate. At each coordinate Fubini gives a positive-measure set of choices whose remaining section has positive measure. Such a set has cardinality continuum, while fewer than continuum many values are forbidden. The resulting set meets every Borel set of positive measure. Its projection on any nonempty subset of coordinates also has full outer measure, by taking inverse images of positive-measure Borel sets. [Full-outer matching construction](completed-finite-groups.md#a-matching-of-full-outer-measure)

Take as the name space a separate zero name and **all** tuples $`(j,g)`$ with $`g\in[0,1]^{m_j}`$. Write $`H`$ for this standard Borel space. Fix a Borel injection $`v:H\to[0,1]`$ taking the zero name to $`0`$ and all other names to $`(0,1]`$. Its image is Borel and it has a Borel inverse on its image by Lusin–Souslin. The feature space consists of the points $`(j,i,x)`$ in the sector copies of $`[0,1]`$, and a separate copy of $`[0,1]`$ for threshold queries. The name $`(j,g)`$ is positive in the sectors precisely at

```math
\{(j,i,g_i):1\le i\le m_j\}
```

when $`g\in G_j`$, and is zero throughout the sectors otherwise. On a threshold query $`t`$, name $`h`$ predicts $`1_{\{t<v(h)\}}`$. The zero name always predicts zero. The threshold queries make all predictors distinct. The rational threshold queries recover $`v(h)`$ as the supremum of the positive rational queries, with value zero if there are none. They therefore generate the Borel sigma-algebra of names. Since all pointwise predictions are Borel in the name, allowing every prediction query gives exactly this sigma-algebra.

For a fixed sector feature at most one name predicts one, by the matching property. For a fixed name its sector support is finite. These facts and the threshold rule prove separate Borel measurability. Two distinct sector features cannot be shattered because either they have the same unique positive name or no name is positive at both. A sector feature with a threshold query cannot be shattered because the positive sector bit determines the name. Two threshold queries cannot be shattered because they are nested. At least one feature is shattered, so the dimension is one.

For later use, call a sector feature $`(j,i,x)`$ a **code hit** of $`h=(j',g)`$ if $`j'=j`$ and $`g_i=x`$. The zero name has no code hits. This test is jointly Borel and includes every true positive in the sectors. In particular it applies to names from the entire cube, regardless of whether their tuple belongs to $`G_j`$.

True evaluation is measurable in the completion of every independent product of a name law and a feature law. On the countable set of atoms of the sector feature marginal, the true positive relation is a countable union of Borel rectangles, since each such atom has at most one positive name. Off those atoms, the Borel code-hit event has product probability zero, by Fubini and the finite sector support of the code-hit test for each name. The true positives there are a subset of this null event. Evaluation on the threshold copy is jointly Borel.

## Expected code hits from the empirical guarantee

Use an iid law $`D`$ supported on the sectors and with every label equal to one. At level $`j`$, of probability $`w_j`$, the sector is uniform among its $`m_j`$ indices and the value is uniform on $`[0,1]`$. Let $`K_j`$ count the rows of a size-$`n`$ sample in level $`j`$. Fix a pattern of levels and sectors on which the level-$`j`$ sectors are distinct. The set of value tuples for which some proper name hits all $`K_j`$ level-$`j`$ rows has full outer probability under the conditional value law. For $`K_j>0`$ this follows from the matching projection to those sectors. In detail, from any Borel set of full sample values of positive conditional probability, Fubini gives a positive-measure set of level-$`j`$ coordinates whose sections in the other values have positive measure. Take a tuple in this projection with an extension in $`G_j`$, and complete it from its positive-measure section. For $`K_j=0`$ the zero name suffices.

Let $`M(z,h)`$ be the number of code hits of the output $`h`$ on the training tuple $`z`$. It is jointly Borel. For an independently seeded learner $`A(z,R)`$, put $`u(z)=\mathbb E_R M(z,A(z,R))`$. If the actual output is measurable on the completion of the pool, selector and seed experiment, then $`u`$ is measurable on the completion of $`D^{\otimes n}`$. Indeed restrict to the all-zero selector event and write the two columns as a selected tuple and an unused tuple. The resulting output has a product-measurable version on training, unused tuple and seed, since the output space is standard Borel. It agrees with the original output off a product-measurable null hull. By Fubini fix one unused tuple for which the version agrees for almost every training tuple and seed. Its section now supplies a measurable version on training and seed alone. Integrating the bounded Borel test $`M`$ yields the claim. The same proof works for a completed-measurable training kernel by directly integrating $`M`$.

Suppose the learner has expected samplewise empirical excess at most $`\epsilon`$. On the fitted tuples just constructed, the proper optimum is at most $`1-K_j/n`$. The number of true positive predictions on the sample is bounded above by the number of code hits, so $`u(z)\ge K_j-n\epsilon`$ on those tuples. The inequality extends almost surely under the conditional value law. Otherwise a positive-measure violation would contain a positive-measure Borel set disjoint from a full-outer-measure set. The pattern has positive probability and its conditional law inherits completed measurability. On other patterns $`u\ge0`$.

If $`m_j\ge4n^2`$, conditional on the level pattern the probability of any level-$`j`$ sector collision is at most $`n(n-1)/(2m_j)\le1/8`$. Since $`K_j`$ is fixed in this conditioning and $`\mathbb E K_j=nw_j`$, averaging gives

```math
\mathbb E M(Z,A(Z,R))\ge \tfrac78 n w_j-n\epsilon .
```

## The output reveals the matching selectors

Write $`W`$ for the iid paired pool, $`S`$ for the independent fair selector, and $`Y=A(W_S,R)`$ for the actual output. For each fixed selector, the unused column tuple is independent of the training tuple and private seed. Under the law just chosen, any fixed name has a code hit on a fresh independent feature with probability zero. The measurable training-and-seed version and Fubini therefore show that the actual output has no code hit on any unused pool row almost surely. This holds for the random selector as well, since it has finitely many possible values.

Given the pool and the output name, in each row with a code hit there is consequently a unique hit and its side is the selected side. Let $`B(W,Y)`$ be the number of such rows. It equals the selected hit count almost surely. Conditional on $`(W,Y)`$, the selector is supported on the subcube specifying these $`B(W,Y)`$ bits. To justify this conditional support statement, for each selector value integrate its conditional probability on the Borel set of pool/name pairs that would contradict one of the decoded bits. The integral is zero, and there are only finitely many selector values. Thus conditional entropy is at most $`(n-B(W,Y))\log 2`$. Since the prior selector is fair and independent of the pool, the whole-output information in nats satisfies

```math
I(Y;S\mid W)
\ge (\log 2)\,\mathbb E M(W_S,Y)
\ge (\log 2)\,n\bigl(\tfrac78 w_j-\epsilon\bigr).
```

This proof uses the Borel readout and the actual output sigma-algebra. It does not need a generalization inequality for the original loss.

## Quantifiers and convergence

For a proposed constant $`c\ge0`$, take just one level of weight one, choose $`n`$ so that $`c/\sqrt n\le1/8`$ and $`(3/4)n\log 2>c`$, and take $`m_j\ge4n^2`$. Conjectured accuracy forces information greater than $`c=cd`$ on the indicated iid law.

For a fixed class and iid law, use $`w_j=2^{-j}`$, $`n_j=16^j`$, and $`m_j=4n_j^2`$. These choices are independent of the candidate constant. At $`n=n_j`$, the conjectured accuracy tolerates $`\epsilon=c/\sqrt{n_j}`$, which is at most $`w_j/8`$ for all sufficiently large $`j`$. The information lower bound is at least $`(3/4)(\log 2)n_j w_j`$, which tends to infinity.

For convergence, decompose each loss as the zero-name loss minus the signed positive prediction on the sectors and minus the signed positive prediction on the threshold-query copy. The sign multiplying a positive prediction is $`2y-1`$. For the sectors, the supports are disjoint and, with just one level of size $`m`$, have size at most $`m`$. For any iid law $`P`$, only countably many supports contain atoms of its feature marginal. If $`\xi_h`$ is the signed hit on the atomic part of the sector support of $`h`$, disjointness gives $`\sum_h P\xi_h^2\le1`$ over these names. The expected squared norm of their vector of empirical-minus-population deviations is at most $`1/n`$. This controls the expected supremum of the absolute atomic deviations by $`1/\sqrt n`$. Outside the atoms every finite support has population mass zero and the observed nonatomic features are almost surely distinct, giving the additional bound $`m/n`$ on their empirical contribution.

For the threshold part, take the supremum over all cut values in $`[0,1]`$. It is measurable using rational cuts from below and the endpoint zero. Symmetrization bounds the expected supremum of the absolute deviations by twice the expected supremum of the absolute Rademacher averages. Conditional on the sample, order its threshold-query rows by value. Each cut selects an initial segment, so the latter supremum is bounded by the maximum of the absolute partial sums of independent signs, divided by $`n`$. The deterministic labels only flip signs. Doob's squared maximal inequality and Cauchy–Schwarz give the bound $`2/\sqrt n`$ for this Rademacher term. Including the zero-name deviation, whose expected absolute value is at most $`1/(2\sqrt n)`$, gives the measurable-envelope bound $`11/(2\sqrt n)+m/n`$ in outer expectation. In particular the one-level class has distribution-uniform convergence in outer probability. For the countable-level version apply the sector estimate on the first $`J`$ levels with $`m=\max_{j\le J}m_j`$. Any later sector deviation is bounded by $`P_n(U_J)+P(U_J)`$ where $`U_J`$ is the set of later sector features. This adds at most $`2P(U_J)`$ in expectation, while the threshold bound stays the same at all levels. For each fixed law first send $`n`$ to infinity and then $`J`$ to infinity.

The convergence is weaker than the sharp absolute VC rate in Theorem 2. Under the test law every name has population loss one. The same full-outer-measure fitting argument gives outer expected uniform deviation at least $`7w_j/8`$ at the corresponding $`n`$. There is also no jointly Borel parametrization of exactly this class by any standard Borel space. On the ordered full-sector pattern at level $`j`$, existence of a hypothesis making every prediction positive is exactly membership in $`G_j`$. Joint Borel evaluation would make this an analytic projection and hence measurable in the completed Lebesgue product law. For $`m_j\ge2`$ the matching has singleton sections in the last coordinate, so each Borel subset has measure zero by Fubini. This contradicts full outer measure. The jointly Borel, sharply uniformly convergent case of Conjecture 6 therefore remains open.

For jointly Borel classes, no countable list of fixed iid test laws suffices for a counterexample to simultaneous attainment of the rates on that list. Form a reference marginal by mixing their feature marginals with strictly positive weights, and use the learner for all laws dominated by that reference. Its measurable fallback still gives the empirical guarantee on every sample, and its information bound holds simultaneously on the specified list. The same domination argument applies to the completed channels on a specified list under the sharp outer uniform-convergence assumption. [Dominated-marginal theorem](dominated-marginals.md)

When the output loss is jointly measurable, the accuracy and information rates together imply sharp outer uniform convergence of the comparator class. The implication uses only the fair-label laws with the same feature marginals. [Necessity of the sharp outer uniform-convergence rate](uniform-convergence-necessary.md)
