# Measurable reconstruction for countable disagreement sets

Let $`X`$ and $`H`$ be standard Borel spaces with Borel evaluation and VC dimension $`d\ge 1`$. Suppose there is a fixed $`h_0\in H`$ such that $`\{x:h(x)\ne h_0(x)\}`$ is countable for every $`h\in H`$. There are countably many universally measurable proper reconstruction maps of at most $`d`$ features which between them realize every feasible trace using features in the sample. Thus one proper learner has expected empirical excess at most $`583\sqrt{d/n}`$ on every sample and actual iid CMI at most $`197{,}152d`$ nats for every iid law, under completed measurability. This follows from the [local reconstruction theorem](measurable-local-reconstruction.md) with $`k=d`$.

## The number of features needed to describe the positives

Work in disagreement coordinates, in which $`h_0`$ predicts zero everywhere, and let $`E(h,x)`$ mean that $`h`$ predicts one. Changing coordinates in this way preserves VC dimension. Identify both spaces with Borel subsets of Baire space. Fix one real parameter $`r`$ with respect to which $`X,H,E`$ are lightface $`\Delta^1_1(r)`$. Such a parameter exists since these sets are Borel. Write $`\operatorname{HYP}(q)`$ for the reals hyperarithmetic in a real parameter $`q`$. A tuple of parameters is encoded by its effective join. Hyperarithmetic reducibility is transitive and closed under finite joins. The effective perfect set theorem gives $`x\in\operatorname{HYP}(r,h)`$ whenever $`E(h,x)`$ holds, because the $`\Delta^1_1(r,h)`$ section is countable. [Effective perfect set theorem and relative pointclasses](https://math.berkeley.edu/~marks/notes/edst_notes3.pdf)

We use the following finite form of hyperarithmetic cone avoidance. If $`A`$ is a nonempty $`\Sigma^1_1(q)`$ set and $`b_1,\ldots,b_t\notin\operatorname{HYP}(q)`$, some $`a\in A`$ satisfies $`b_i\notin\operatorname{HYP}(q,a)`$ for all $`i`$. Indeed, for each $`i`$ and each pair of analytic formulas relative to $`(q,a)`$ that could give complementary definitions of the digit set of $`b_i`$, the Gandy–Kreisel–Tait cone-avoidance argument refines any nonempty $`\Sigma^1_1(q)`$ set to a nonempty $`\Sigma^1_1(q)`$ set on which that pair fails. Process the countably many requirements as moves in the Choquet game of nonempty $`\Sigma^1_1(q)`$ sets. Use the winning strategy with nonempty intersection after each refinement. The intersection then contains a real satisfying every requirement. This is the relativized argument of Lemmas 3.4 and 3.12 and Exercise 3.13, using the digit graph to encode Baire reals as sets of integers. [Cone avoidance and the Choquet game](https://math.berkeley.edu/~marks/notes/edst_notes3.pdf)

Let $`P`$ be a finite set of features on which some hypothesis predicts one in disagreement coordinates. Choose an inclusion-minimal subset $`I\subseteq P`$ such that $`P\subseteq\operatorname{HYP}(r,I)`$. Such a subset exists since $`P`$ itself has the property. If $`x\in I`$, then $`x\notin\operatorname{HYP}(r,I\setminus\{x\})`$. Otherwise transitivity and finite joins let us remove $`x`$ from an anchor for every member of $`P`$.

For any $`S\subseteq I`$, the set of hypotheses predicting one on $`S`$ is a nonempty $`\Delta^1_1(r,S)`$ set. Each point of $`I\setminus S`$ is outside $`\operatorname{HYP}(r,S)`$. Apply finite cone avoidance to choose a hypothesis in that set such that every point of $`I\setminus S`$ remains outside $`\operatorname{HYP}(r,S,h)`$. Since a positive feature of $`h`$ belongs to $`\operatorname{HYP}(r,h)`$, this hypothesis predicts zero on $`I\setminus S`$. Hence $`I`$ is shattered, so $`|I|\le d`$.

## Constructing the lists

For each number of anchors up to $`d`$, a countable family of universally measurable maps of the anchor tuple lists a superset of its $`r`$-relative hyperarithmetic reals. To see this, enumerate the lightface analytic formulas $`P_e(q,k,m)`$ for predicates of two natural numbers and the real parameter $`q`$. For each $`e`$ return the Baire real whose $`k`$-th digit is the least $`m`$ satisfying $`P_e(q,k,m)`$, with default digit zero if the set is empty. The map is universally measurable by the analyticity of the digit tests and countable Boolean operations. Every hyperarithmetic real occurs, using an analytic formula for its digit graph. Here $`q`$ is the join of $`r`$ and the anchor tuple. Retain only outputs in the Borel copy of $`X`$.

Enumerate all finite lists of outputs from these maps as candidate lists of positive features. For each such list, use Jankov–von Neumann to select a proper hypothesis matching its positive requirements wherever feasible. This is an analytic selection on the finite feature list. Continue with a countably branching tree of hypotheses. At a node, the requirements are the same positive features and a finite set of features to avoid. For each feature in the current hypothesis's disagreement set, add a child which appends that feature to the avoidance requirements. Select a hypothesis for that child where feasible. Lusin–Novikov enumerates the countable disagreement sets by Borel partial maps, and Jankov–von Neumann makes the new selection universally measurable in the finite requirements. For each finite address, compose the selections and feature enumeration maps. Invalid candidates or branches may return $`h_0`$. All maps are universally measurable since composition and countable tuples of universally measurable maps between standard Borel spaces preserve universal measurability. [Kechris, Theorems 18.1 and 18.10](https://doi.org/10.1007/978-1-4612-4190-4)

For a feasible trace, let $`P`$ be its positive features and choose $`I\subseteq P`$ as above. One of the lists generated from those observed anchors is $`P`$. Its tree begins with a proper hypothesis fitting $`P`$. If the current hypothesis predicts one at a feature declared negative in the trace, follow the child forbidding that feature. The target trace still has a realizing hypothesis, so the child is feasible. Every such step adds a distinct negative feature, since all earlier requirements persist. After at most the number of distinct negative features, the tree gives a hypothesis matching the whole trace. The all-zero disagreement trace also uses the fixed candidate $`h_0`$. All tree addresses and finite list indexes form a countable family, and each map reads at most $`d`$ features from the original sample. This proves exact reconstruction and the two rates.

The countable-disagreement assumption is used for both cone avoidance on the feature side and the enumeration of the children. The regular completed-iid problem for arbitrary finite VC classes remains open here.
