# Proper reconstruction for analytic score families

Let $`X,H`$ be standard Borel spaces, $`U\subseteq\mathbb R^p`$ open, and $`\theta:H\to U`$ a Borel parameter map. Let $`f:X\times U\to\mathbb R`$ be Borel and real analytic in the parameter for each feature. Suppose the threshold class

```math
(x,t)\longmapsto 1_{\{f(x,\theta(h))\ge t\}},\qquad h\in H,
```

has VC dimension $`d\ge1`$, and $`\theta(H)`$ is dense in $`U`$. The catalogue below reads at most $`d`$ observed features, including their thresholds, and realizes every feasible finite trace. It supplies one proper learner with actual iid CMI at most $`197{,}152d`$ nats and expected empirical excess at most $`583\sqrt{d/n}`$ on every sample. The feature dependence of the scores can be arbitrary Borel dependence, and the bound is independent of the ambient parameter dimension $`p`$. Strict thresholds work by the same argument. [Named-output catalogue theorem](measurable-local-reconstruction.md) · [Published conjecture](https://proceedings.mlr.press/v125/steinke20b/steinke20b.pdf)

## A measurable reconstruction rule in a parameter box

First take any Borel parameter map into a connected open box $`W\subseteq\mathbb R^m`$, with a jointly Borel real-valued score $`s(a,w)`$ that is real analytic in $`w`$ for each input feature $`a`$. The prediction is the sign test $`1_{\{s(a,w)\ge0\}}`$. Here the score can already incorporate the threshold supplied by $`a`$. There is an exact catalogue reading at most $`m`$ features. The allowed names may have any parameter image in $`W`$.

Fix a target parameter realizing a finite trace. If every observed score is nonzero at the target or identically zero on $`W`$, all the signs are constant on some neighborhood of the target. Otherwise, choose one observed feature whose score vanishes at the target and is not identically zero. At least one derivative has nonzero value there, by analyticity and connectedness. Choose a derivative of smallest total order with nonzero value, of order at least one. It has the form $`\partial_j g`$ for a partial derivative $`g`$ of the score which vanishes at the target. A neighborhood of the target on $`g=0`$ is an analytic graph over $`m-1`$ coordinates. Restrict the parameter presentation to this graph and pull back all scores. The graph contains the target and the pulled-back scores are again analytic. A feature can be used again if its new score still has an unresolved zero. At most $`m`$ such steps are possible. At dimension zero all signs are fixed. [Real-analytic identity and implicit function theorems, Krantz and Parks](https://link.springer.com/book/10.1007/978-0-8176-8134-0)

The choices can be encoded in a countable list of Borel charts depending on the observed features. For each step specify the feature index, the derivative multi-index, the eliminated coordinate $`j`$, and a rational product box $`V\times(\ell,u)`$ whose closure lies inside the current parameter box, with $`(\ell,u)`$ in coordinate $`j`$. Also specify a sign orientation and a positive rational lower bound for the oriented derivative $`\partial_j g`$ on the closed product box. Require the oriented values of $`g`$ at the two endpoints $`\ell,u`$ to have opposite signs, bounded away from zero by a positive rational margin uniformly on $`\overline V`$. Such a choice exists near the target. First shrink the eliminated-coordinate interval about the target, where its derivative is nonzero and of one sign, and then shrink the other coordinates to preserve both endpoint inequalities by continuity.

The test for each code is Borel. Compute derivatives by pointwise limits of difference quotients with shifts remaining inside the open box. Check the uniform inequalities on a countable dense grid, which suffices by continuity. For valid codes the unique root in $`(\ell,u)`$ at each base coordinate in $`V`$ is Borel in the supplied features and the base coordinate by bisection. It is analytic in the base coordinate by the analytic implicit function theorem and uniqueness. Composing the chart maps preserves joint Borel measurability and analyticity in the current chart coordinate. These claims apply on the Borel domain of valid chart codes, and invalid codes return a fixed proper default.

After the descent, include a rational sub-box where the remaining signs are constant. In dimension zero use the one-point box. The relation that a proper name has parameter given by the final chart at some coordinate in this sub-box is Borel in the features, the name, and that coordinate. Analytic uniformization chooses a proper name from its projection at every feasible feature tuple. The target belongs to this relation for the chosen code, and every selected name agrees with the target trace. A fixed code reads only the distinct observed features used in its descent. The rational boxes, derivative indices, coordinate choices, and possible feature reuse are countable side information. This gives the $`m`$-feature catalogue. [Analytic selection, Kechris, Theorem 18.1](https://doi.org/10.1007/978-1-4612-4190-4)

## Arbitrary threshold queries bound the analytic rank

For any finite tuple $`x_1,\ldots,x_k`$ and $`z\in U`$, the derivative of $`(f(x_1,\cdot),\ldots,f(x_k,\cdot))`$ at $`z`$ has rank at most $`d`$. Otherwise choose $`r>d`$ independent rows. The corresponding score map has image containing a neighborhood of its value at $`z`$, by the inverse function theorem applied to $`r`$ suitable coordinates. Use thresholds $`t_i=f(x_i,z)`$ for those rows. Every strict sign pattern occurs in a nonempty open subset of $`U`$, so it is attained by a named parameter by density. This shatters the $`r`$ queries. The rank bound also holds on every analytic chart mapped into $`U`$, by the chain rule.

Cover the class by countably many analytic parameter presentations of dimension at most $`d`$. Start with a countable cover of $`U`$ by open boxes. During the construction, each current box $`W`$ of dimension $`m`$ maps into $`U`$ by an injective analytic map $`\psi`$. Consider the scores $`F_x=f(x,\psi(\cdot))`$ on $`W`$. If $`m\le d`$, retain the box. Otherwise let $`r\le d`$ be the maximum derivative rank of finite tuples of these scores over $`W`$. The maximum is attained because the ranks are integers in a finite range. If $`r=0`$, every $`F_x`$ is constant on $`W`$, and all its names share a zero-dimensional presentation.

If $`r>0`$, fix $`r`$ score functions $`G=(F_{x_1},\ldots,F_{x_r})`$ and an $`r\times r`$ derivative minor $`\Delta`$ nonzero at some point. Where $`\Delta\ne0`$, the coordinates $`(G,v)`$, with $`v`$ given by the remaining old coordinate projections, form a local analytic coordinate system by the inverse function theorem. Use countably many neighborhoods on which these coordinates have open product-box image. Such neighborhoods cover the open set in question, and a countable subcover exists by second countability. In each coordinate product the derivatives of every $`F_x`$ in the $`v`$ directions vanish. A nonzero derivative in those directions would give rank $`r+1`$ after adjoining $`F_x`$ to $`G`$. Each $`F_x`$ is therefore constant on each connected $`v`$ slice. Fix one $`v_0`$ from the product box and evaluate on the section $`(G,v_0)`$. This gives a Borel, real-analytic-in-parameter score family in $`r`$ coordinates. The names in the neighborhood are parametrized by their $`G`$ coordinate and all their original scores are preserved by the section.

The zero set of $`\Delta`$ is covered by countably many analytic graphs mapped injectively into $`W`$ from boxes of dimension $`m-1`$. For each zero choose a derivative of smallest order which is nonzero there. As in the reconstruction rule, the derivative obtained by omitting its last differentiation is zero there and has nonzero derivative in the omitted coordinate. Use the rational product-box construction for that derivative. The union of all such graphs covers the zero set. A graph may contain points where $`\Delta\ne0`$, which are valid parameters as well. Compose each graph with $`\psi`$ and recurse. The dimension decreases at each unresolved step, and there are countably many boxes at each step.

All domains of names used here are Borel. An injective analytic map from an open box is Borel with Borel image and inverse on that image, by Lusin–Souslin. For each box first restrict names to the image of the box or coordinate neighborhood under $`\psi`$, and use that inverse followed by the appropriate coordinate map. The sections in the new $`r`$ coordinates define scores for these actual names even if some section parameters are absent from $`\theta(H)`$. Every original name belongs to a retained presentation, and every presentation uses names of $`H`$. [Lusin–Souslin, Kechris, Theorem 15.1](https://doi.org/10.1007/978-1-4612-4190-4)

Use the box reconstruction rule in each presentation and take the union of the countably many catalogues. The presentations were fixed from the class before seeing a sample, including the score choices $`G`$. Only the descent inside one retained presentation reads observed features. Its budget is at most $`d`$, giving the stated information and error. The argument also covers a restricted set of available threshold queries with the same anchor budget when the complete threshold class has VC dimension $`d`$. The assumption on all thresholds is used to bound the score rank.
