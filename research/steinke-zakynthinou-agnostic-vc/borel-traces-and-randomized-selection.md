# Borel trace feasibility and proper randomized selection

There is a class of VC dimension one with standard Borel feature and hypothesis spaces, jointly Borel evaluation, and Borel realizability of every finite trace, for which **no proper Borel Markov learner** has worst-case empirical excess strictly below one at any positive sample size. This class has the usual agnostic uniform-convergence rate. Under completion of each iid law, the very same class has a proper learner attaining both rates of Conjecture 6. Thus even within standard Borel spaces with Borel empirical infima, the choice between global Borel and completed iid measurability changes the bounty statement.

This strengthens the Borel obstruction in the [scope audit](../../results/steinke-zakynthinou-agnostic-vc/SCOPE.md). It uses a Borel proper output space and leaves the completed-iid question for general Borel classes open. The empirical-accuracy argument applies to randomized kernels directly. [Original conjecture and Definition 3](https://proceedings.mlr.press/v125/steinke20b/steinke20b.pdf)

## Class and finite traces

Let $`P=\mathbb N^{\mathbb N}`$. Use a closed set $`F\subset P\times P`$ with first projection $`P`$ and no Borel uniformization. This is the classical example from Kechris, Exercise 18.17. Set $`U=F\times\mathbb N`$ and define $`f((x,y),j)=x`$. All fibers of $`f`$ are infinite. Take feature space $`P\sqcup U`$ and class $`\{0\}\sqcup U`$. The element $`u`$ labels precisely $`(0,f(u))`$ and $`(1,u)`$ positive. The zero classifier labels no point positive. The marker $`(1,u)`$ distinguishes each $`u`$ as an actual classifier and the two diagonal tests make evaluation jointly Borel. [Kechris, *Classical Descriptive Set Theory*, §18](https://link.springer.com/book/10.1007/978-1-4612-4190-4)

Any one marker is shattered. Two features in one copy cannot both be labeled positive. In a mixed pair, positivity at the marker forces the entire classifier, so both patterns with the marker positive cannot be realized. Hence the VC dimension is exactly one.

Fix a finite binary trace. If it calls for a positive marker, its first positive marker forces a single candidate, which can be evaluated on every row by the joint Borel map. If it has no positive markers but calls for a positive feature in the first copy, all its positive points must equal that feature and no negative point in the first copy may equal it. The infinite fiber above that point permits a choice avoiding the finitely many negative markers. The zero trace is always realized. These are Borel tests of the feature tuple. The empirical infimum is the least mismatch count over the finite list of realized traces divided by the sample size, hence Borel.

## Borel randomized kernels would uniformize the closed relation

Let $`K`$ be a proper Borel Markov kernel with empirical excess bounded by a constant $`\eta<1`$ on every sample of size $`n>0`$. Feed it $`n`$ copies of $`((0,x),1)`$. Write $`K_x`$ for its law. The optimum is zero for every $`x`$, so $`K_x`$ assigns at least $`1-\eta`$ to hypotheses $`u`$ with $`f(u)=x`$. Restrict $`K_x`$ to those hypotheses, normalize, and push it forward under $`((x',y),j)\mapsto y`$. This produces a Borel probability kernel $`x\mapsto\nu_x`$ on $`P`$ with $`\nu_x(F_x)=1`$. Borel measurability follows from integration of the indicator of the joint Borel success event against $`K_x`$.

For each $`x`$, build an infinite sequence $`y(x)`$ by beginning with the empty prefix and extending it by the least natural digit for which the cylinder still has positive $`\nu_x`$-mass. Every positive cylinder has such a child because its children form a countable partition. Each next digit is Borel in $`x`$ by the kernel property and induction on prefix length. Every prefix of $`y(x)`$ has a realization in $`F_x`$ because its cylinder has positive $`\nu_x`$-mass. The closedness of $`F_x`$ gives $`y(x)\in F_x`$. This Borel map uniformizes $`F`$, a contradiction.

Taking $`n>c^2`$ rules out the empirical requirement of Conjecture 6 for any proposed universal $`c`$ under the global Borel-kernel convention.

### Self-contained version used in Lean

One can use a Borel relation in place of the closed relation $`F`$ and get the contradiction directly from the randomized output. Let a code assign to each finite sequence of naturals an operation. An operation is a countable union, a countable intersection, or a literal that asks whether a designated coordinate of the input equals a designated value, or differs from it. Each code and input determines a monotone operator on sets of nodes marked true. Its least fixed point gives a valid truth assignment, even for codes containing infinite branches. The relation of being a valid assignment is Borel because each local rule uses a countable union or intersection of coordinate events.

Every Borel set of code inputs has a code whose root is true under every valid assignment exactly on that set. Coordinate cylinders have literal codes. Flipping unions with intersections and complementing literals yields the complement of a represented set. Grafting a countable sequence of codes below a union node represents its union. These operations give the assertion by induction over the product sigma-algebra.

Use codes as first-copy features and pairs of a code with a valid assignment on itself, tagged by a natural number, as the marker space. Projection to the code replaces $`f`$. Its fibers are infinite, so the preceding finite trace tests apply. A learner attaining excess below one on repeated positive code $`x`$ must put positive probability on matching hypotheses. Let $`A`$ be the Borel set of codes for which the learner puts positive probability on a matching hypothesis with a false root assignment. Choose a code $`c`$ representing $`A`$. When queried on $`c`$, every matching hypothesis has a true root if $`c\in A`$, and a false root if $`c\notin A`$. The positive matching probability makes both cases contradict the definition of $`A`$. The proof includes distinct hypotheses, standard Borel spaces, Borel finite trace feasibility and the impossibility for all proper Borel Markov kernels. ## Uniform convergence on the same class

For an arbitrary iid labeled law, let $`\phi(x)=\mathbb E[(2Y-1)1_{X=x}]`$ and let $`\phi_n`$ be its empirical counterpart. The set of atoms of the feature marginal is countable. For those coordinates, independence gives total expected squared error at most $`\Pr(X\text{ is an atom})/n`$. Outside the atoms, the sampled features are distinct almost surely because each coincidence has probability zero by the product measure and measurability of the diagonal. Their total expected squared error is $`\Pr(X\text{ is not an atom})/n`$. Consequently

```math
 \mathbb E\|\phi_n-\phi\|_2^2\le 1/n.
```

The countable union of the sampled points and the population atoms contains the support of the difference, so this squared norm is a measurable random variable. A classifier differs from the zero classifier at at most two points. The correction to its empirical-minus-population loss, relative to the zero classifier, is therefore at most $`\sqrt2\|\phi_n-\phi\|_2`$ in absolute value. The zero classifier's deviation has expected absolute value at most $`1/(2\sqrt n)`$. This proves the $`(\sqrt2+1/2)/\sqrt n`$ bound on expected uniform deviation, including with outer expectation. The uniform-deviation supremum is also measurable in the completion by analytic projection of its strict level sets. The measurable envelope just displayed changes by at most $`(1+2\sqrt2)/n`$ when one example is replaced, yielding the usual bounded-differences tail above its expectation.

## Completed iid learners on the same class

For each finite dictionary of distinct features and each realizable trace, choose a universally measurable representative by the Jankov–von Neumann uniformization theorem. One applies that theorem to the Borel relation between the finite dictionary, a trace, and a classifier realizing it. Dictionary entries can be ordered by a fixed Borel injection of the standard Borel feature space into $`\mathbb R`$. Thus the representative depends only on the dictionary and trace. [Kechris, §18.A](https://link.springer.com/book/10.1007/978-1-4612-4190-4)

Apply the [bounded score perturbation lemma](bounded-score-noise.md) with $`u_x=e_x`$, $`v_h=1_{\{x:h(x)=1\}}`$, $`U=1`$, $`V=2`$, and $`d=1`$. On the dictionary of nonzero noisy scores, choose the maximizing realized trace in a fixed order and return its chosen representative. Empty dictionaries use the zero classifier. The accuracy proof holds for each realization of the independent noise and gives empirical excess at most $`8/\sqrt n`$. The exact postprocessing rule depends only on the nonzero dictionary. The information proof therefore applies to the whole returned classifier on each fixed paired pool and gives at most $`\pi^2`$ nats.

For a fixed iid pool law, a pool has finitely many feature subdictionaries and finitely many traces on each. Almost surely all representatives needed by the selector experiment agree with Borel versions for the corresponding dictionary laws. The finite selector channel then has measurable masses in the completion, since the noise step is Borel, ties between the finitely many candidate classifier names are measurable, and the quantitative information bound integrates. Equivalently, the training output kernel is measurable after completion by taking Borel versions of the finitely many representative selections for the dictionary laws induced by the training input. The original dictionary selections are fixed before the iid law is chosen. This yields both rates with one learner under the completed-iid convention.
