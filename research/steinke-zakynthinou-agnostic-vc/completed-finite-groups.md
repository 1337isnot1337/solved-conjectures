# A completed-iid obstruction with finite supports and uniform convergence

For each integer $`m\ge2`$ there is a VC-one class with distinct Borel classifiers, finite positive supports, and jointly measurable evaluation. For one fixed iid labeled law and sample size $`m`$, **every proper Markov learner measurable on the completed training law** has a sample with optimum zero and expected empirical error at least $`1-1/m`$. The class is distribution-uniform Glivenko–Cantelli. More precisely, for every iid labeled law and every sample size $`n`$, its expected uniform deviation in outer expectation is at most $`3/(2\sqrt n)+m/n`$. This disproves the literal all-class, completed-iid reading of Conjecture 6 even when every admitted class must have distribution-uniform convergence in outer probability. The hypothesis parameter space is a trace-measurable subspace of a Polish space. The construction does not assert that this subspace is standard Borel or that the uniform-deviation supremum is measurable. [Original conjecture](https://proceedings.mlr.press/v125/steinke20b/steinke20b.pdf) · [Earlier null-chain obstruction](../../results/steinke-zakynthinou-agnostic-vc/SCOPE.md#completion-of-an-iid-law)

Lean formalizes the full outer-measure matching and the failure of the empirical rate for every proposed constant. The obstruction needs only almost-everywhere measurability of the scalar expected loss on the iid training law. Lean also verifies a measurable uniform-deviation envelope with expectation at most $`2/\sqrt n + m/n`$. Its hypotheses are the coordinate injectivity properties of the matching. ## A matching of full outer measure

Write $`P=[0,1]`$ and use Lebesgue measure. There is a subset $`G\subset P^m`$ of full outer measure such that for distinct $`g,g'\in G`$, $`g_i\ne g'_i`$ for every $`i`$. To build it, list all Borel subsets of $`P^m`$ having positive product measure in a list of length at most the continuum. This uses the fact that Polish Borel sets have countable codes. At each stage choose a point of the listed set using fresh values in every coordinate. Fewer than continuum many values have been used in each coordinate. Fubini gives a positive-measure set of first coordinates with positive-measure sections in the remaining coordinates. Every Borel set of positive Lebesgue measure has cardinality continuum, so a fresh first value with positive-measure section exists. Repeat in that section, one coordinate at a time. This gives the required point in the listed set. The resulting matching meets every positive-measure Borel set, so its outer measure is one.

Take feature space $`X=\{1,\ldots,m\}\times P`$. There is one classifier $`h_g`$ for each $`g\in G`$, with positive support $`\{(i,g_i):1\le i\le m\}`$, and a zero classifier. Equip $`\{0\}\sqcup G`$ with the disjoint-union trace Borel sigma-algebra. The class consists of distinct functions and its evaluation map is jointly measurable by the coordinate equality tests. Different nonempty supports are disjoint. A point in one support is shattered using that support and the zero classifier. For two points from the same support, every classifier predicts the same value on both. For two points from different supports, no classifier predicts both positive. A point outside all supports cannot be labeled positive. The VC dimension is exactly one.

## The scalar expected loss cannot attain the empirical rate

Use the fixed distribution that chooses the feature sector uniformly, the value independently uniformly on $`P`$, and the label always one. Write $`r(s)`$ for the expected empirical loss of a proper randomized learner on sample $`s`$. The argument needs two properties of $`r`$. It is measurable in the completion of this iid training law, and it dominates the empirical optimum on each individual sample.

Say two features are related if a single support contains both. The relation is symmetric and each section is finite, since at most one support contains a given feature. Every positive-measure Borel set of samples contains a sample with no two distinct rows related. To prove this, induct on the number of rows. By Fubini the set of prefixes whose last-coordinate section has positive measure is measurable and of positive measure. Choose a prefix with no related pair by induction. Each chosen feature excludes finitely many last coordinates, so the positive section contains an admissible last coordinate. The induction starts with one row, which contains no pair.

If a sample has no related pair, any proper hypothesis hits at most one row, and $`r(s)\ge1-1/m`$. Thus the completed-measurable event $`\{s:r(s)\lt1-1/m\}`$ has no positive-measure Borel subset. Every completed-measurable event admits a Borel subset of the same probability, so this event is null. The almost-sure lower bound applies to every completed-measurable Markov learner with jointly measurable evaluation, since kernel integration makes its expected loss measurable.

The event that row $`i`$ comes from sector $`i`$ for all $`i`$ has probability $`m^{-m}`$. Conditional on this event its value tuple has product Lebesgue law. The subset with value tuple in $`G`$ has full outer measure inside this event. Consequently it contains a sample outside the completed null exceptional set for $`r`$. Its proper empirical optimum is zero, attained by its matching classifier. On that sample the expected loss is at least $`1-1/m`$.

Given any proposed finite $`c`$ in Conjecture 6, choose $`m`$ with $`c/\sqrt m\lt1-1/m`$. This violates the empirical requirement. The COLT paper uses an ordinary expectation over the sample and the learner's randomness in Theorem 4. Under the test law here, all labels are positive and every proper hypothesis has population loss one. Consequently the generalization difference in that expectation is measurable exactly when the realized empirical loss is measurable. Lean proves that if the realized loss is measurable on the completion of the iid training law times the independent random-seed law, and the seed-wise losses on every fixed sample define ordinary expectations, the empirical rate is impossible. Fubini makes the scalar expected empirical loss measurable on the completed training law. [COLT paper, Theorem 4 and Conjecture 6](https://proceedings.mlr.press/v125/steinke20b/steinke20b.pdf) · [Lean randomized-learner formulation](../../lean/Conjectures/AgnosticVC/CompletedFiniteGroups.lean)

There is also a direct formulation for the conditional joint law of the selector and actual output in iid CMI. Let $`A(z)`$ be the output probability measure specified on each fixed sample, and suppose a completed-measurable kernel $`J(w)`$ agrees almost everywhere with the actual conditional joint law on the iid pool. For every measurable output event $`B`$, the mass $`J(w)(\{0^m\}\times B)`$ is almost surely $`2^{-m} A(z)(B)`$, where $`z`$ is the first column. The other column is an independent ghost sample. A set depending only on the first column and measurable after completion of the product law is measurable after completion of the first law, by Fubini. Applied to the event probabilities, this gives a completed-measurable training kernel with exactly the output probabilities $`A(z)`$ on every sample. The finite-support contradiction now applies. Lean verifies the reduction for arbitrary pointwise probability measures, with almost-everywhere agreement on the original iid pool. [Lean conditional joint-law obstruction](../../lean/Conjectures/AgnosticVC/ConditionalJointObstruction.lean)

The conditional law may also be taken on the ambient standard Borel space $`\{0\}\sqcup[0,1]^m`$ of all output codes. The proper learner still assigns a probability law on $`\{0\}\sqcup G`$ at each sample. Applying the all-zero selector argument to its pushforward makes the probabilities of ambient Borel events measurable. Every measurable event of the proper class is the restriction of an ambient Borel event, so the proper output laws form a completed-measurable training kernel. Lean verifies this version, including that the ambient code space is standard Borel. The proper subclass remains the trace Borel space. ## Distribution-uniform convergence

Fix an arbitrary iid labeled distribution, and let $`B`$ be the countable set of atoms of its feature marginal. For a nonempty classifier support $`S`$, define $`\xi_S(X,Y)=(2Y-1)1_{X\in B\cap S}`$. Only countably many supports meet $`B`$, and at each input at most one $`\xi_S`$ is nonzero. Write $`P_n`$ for the empirical average and $`P`$ for expectation. Then

```math
 \mathbb E\sum_S |(P_n-P)\xi_S|^2
 =\frac1n\sum_S \mathop{\mathrm{Var}}(\xi_S)\le\frac1n .
```

Every support has population mass zero outside $`B`$. Almost surely all sampled features outside $`B`$ are distinct, by the measurable diagonal and the nonatomic part of the marginal. Any support contains at most $`m`$ of them, so its empirical signed mass from outside $`B`$ is at most $`m/n`$ in absolute value. The empirical-minus-population deviation for the zero classifier has expected absolute value at most $`1/(2\sqrt n)`$. Subtracting this zero-classifier deviation from the deviation for any other classifier reduces to the corresponding signed masses. The measurable upper bound consisting of the absolute zero-classifier deviation, the square root of the countable sum displayed above, and $`m/n`$ dominates the uniform deviation almost surely. Jensen's inequality proves the stated outer-expectation estimate. Markov's inequality then gives distribution-uniform convergence in outer probability. The term $`m/n`$ is class-dependent, and the same estimate is at most $`5/(2\sqrt n)`$ with an absolute coefficient once $`n\ge m^2`$.

## Prize scope

At the counterexample sample size $`n=m`$, the dependence on $`m`$ in the uniform-convergence bound is necessary. Conditional on the sector pattern, take the first row from each of the $`K`$ occupied sectors. The projection of $`G`$ onto those sectors has full outer product measure. Its inverse image under selection of the first rows also has full outer measure by Fubini applied to positive-measure Borel sets and their sections. On this event some support contains all $`K`$ selected rows. Every support is population-null for the nonatomic tagged law, so the uniform loss deviation is at least $`K/m`$ on a full-outer-measure subset for that pattern. Any measurable majorant is at least $`K/m`$ almost surely there. Averaging over patterns, the outer expected deviation is at least $`\mathbb E[K]/m=1-(1-1/m)^m\ge 1-1/e`$. Thus this family satisfies class-by-class distribution-uniform convergence, while an absolute VC-one $`O(1/\sqrt n)`$ bound across all these classes at every sample size fails.

This obstruction applies to the empirical requirement under the literal all-class statement with completed-iid learners. It persists if the class is required to have distribution-uniform asymptotic convergence in outer probability. Standard Borel parametrization, analyticity of the finite-trace feasibility relation, and measurability of all uniform-deviation events are stronger regularity requirements. The written counterexample here does not impose them. Under those requirements the general completed-iid question remains open in this repository. The sponsors can clarify which regularity convention governs their bounty.

In fact the finite-support class admits no jointly Borel parametrization by a standard Borel space, even allowing repeated names. On the ordered sector pattern, the existence of one hypothesis predicting every row positive would be the analytic projection of a Borel relation. That projection is exactly the matching $`G`$. For $`m\ge2`$ its countable sections force every measurable subset to have product measure zero, and its full outer measure makes it nonmeasurable in the completion. Analytic sets are measurable in every such completion.

## Universal measurability on the sample space

If a learner's scalar expected loss is required to be measurable under the completion of **every** sample-space probability law, one class with support size two suffices for every candidate constant. At each iid law and sample size, the Lean envelope has expectation at most $`2/\sqrt n+2/n\le 4/\sqrt n`$. The calculation above gives the slightly smaller bound $`7/(2\sqrt n)`$. [Lean disproof for the fixed class](../../lean/Conjectures/AgnosticVC/CompletedFiniteGroups.lean) · [Lean uniform-deviation bound for the same class](../../lean/Conjectures/AgnosticVC/FiniteSupportUniform.lean)

Draw $`u,v`$ independently uniformly on $`P`$ and form a labeled sample of size $`n=2k`$ by repeating each of $`(1,u)`$ and $`(2,v)`$ exactly $`k`$ times with positive labels. This sample law is a Borel pushforward of the product law of $`(u,v)`$. Consequently the learner's scalar expected loss after this substitution is measurable in the completion of the product law. For $`(u,v)\notin G`$, any proper classifier misses at least half the rows. The event of scalar loss below $`1/2`$ is therefore a completed-measurable subset of $`G`$. Each section of $`G`$ has at most one point, so Fubini applied to a Borel subset of equal probability shows that the event is null. Since $`G`$ has full outer measure, there is some $`(u,v)\in G`$ at which the loss is at least $`1/2`$ and the empirical optimum is zero. Taking $`c/\sqrt{2k}\lt1/2`$ violates the rate.

This variant uses a dependent law to test universal measurability of the learner's loss. Its uniform convergence bound concerns iid laws, and its accuracy contradiction uses the conjecture's requirement on every labeled sample. The hypothesis parameter space carries the trace Borel sigma-algebra. A written construction attains both rates for this two-point class with measurability under each completed iid law. The general case with standard Borel parameter spaces and completed iid learners remains open. [Completed-iid learner for the same class](completed-disjoint-support-learner.md)
