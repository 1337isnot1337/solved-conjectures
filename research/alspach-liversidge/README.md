# Alspach–Liversidge conjecture

Research log for [issue #313](https://github.com/1337isnot1337/solved-conjectures/issues/313). The original conjecture remains open in this work. Neither reduction below is a claimed resolution or a claimed priority result.

## Exact target and source check

In the formulation of Kuang–Wang and Nguyen–Tran–Vu, every finite set A of distinct nonzero elements of a finite abelian group should have an ordering with distinct **nonempty** partial sums. We call that weak validity. Strong sequencing means no zero interval other than possibly the full word (so the empty prefix and the last prefix may coincide exactly when the total is zero). Strong sequencing implies weak validity; for zero total the two are equivalent. We do not assume their equivalence for a fixed nonzero-total set.

- [Alspach and Liversidge, *On strongly sequenceable abelian groups*](https://doi.org/10.26493/2590-9770.1291.C54), Section 3: the original paper uses the strong definition, with Conjecture 3.5 formulated more generally for diffuse posets. Its Section 4 gives the disjoint-atom partition observation, and Lemma 4.1 uses the same interleaving pattern for disjoint 2-atoms. Section 1 below extends that particular construction using ordered zero-sum components.
- [Kuang and Wang, arXiv:2610.34424v1](https://arxiv.org/html/2610.34424v1), Conjecture 1.3 and Theorem 1.6: their threshold is an absolute lower bound on set size, not group size.
- [Nguyen, Tran and Vu, arXiv:2610.40712v1](https://arxiv.org/html/2610.40712v1), Conjecture 1.2 and Theorem 1.5: despite the broad abstract language, the formal theorem likewise requires a sufficiently large subset, uniformly over the group.
- [Costa, Della Fiore, Fontana and Vena, arXiv:2603.20961v1](https://arxiv.org/html/2603.20961v1), Theorems 1.4–1.6: strong sequencing for size at most 20, or 22 for zero total, with an additional hypothesis in their size-23 result. Their Section 2 merges pairs; the decomposition below instead preserves all zero-sum relations across a partition. These are distinct mechanisms.

## 1. Interleaving zero-sum components

**Proposition.** Let H have vertex set A and hyperedges the inclusion-minimal nonempty zero-sum subsets of A. If every connected component of H admits a strong sequencing, then A does. The same statement holds with weak validity in both places. Consequently a minimum-size counterexample to either version has connected H, and any set with pairwise disjoint minimal zero-sum subsets is strongly sequenceable.

**Proof.** Every nonempty zero-sum subset Z partitions into minimal nonempty zero-sum subsets: remove a minimal one and iterate, since the remainder still sums to zero. Hence Z intersects each component in a zero-sum subset (possibly empty). In particular a singleton component contributes to no zero-sum subset, since 0 is excluded. Write C_1,...,C_t for the nonsingleton components and give each its own strong ordering. Construct a word by listing the first element of C_1,...,C_t in that order, then all singleton elements, then the remainders of C_1,...,C_t in the same component order.

For any nonempty zero-sum interval of the resulting word, its slice in each C_i is a consecutive interval of the component's order. The partition observation makes every slice zero-sum, so a nonempty slice must use all of C_i. No singleton can be present. To include an entire C_i, the interval must cross the cut between the first-element segment and the remainders. Its selected component indices are therefore simultaneously a nonempty suffix of (1,...,t) from the first-element segment and a nonempty prefix from the remainder segment. The only such index set is all of (1,...,t). If there is a singleton this crossing is impossible; otherwise it gives exactly the whole word. If t=0 no nonempty subset sums to zero. This proves the proposition.

For the weak version use the same word, built from weakly valid component orders. A nonempty zero-sum slice in a component must be a prefix: otherwise its endpoints give two equal nonempty partial sums. Its length is at least two, as each element is nonzero. Therefore each component it meets contributes both its first entry and at least one entry from its remainder. The suffix/prefix argument still forces any zero-sum interval to include the first entry of the whole word. Such intervals do not obstruct weak validity.

In fact, when H is disconnected, weakly valid component orders suffice for a strong order of A. A singleton in the middle prevents every nonempty zero interval by the argument above. Otherwise there are at least two nonsingleton components. If all have total zero, each weak component order is strong. If some component has nonzero total, place one such component before the last. Any putative zero interval intersects all components and reaches the last remainder. It therefore contains the entire earlier nonzero-total component, contrary to the zero-sum slice property.

In the disjoint case each nontrivial component is itself a minimal zero-sum subset, so every order of it is strong. A minimum-size obstruction to either version cannot be disconnected.

**Deletion constraint on a minimum weak obstruction.** For every a in A other than the possible element a = sum(A), the set B=A\\{a} has nonzero total. If B had a strong order, prepending a would give a weakly valid order of A: a collision of two nonempty prefixes would give a nonempty zero interval entirely in B, which its strong order forbids because the total of B is nonzero. This is impossible. Since all subsets smaller than A are weakly sequenceable, disconnectedness of the minimal-zero-subset hypergraph on B would imply strong sequenceability by the upgrade above. Thus deleting any vertex other than the possible element equal to the total leaves a connected hypergraph, where deletion removes every hyperedge containing that vertex rather than shortening it. In the zero-total case there is no exception. Also, any zero-total strong obstruction forces every single-element deletion to be a nonzero-total strong obstruction, by the same argument and the equivalence of weak and strong at zero total.

## 2. Order-independent finite witness compression

**Proposition.** Every zero-sum subset pattern on n distinct nonzero elements of an abelian group has an exact realization on n distinct nonzero elements in a finite abelian group. If the integral span of the zero-subset indicators has rank r, the realizing group can be taken of order less than
`2 r^(r/2) max(2, 2^n-1+n(n-1)/2, (r+1)^((r+1)/2))`, with `0^0=1`. Thus this normalization preserves which labelled permutations are weakly valid, which are strong, and whether the total is zero. It bounds the group size in terms of the relation rank and cardinality, without assuming any bound on the original group or its torsion.

**Proof.** Label the elements a_i. In Z^n let L be the lattice generated by the incidence vectors of all zero-sum subsets, or equivalently of minimal nonempty zero-sum subsets by the partition observation. The assignment e_i -> a_i factors through Q=Z^n/L. Every zero subset vanishes in Q. A nonzero subset and each e_i-e_j remains nonzero in Q because its image in the original group is nonzero. Let F consist of the nonzero subset vectors and the pairwise differences e_i-e_j for i<j, so |F| <= m=2^n-1+n(n-1)/2.

Write Q = T plus a free abelian group, with T finite. By Smith normal form, |T| is the gcd of the nonzero r-by-r minors of any row generator matrix for L (and 1 for r=0). A minor of a 0-1 matrix has absolute value at most r^(r/2) by Hadamard, hence so does |T|.

Pick a prime p larger than max(2,m,(r+1)^((r+1)/2)) and less than twice this maximum; apply Bertrand to its integer floor. For every v in F with nonzero free part, append v to a fixed list of r linearly independent rows of L. Some (r+1)-minor is nonzero, with absolute value at most (r+1)^((r+1)/2), because all entries have absolute value at most 1. Thus v lies outside the mod-p span of those r rows. That span equals the mod-p row span of all L: it has dimension r (a nonzero r-minor survives), and all (r+1)-minors of the original generator matrix vanish identically. Hence v does not belong to L+p Z^n, so has nonzero class in Q/pQ. In fact p>|T|, so this is exactly a nonzero free-part reduction. Pick a linear functional on the free part mod p that is nonzero on all these reduced vectors; each constraint excludes exactly 1/p of the functionals, so a union of at most m<p such hyperplanes does not cover the dual space. Keep T and reduce the free part via this one functional to Z/p. All torsion-only members of F survive because their T components are unchanged. Every vector in L still vanishes. Thus the images of e_i are distinct, nonzero, and realize exactly the original pattern, in a group of order at most |T| p. The full-rank and rank-zero cases satisfy the same argument, including a vacuous free part at full rank.

**Audit boundaries.** The qualitative residual-finiteness idea and use of Smith normal form are standard; related universal constructions for preserving additive relations appear in [*Unique sums and differences in finite abelian groups*](https://doi.org/10.1016/j.jnt.2021.06.014). No priority for the explicit bound is asserted. Preserving all nonzero subset sums requires exponential many hyperplane exclusions as proved above. If all one needs is transport of a counterexample, preserving its old zeros suffices, plus nonzero singletons and pairwise differences; use m=n(n+1)/2, adding the full indicator only when its nonzero total must also survive. More collisions can never create a valid permutation. This gives a smaller witness bound but need not preserve good permutations. These reductions do not turn the currently non-explicit large-size threshold into a feasible finite verification and do not count as a solved conjecture.

## 3. Concentrating the obstruction in the relation torsion

Use the presentation Q=Z^n/L above and let φ:Q→G carry its coordinate classes to the original elements. Set H=φ(T), with T the finite torsion subgroup of Q. Then Q/ker(φ|T) is isomorphic to H × Z^(n−r). The original map factors through this quotient. Consequently every original zero subset remains zero in the quotient (by L), and no original nonzero subset, single-element, or pairwise difference is made zero (by the factor map to G).

Kravitz’s [*Rearranging Small Sets for Distinct Partial Sums*](https://math.colgate.edu/~integers/y113/y113.pdf), Remark 2, notes that strong sequenceability of an abelian group passes to its product with Z (and thus any finite free abelian power, for finite subsets). It follows that if H is strongly sequenceable, the original set is strongly sequenceable. In particular any obstruction to either version must have nontrivial H of order dividing the gcd of the nonzero r-by-r minors; more precisely this H itself must contain a nonzero subset with no strong sequencing. Thus when G has no torsion at any prime dividing that gcd the original set is strongly sequenceable. This is a rank- and pattern-dependent application of Kravitz’s rectification strategy, not a general solution or a priority claim.

## Next attack

A minimum-size obstruction to either version is connected. Look for a cut-vertex gluing lemma that preserves enough freedom to split a common element across two strong components. Note that imposing no zero interval is not equivalent to forbidding only inclusion-minimal zero subsets as intervals: a zero interval can be a union of intertwined minimal subsets, with no one of them contiguous. Any further reduction must account for unions.
