# A pair need not descend through a cover

The cover construction cannot reduce [Erdős #585](https://www.erdosproblems.com/585) to a statement guaranteeing a pair after replacing the host by one chosen finite cover. Even a two-sheet cover can introduce a pair into a bipartite graph that originally had none.

**Lemma.** Every finite connected simple $`2k`$-regular graph $`B`$, $`k\ge1`$, has a cyclic $`k`$-sheet cover with a Hamilton decomposition into $`k`$ cycles. Each of those cycles projects to the same Euler tour, in particular projecting bijectively onto the base **edge set**.

**Proof.** Fix a cyclic Euler tour of $`B`$. There are exactly $`k`$ visits to each base vertex: the visits partition its $`2k`$ incidences into pairs. Label the visits at each vertex bijectively by $`\mathbb Z/k`$, and take one lifted vertex for each pair (base vertex, visit label). For an oriented base edge $`u\to v`$ in the tour, let its visit labels at its two ends be $`i,j`$. Over this edge use the entire matching $`(u,i+a)(v,j+a)`$, $`a\in\mathbb Z/k`$. This is a cover. Lifting the cyclic tour through its assigned visit labels gives a simple spanning cycle, since each lifted vertex occurs exactly once. Translating all labels by $`a`$ gives a Hamilton cycle for each $`a`$, and these cycles use the $`k`$ edges in each base-edge matching exactly once between them. The cover is connected because one such cycle already spans it. $`\square`$

For $`k=2`$, take the base to be the incompatible gluing in [FOUR-EDGE-CUTS.md](FOUR-EDGE-CUTS.md). The base can be simple, bipartite, 4-edge-connected and of arbitrarily large girth, and it contains no witness pair. The cover from the lemma has two Hamilton cycles with no shared edges. It is bipartite and has girth at least that of the base: the local matching property sends any cycle to a closed nonbacktracking walk, which contains a simple cycle no longer than itself. It is also 4-edge-connected since each spanning cycle crosses every nontrivial cut at least twice. Thus even when edge projection is injective on each of the two upstairs cycles, it can create no pair downstairs. The images can be closed trails sharing every base edge, not simple cycles.

Combining the lemma with [the three-edge switch](COVERS-PRESERVING-CYCLES.md), any connected simple even-regular graph has Hamilton-decomposable finite covers with arbitrarily large girth. First take the cyclic Euler-tour cover, then take a girth-raising cover preserving its edge-disjoint Hamilton preimages. The composed cover need not be cyclic. This construction gives positive examples and an obstruction to descent, not a proof that an arbitrary base has the desired two cycles.

## The same quartic base also has a negative cover

For **every** connected simple 4-regular base, a second connected two-sheet cover has no witness pair. Choose a base edge and start with two disjoint copies. Remove both copies of the chosen edge and match its end fibres crosswise. Every cut in the base has even size, so the chosen edge was not a bridge and each punctured copy is connected. The resulting cover is connected, and just two edges join its sheets. Any common-support pair in the cover would have to span by degree saturation, yet each cycle meeting both sheets must use both cut edges. That contradicts edge-disjointness. This cover also preserves bipartiteness and never decreases girth.

Thus for a fixed connected quartic base of either status, the existence of the pair can be toggled by choosing between two connected covers of **the same sheet number**. The negative cover in this paragraph has a two-edge cut; no claim that every base has a negative maximally edge-connected cover is made.
