# Erdős–Turán additive basis conjecture

**Partial research.** In any fixed integer base, a set with a multiple context-free language of canonical numerals is either polylogarithmically sparse or has two-term representation counts with power-law spikes. In particular, the conjecture holds for every asymptotic additive basis of order two in this grammar class. The proof allows arbitrary finite fanout and arbitrary language ambiguity. General asymptotic additive bases remain open. [Issue #379](https://github.com/1337isnot1337/solved-conjectures/issues/379)

## Target and sources

For $A\subseteq\mathbb N$, let $r_A(n)$ count unordered pairs with repetition from $A$ summing to $n$. Erdős and Turán conjectured that, if $r_A(n)>0$ for all sufficiently large $n$, then $r_A$ is unbounded. Using ordered pairs changes the counts by at most a factor of two. The target is the unrestricted assertion. [Erdős–Turán, 1941, p. 215](https://combinatorica.hu/~p_erdos/1941-01.pdf#page=4)

Li and Zhang’s 2026 paper states the general conjecture and proves an improved density threshold for forcing a fixed representation count. Bell, Hare and Shallit characterize when automatic sets are additive bases, using the sparse versus nonsparse distinction for regular languages. Here the language argument also covers multiple context-free grammars and directly bounds repeated sums. The November 24, 2026 source check did not locate an unrestricted resolution or establish priority for this arithmetic lifting. [Li–Zhang](https://arxiv.org/abs/2605.30922) · [Bell–Hare–Shallit](https://arxiv.org/abs/1710.08353) · [Seki–Matsumura–Fujii–Kasami, *On multiple context-free grammars*](https://nessie.ilab.sztaki.hu/~kornai/2023/Hopf/Resources/seki_1991.pdf)

## Grammar and claim

Fix $b\ge2$ and use the usual base-$b$ digit alphabet and canonical numerals. A multiple context-free grammar has finitely many nonterminals, each returning a tuple of strings of some fixed positive arity. Each production concatenates terminal strings and components of its child tuples to produce the output tuple. The start nonterminal has arity one. Linearity allows any child component to occur at most once in the entire output. In a nondeleting grammar each child component occurs exactly once.

One may assume the grammar is nondeleting. First remove unproductive symbols and rules. For every nonterminal $X$ of arity $d$ and every nonempty $I\subseteq\{1,\ldots,d\}$, introduce a symbol for the projection of $X$ onto its components in $I$. In a production for this symbol, retain only outputs in $I$. For each child use the corresponding projected symbol for the components that occur in those outputs, dropping a child when none of its components occur. Every remaining child component is used exactly once. Projecting an original derivation gives a new one, and lifting each participating child independently and filling any omitted productive child gives a derivation of the original production. Thus the start language is preserved. Finally keep only symbols and productions that occur in complete derivations.

**Theorem.** If the canonical base-$b$ numerals of $A$ form such a language, then exactly one of the following holds.

- There is a finite $D$ with $|A\cap[1,x]|=O((1+\log x)^D)$.
- There are $c,\delta>0$ such that $\max_{n\le x}r_A(n)\ge c x^\delta$ for all sufficiently large $x$. Moreover there are infinitely many $n$ with $r_A(n)\ge c n^\delta$.

The alternatives are disjoint because $r_A(n)\le |A\cap[1,n]|$. The sparse alternative is incompatible with being an asymptotic additive basis of any fixed order $h$. For all large $x$, the representations of all sufficiently large integers up to $x$ would require $|A\cap[1,x]|^h\ge x-O(1)$. Hence in particular an asymptotic basis of order two must satisfy the second alternative.

## A pair of recursive contexts gives repeated sums

For a nonterminal $X$ of arity $d$, choose an ancestor and descendant labeled $X$ in a derivation, evaluate all other branches between them to terminal tuples, and leave that descendant open. The resulting map from the descendant’s $d$ components to the ancestor’s $d$ components is a recursive context for $X$. Include the identity context from the empty path. By nondeletion and linearity, it has $d$ output strings with the $d$ named input variables occurring exactly once. Its shape specifies the variables in order in each output, and there are $2d$ terminal gaps including possible empty gaps. The length vector records the length of each gap.

Suppose some $X$ has two distinct recursive contexts $C_0,C_1$ of the same shape and the same length vector. Their total terminal length $\ell$ is positive because at least one gap differs. Fix a complete tuple derivation from $X$ as the seed and a surrounding start context with a hole at $X$. These exist because $X$ occurs in a complete derivation. For each $k\ge1$ and each bit string $\varepsilon\in\{0,1\}^k$ form a numeral by applying the $k$ chosen contexts in nested order between the seed and the start context.

All numerals made this way have the same length $L+k\ell$, for a constant $L$ from the seed and surrounding context. The components at each layer have lengths independent of the choices, by induction from the seed. A terminal letter contributed by a given gap of a given layer therefore appears in a position independent of the choices. Each such letter appears exactly once in the final numeral. Different layers and gaps occupy disjoint positions, and the positions of the seed and surrounding letters are fixed as well. At least one gap distinguishes the two choices at any given layer, which makes the $2^k$ numerals distinct.

Pair each $\varepsilon$ with its bitwise complement. In the two numerals of each pair, the digit sum at every position is fixed. At variable positions it is the sum of the two possible digits from that gap and layer. At fixed positions it is twice the common digit. Positional evaluation is linear in the digits, so all pairs have the same numerical sum $n_k$, including when base-$b$ carries occur. There are $2^{k-1}$ unordered pairs and $n_k<2b^{L+k\ell}$. Canonicality also forces $n_k\to\infty$ with $k$. Taking $\delta=(\log_b2)/\ell$ proves the spike bound. For each sufficiently large $x$, choosing the largest $k$ with $2b^{L+k\ell}\le x$ gives the bound on the maximum up to $x$.

## Without such a pair the language has polynomial growth

Suppose there are no two distinct recursive contexts with matching shape and gap lengths at any useful nonterminal. For a symbol of arity $d$, the number of distinct contexts with total terminal length at most $N$ is then at most a constant times $(N+1)^{2d}$, because there are finitely many shapes and at most that many length vectors. This counts actual terminal contexts regardless of how many derivations produce them.

For a subset $S$ of nonterminals and $X\in S$, consider the tuples generated at $X$ by trees using only labels in $S$. We prove by induction on $|S|$ that the number of such tuples of total length at most $N$ is bounded by a polynomial in $N$. In any such tree choose a deepest occurrence of $X$, allowing the root. The region between the root and this occurrence gives a recursive context of terminal length at most $N$. Below the chosen occurrence there is no further $X$. Choose its root production, which has finitely many possibilities. Each child tuple comes from a tree over $S\setminus\{X\}$ and has total length at most $N$. This bound on each child follows from nondeletion, since all its strings appear in the final tuple. By induction there are polynomially many possibilities for each child tuple, and each production has finitely many children. For a terminal-only production there is one output tuple. Multiplying by the polynomial bound for the outer context gives the claimed induction.

Taking $S$ to be the entire grammar and $X$ the start symbol bounds the number of words with at most $N$ digits by a polynomial. A canonical base-$b$ numeral at most $x$ has at most $1+\lfloor\log_b x\rfloor$ digits. This gives the sparse alternative and completes the proof.

## Exact controls and scope

Two binary grammars exercise the routing of multiple components. Start with the arity-two seed $(\epsilon,\epsilon)$, where $\epsilon$ is the empty string, and end by concatenating a leading $1$ followed by both components. Each step chooses a bit $t\in\{0,1\}$ and its complement $\bar t$. In the first grammar the contexts are $(x,y)\mapsto(ty,x\bar t)$, which exchange the variable locations. In the second they are $(x,y)\mapsto(txy\bar t,\bar t)$, which merge both variables into one output. For each grammar and every depth from one to twelve, exact enumeration checked distinctness and constant sums for all complementary pairs. At depth twelve, the two common sums were $50{,}331{,}647$ and $206{,}158{,}430{,}207$, with 2,048 distinct unordered pairs constructed in each case.

The argument only uses positional weights for the arithmetic step. It also applies to a canonical injective digit system with a fixed sequence of positive weights from the right and with numeral length comparable to the logarithm of its numerical value. The unresolved issue for the general conjecture is to obtain some substitute for recursive contexts in an arbitrary additive basis. A basis assumption alone supplies a count of numerals and no finite grammar.
