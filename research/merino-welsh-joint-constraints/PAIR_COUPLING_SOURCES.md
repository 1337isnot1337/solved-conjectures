# Source record for the pair coupling note

Checked 21 November 2026. This is a bounded literature and input record for an **unproved auxiliary inequality**, not a claim that a new named conjecture has been resolved.

1. Noble and Royle, *The Merino–Welsh conjecture holds for series–parallel graphs*, [arXiv:1303.6416](https://arxiv.org/abs/1303.6416). The definitions and composition identities in Section 3, Lemmas 3.3–3.4, were read directly in the primary PDF. They give the underlying orientation-count factorization. Local PDF SHA-256: `2dfaff6cef5cc8256743531cd05682c95d27198e836050994d0f34583340203e`.
2. Chen, Jin, and Ma, [arXiv:2610.27706](https://arxiv.org/abs/2610.27706), Section 5, together with the [existing repository reduction](https://github.com/1337isnot1337/solved-conjectures/blob/main/docs/merino-welsh-research.md). The current note retains the already documented exactly-two class restriction, safe pair deletion, and marginal interval. It does not claim those as new. Local PDF SHA-256: `3bafa90f723c2a2a4b53cfd25cae28ba1bd44a611c3d14698592c30a32aa6569`.
3. Jungang Chen and Jiaxin Xie, *Quantitative Merino–Welsh inequalities for joins*, [arXiv:2609.33680v1](https://arxiv.org/abs/2609.33680), 27 September 2026. The main statements, Proposition 2.6, and Lemma 2.7 were read. Lemma 2.7 is an edge-addition comparison of `Q`, not the proposed terminal-comparability coupling. Local PDF SHA-256: `4b36867cf4c72b723bbc01e3f0b8c2356de96c6ae193378ab0faf9555e3db093`.
4. Shaohan Xu, Fengming Dong, and Kexiang Xu, *The multiplicative Merino–Welsh inequality for chordal graphs*, [arXiv:2610.25817v1](https://arxiv.org/abs/2610.25817), 19 October 2026. The terminal definitions, composition identities, equation (4.1), and Theorem 4.3 were read. Their exponential bound concerns an edge-deleted rooted two-tree and effective conductance. Local PDF SHA-256: `b55c8bf7ec4ba4687ce94c3e48d31d2056c1fae2791063d2fd3abf15cc0d4a46`.
